## 重新生成

在 `工具/video-render` 下运行（Windows 用 `python`）。`public/` 和 `*.mp4` 不进仓库，换电脑后先入库素材：

```bash
cd 工具/video-render
npm install && npx remotion browser ensure                      # 新机器一次
P="../../进行中/AI时事03-AI越强什么越值钱"
python scripts/import_photos.py "$P/图片素材" ai03 --need "$P/AI越强什么越值钱-发布清单.md"
python scripts/import_cards.py "$P/图片素材" ai03 --need "$P/AI越强什么越值钱-发布清单.md"
python scripts/import_sfx.py
# A-roll：4 段按顺序拼成 1080p 静音代理（第 1 章用降噪版画面，和原版画面一致）
ffmpeg -i "$P/11月2日(1)/11月2日(1)-1.mp4" -i "$P/11月2日(1)/11月2日(1)-2-降噪.mp4" -i "$P/11月2日(1)/11月2日(1)-3.mp4" -i "$P/11月2日(1)/11月2日(1)-4.mp4" -filter_complex "[0:v][1:v][2:v][3:v]concat=n=4:v=1:a=0,scale=1920:1080,fps=30[v]" -map "[v]" -an -c:v libx264 -crf 18 -preset fast -pix_fmt yuv420p public/ai03/aroll.mp4
python scripts/render.py ai03 arollsheet                        # 拼图
python scripts/render_seq.py ai03 --comp Ai03Full --frames 0-14451 --out out/ai03-full.mp4 --workers 3 --concurrency 3 --fresh --no-check
python scripts/glitch_check.py out/ai03-full.mp4                # 应为 坏帧 0
cp out/ai03-full.mp4 "$P/AI越强什么越值钱-动画轨+出镜-仅音效-全片.mp4"
```

字幕或口播改了：`python scripts/timeline_from_srt.py "$P/AI越强什么越值钱-口播逐字稿.md" "<新的.srt>" ai03 src/ai03/scenemap.json`，再整片重渲。出镜表：`python scripts/aroll_cues.py ai03`。改叠字 / 版式：改 `src/ai03/photo.json`，先 `python scripts/render.py ai03 arollsheet` 看拼图，再渲全片。
