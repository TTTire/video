动画轨的时间轴按你口播的字幕（`10月13日.srt`）生成，59 句和口播稿一一对上，每个画面切换都卡在你说那句话的时间点上。总长 5 分 13.5 秒。

## 推荐剪法（整条动画轨）

1. 主轨放口播 A-roll，**从 0 秒开始**。
2. 动画轨放在画中画轨（上一层），**起点也对齐 0 秒**。
3. 想露脸的段落把动画轨切开、删掉，下面的 A-roll 就露出来了。适合露脸的位置：03（"我一开始也是这么想的"）、13 最后一句（"我第一次看到这个数愣了一下"）、21–22（建议段）。
4. 音效跟着动画走：删掉动画的段落音效也一起没了，不用单独处理。
5. 字幕和 BGM 在剪映里加；画面文字都压在上 2/3，底部字幕位是空的。
6. 口播里如果剪掉了 NG 或停顿，导致后面整体错位，就在动画轨同一位置剪掉同样的长度；或者改用分场景片段，按下表时间点逐段摆。

## 重新生成

字幕或口播改了以后，在 `工具/video-render` 下运行：

```bash
python scripts/timeline_from_srt.py "<口播逐字稿.md>" "<新的.srt>" ai01 src/ai01/scenemap.json
python scripts/render.py ai01 full
python scripts/split_scenes.py out/ai01-photo.mp4 ai01 "<选题文件夹>/剪辑素材-分场景-仅音效" src/ai01/scene-names.json
```

改叠字 / 版式：改 `src/ai01/photo.json`，先 `python scripts/render.py ai01 sheet` 看拼图，再渲全片。
