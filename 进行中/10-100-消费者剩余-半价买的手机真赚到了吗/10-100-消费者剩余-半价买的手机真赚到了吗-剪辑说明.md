## 剪法

- 成片直接放主轨，从 0 秒开始，不用再对 A-roll：出镜层已经合在画面里，人声已经混进音轨。
- 人声是 `同步/A-roll-同步-全部.mp4`（录音笔音轨）按 `A-roll粗剪/剪辑映射.json` 的 52 段 keeps 切出来的，和粗剪完全同一条时间线（逐段对过，偏差 < 1 ms）。
- 字幕：导入 `10-100-消费者剩余-半价买的手机真赚到了吗-中文字幕.srt` / `-英文字幕.srt`，或直接用双语版。字幕时间轴就是成片时间轴。
- BGM 按发布清单「背景音乐（Suno）」那段出，铺在人声下面。

## 重新生成

粗剪（`工具/aroll-prep` 下）：

```bash
# 录音笔每段都停过：0–3.wav 按顺序接成一条，中间各插 30 秒静音，用完删掉
ffmpeg -i 未剪辑/0.wav -i 未剪辑/1.wav -i 未剪辑/2.wav -i 未剪辑/3.wav -filter_complex "[0:a]apad=pad_dur=30[a0];[1:a]apad=pad_dur=30[a1];[2:a]apad=pad_dur=30[a2];[a0][a1][a2][3:a]concat=n=4:v=0:a=1[out]" -map "[out]" -c:a pcm_s16le -ar 48000 -ac 2 同步/录音笔-拼接.wav
python scripts/sync.py "<选题文件夹>/未剪辑" --recorder "<选题文件夹>/同步/录音笔-拼接.wav" --concat
# A-roll-同步-全部.words.json 是按能量切句后逐句转写的（做法写在它的 note 里），transcribe.py 整条转写只拿来核对专有名词
python scripts/cut.py "<选题文件夹>/同步/A-roll-同步-全部.mp4" "<选题文件夹>/同步/剪切清单.md" --words "<选题文件夹>/同步/A-roll-同步-全部.words.json" --out "<选题文件夹>/A-roll粗剪/10-100-消费者剩余-半价买的手机真赚到了吗-A-roll粗剪.mp4" --snap 0 --margin 0
```

动画轨 + 出镜层（`工具/video-render` 下）：

```bash
python scripts/scenes_from_checklist.py "<发布清单.md>" "<讲稿卡.md>" ep10          # photo.json 已手调，不要加 --force
python scripts/import_photos.py "<选题文件夹>/图片素材" ep10 --need "<发布清单.md>"
python scripts/make_timeline.py "<讲稿卡.md>" ep10 --starts src/ep10/starts.json --srt "<选题文件夹>/10-100-消费者剩余-半价买的手机真赚到了吗-中文字幕.srt"
ffmpeg -i "<选题文件夹>/A-roll粗剪/10-100-消费者剩余-半价买的手机真赚到了吗-A-roll粗剪.mp4" -vf scale=1920:1080 -r 30 -an -c:v libx264 -crf 18 -preset fast public/ep10/aroll.mp4
python scripts/aroll_face.py ep10
python scripts/render_seq.py ep10 --comp Ep10Full --frames 0-10475 --out out/ep10-full.mp4 --fresh --no-check

```

```bash

```
