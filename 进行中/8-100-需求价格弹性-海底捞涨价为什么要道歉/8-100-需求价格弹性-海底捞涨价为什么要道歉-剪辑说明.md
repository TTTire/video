## 推荐剪法（整条动画轨）

1. 主轨放口播 A-roll，**从 0 秒开始**。
2. 动画轨放在画中画轨（上一层），**起点也对齐 0 秒**。
3. 在想露脸的段落把动画轨切开、删掉，下面的 A-roll 就露出来了。
4. 音效跟着动画走：露脸的段落删掉动画，音效也一起没了，正好。
5. 口播里如果剪掉了 NG 或停顿，导致后面整体错位，就在动画轨同一位置剪掉同样的长度；或者改用下表的分场景片段，按时间点逐段摆。
6. 这期开了黑边，字幕放在底部黑边里（y ≈ 1010）正好，不会压到画面文字。

## 重新生成

字幕或口播改了以后，在 `工具/video-render` 下运行（Windows 把 `python3` 换成 `python`）：

```bash
python3 scripts/timeline_from_srt.py "<口播逐字稿.md>" "<新的.srt>" ep8 src/ep8/scenemap.json
python3 scripts/render.py ep8 full
python3 scripts/split_scenes.py out/ep8-photo.mp4 ep8 "<输出文件夹>" src/ep8/scene-names.json
```
