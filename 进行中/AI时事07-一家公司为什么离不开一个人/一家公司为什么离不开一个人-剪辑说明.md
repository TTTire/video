# 一家公司为什么离不开一个人 — 剪辑说明

时间轴依据：用户审核通过的粗剪 `粗剪审核通过.mp4`（05:59.30，比 `A-roll粗剪/` 那版少两段各 0.40 秒的停顿：审核版 01:47.56「数字很僵硬」之后、03:26.00「15 亿美元」之后，两版音频逐段互相关对过，其余一帧不差）。对它重新转写出 `粗剪审核通过.words.json`，要点起点表 `工具/video-render/src/ai07/starts.json` 按逐字时间 + 句间停顿填；字幕是本期定稿的 `一家公司为什么离不开一个人-中文字幕.srt`。总长 10814 帧（06:00.47），1920×1080 / 30fps，不开黑边、不加颗粒。引擎合了出镜层（A-roll = `粗剪审核通过.mp4`，跟脸）。成片音轨 = 人声 + 音效，没有 BGM、没有烧字幕。最后一句在 05:58.45 说完，粗剪到 05:59.30，画面再多留 1.2 秒收尾（出镜半屏卡停在粗剪最后一帧）。

三段动画用了 `工具/remotion模版`：07 片头（01-宋体标题-打字数据表，只用标题）、19 「我让 AI 去调研了一圈」（06-AI输入框-打字发送）、27「先拒绝 后请回」（01 的标题 + 表格）。参数在 `工具/video-render/src/ai07/tpl/*.json`，出好的片子放 `工具/video-render/public/ai07/tpl/`，由 `src/ai07/custom.tsx` 按场景起点铺进来。02–05 是粗做、示例多的模版（榜单、鱼眼卡片、截图鱼眼、照片卡片），本期没有对应的内容，没用。

## 剪法

- 成片直接放主轨，从 0 秒开始，不用再对 A-roll：出镜层已经合在画面里，人声已经混进音轨。
- 人声就是 `粗剪审核通过.mp4` 自带的音轨，原样抽出来转 48 kHz 混的，和画面同一条时间线。
- 字幕：导入 `一家公司为什么离不开一个人-中文字幕.srt` / `-英文字幕.srt`，字幕时间轴就是成片时间轴。
- BGM 按发布清单「背景音乐（Suno）」那段出，铺在人声下面。

## 录制时跳过、改说的要点

没有跳过的要点，0.1–3.8 都讲了。改说的和讲稿卡、发布清单的回写一致：
- 0.1：说成"股价暴涨了 30%"，没说"约"；画面写"跳涨约 30%"。
- 0.3 / 1.3：请愿签名说成"从 11 万左右涨到 18 万""从 11 万涨到了 18 万"；画面照原数 11.5 万，字幕照口播。
- 1.1：Synopsys 说成"前某公司的 CEO"；画面只写"哈维·琼斯"。
- 1.4："数字很硬"说成"数字很僵硬"，字幕照口播，英文按原意译成 rock solid。
- 2.5：苹果"市场份额"说成"市场价"；画面写"份额掉到 3% 左右"，中文字幕按原意写"市场份额"（这是口误，照口播写成"市场价掉到 3%"意思就错了；要照口播就改第 93 条）。
- 2.7 / 3.4：没点名杨锦方，说成"北大创投课有一位老师""北大老师"；画面也不点名。
- 3.7："还没找到第二个"说成"没有找到一个更好的继承人"；画面照口播。

字幕里按逐字转写校过的错字（两遍转写对照）：延请（宴请）、科莱特（克劳特）、英伟达（应伟达 / 因为达）、人情戏（人情系）、复出（付出）、转起来 / 都能转（赚）、AI（AA）、继任计划（机人计划）；"CEO 和董事职务"两遍转写一遍听成"的"，按讲稿卡写"和"。
