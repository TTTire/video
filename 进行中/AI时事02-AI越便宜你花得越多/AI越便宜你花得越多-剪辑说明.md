# AI越便宜你花得越多 · 剪辑说明：口播 A-roll + 动画轨

动画轨的时间轴按你口播的字幕（`AI便宜.srt`）生成，190 句和口播稿一一对上（没有一句出入），每个画面切换都卡在你说那句话的时间点上。总长 **7 分 01.1 秒**。

## 文件

| 文件 | 用法 |

| `素材/` | 你出的 20 张原图 |

## 推荐剪法（整条动画轨）

1. 主轨放口播 A-roll，**从 0 秒开始**。
2. 动画轨放在画中画轨（上一层），**起点也对齐 0 秒**。
3. 想露脸的段落把动画轨切开、删掉，下面的 A-roll 就露出来了。适合露脸的位置：13（"说实话，我自己就是这样：我英语一般……"）、22 最后两句（"他是卖算力的，当然希望这样"）、26（"多问一句"那段建议）、28 前四句（"我自己打算这周……重新算一遍"）。
4. 音效跟着动画走：删掉动画的段落音效也一起没了，不用单独处理。
5. 字幕和 BGM 在剪映里加；画面文字都压在上 2/3，底部字幕位（y>820）是空的。BGM 用发布清单里的 Suno 曲子，压到 -22 到 -28 dB。
6. 口播里如果剪掉了 NG 或停顿，导致后面整体错位，就在动画轨同一位置剪掉同样的长度；或者改用分场景片段，按下表时间点逐段摆。

## 重新生成

字幕或口播改了以后，在 `工具/video-render` 下运行：

```bash
python scripts/timeline_from_srt.py "<口播逐字稿.md>" "<新的.srt>" ai02 src/ai02/scenemap.json
python scripts/render.py ai02 full
python scripts/split_scenes.py out/ai02-photo.mp4 ai02 "<选题文件夹>/剪辑素材-分场景-仅音效" src/ai02/scene-names.json
```

改叠字 / 版式：改 `src/ai02/photo.json`（或改 `src/ai02/_build_photo_json.py` 再跑一遍生成），先 `python scripts/render.py ai02 sheet` 看拼图，再渲全片。图表在 `src/ai02/custom.tsx`。
