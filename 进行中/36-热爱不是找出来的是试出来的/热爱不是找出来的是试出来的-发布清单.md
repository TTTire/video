### 发布文案

晚上十一点。

你又打开招聘软件。

每个方向都像别人的人生。

你不知道哪一条是自己的。

很多人不是没有热爱。

是一直想在开始之前，就拿到一个不会错的答案。

可热爱很少像一道被发现的题。

它更像一次次做过、改过、再回来以后。

你慢慢认出的自己。

#热爱 #职业选择 #人生选择 #心理学

### 画面方向

- 深夜招聘软件、课程页面和备忘录反复切换，手指停在报名按钮上
- 同学聚会里别人说起稳定工作、创业和转行，主角安静听着
- 写五百字、录一段音频、做一道菜、改一张 App 页面等低成本试验
- 吉他按弦、剪辑卡壳、第一次做饭失败，表现笨拙而非励志摆拍
- 睡前记录“开始前抗拒、过程中投入、结束后是否愿意再做一次”
- 视频 Prompt 后缀统一使用：Cinematic lighting, hyper-realistic, dark moody color palette, 8k resolution

## 内容自查

- [x] 核心反转明确：热爱不是提前藏好的答案，而是行动和反馈共同长出的偏好
- [x] 前3秒从深夜刷岗位和课程页面的具体动作切入
- [x] 生存张力：一直等确定答案，会让人越来越没有属于自己的证据
- [x] 身份张力：转行焦虑、同学聚会比较、害怕失败和害怕被问回报都能代入
- [x] 进步张力：用两个小时的低成本实验，积累自己的真实反馈
- [x] 明确排除错误期待：不是鼓励辞职追梦，也不是把每个爱好都变现
- [x] 四章只服务“热爱靠实验长出来”这个反转
- [x] 至少3句可独立传播的表达：
  - “热爱不是出发前给你的通行证，它常常是你走了一小段之后才发给你的回执。”
  - “你会越来越会评价别人走过的路，却越来越没有自己的证据。”
  - “真正值得走下去的事，不是完全不累，而是累过以后你还愿意回来。”
