# 模版库改成“一个工程、多个模版”

## 背景

模版可能会有很多。现在每个模版是独立工程，各带一份依赖，一个约 700MB，十个就是 7GB，而且版本会漂、没法一处浏览。

做法照现有渲染工程 `工具/video-render` 的规矩来：一个工程、多个合成、用脚本建骨架并自动登记（见它的 `src/Root.tsx` 标记块和 `scripts/new_episode.py`）。

你刚才的两个决定：
- **AGENTS.md 规则入口加一行**：做。
- **先粗后精**：做。

关于“参考视频”：它不是要你另外做的东西，就是你要我复刻的那段视频本身，也就是上次从下载链接存下来的那个 mp4。没有它就没法复刻，所以必须有；你只要照上次那样把链接或提示词发给我就行。

## 目标结构

```
工具/remotion模版/
├── README.md              库级说明：用哪个模版、命令、保存流程
├── package.json 等        整个库共用一份依赖（版本不变，Remotion 4.0.530）
├── scripts/
│   ├── new_template.py    建新模版骨架并登记
│   ├── render.py          按编号出片 / 出单帧，能直接指定某个示例
│   └── measure/           量帧小工具（抽帧拼图、量外框、量逐帧轨迹）
├── public/
│   ├── fonts/             所有模版共用的开源字体
│   └── t01/               各模版自己的素材（示例铺底图等）
├── src/
│   ├── index.ts、Root.tsx  用标记块注册所有模版，合成 id 形如 T01、T02
│   ├── shared/            共用部件：拆通道色散、逐字打出、颗粒、铺底推镜、字体度量
│   └── templates/
│       └── 01-宋体标题-打字数据表/
│           ├── README.md、示例-*.json、组件和参数文件
│           └── 参考/参考视频.mp4（mp4 被根目录 .gitignore 忽略，不进 git）
└── out/01-宋体标题-打字数据表/   成片和左右对照图
```

## 步骤

1. **把 01 的工程升格成库工程。** `package.json`、锁文件、`tsconfig`、`remotion.config.ts`、依赖文件夹整体移到 `工具/remotion模版/` 根下（依赖是移动不是重装）。如果自动备份已经把旧结构提交进 git，就用 `git mv` 保留历史。
2. **迁移 01。** 源码移进 `src/templates/01-…/`，字体集中到 `public/fonts/`，示例照片移到 `public/t01/`，示例 json 里的图片路径跟着改，成片移到 `out/01-…/`，参考视频从下载文件夹移进 `参考/`。`Root.tsx` 带两处标记注释（`// ---- templates ----` 和 `// ---- /templates ----`），供脚本插入。
3. **抽共用部件。** 把 `TypedTable.tsx` 里通用的部分移到 `src/shared/`：`SplitGroup`、`Typed`、`Grain`、`channelColor`、`dotPattern`、铺底推镜的 `Background`、字体度量常量。01 留自己的版面常量和运动曲线。字体统一在 `src/shared/fonts.ts` 注册。
4. **写脚本，照 `video-render/scripts` 的风格（中文文档字符串、用法写在第一行）。**
   - `python3 scripts/new_template.py 02-名称`：新建 `src/templates/02-名称/` 骨架（组件、参数、README、示例 json）和 `public/t02/`，在 `Root.tsx` 两处标记之间加上引入和注册，并在库 README 的表里加一行“待补充 / 粗做”。已存在的不覆盖。
   - `python3 scripts/render.py 01 --示例 片头`（或 `--props 路径`、`--out 路径`、`--still 帧号`）：默认输出到 `out/01-…/`。不带参数时列出所有模版和各自的示例。
   - `scripts/measure/`：把这次用过的量帧办法整理成带参数的三个小工具，以后每个模版复用（需要 python3 的 numpy 和 ffmpeg，本机都有）。
5. **改文档。** 重写库 README：结构、命令、用哪个模版的表（加一列“状态”）、保存流程（两档标准）。更新 01 的 README 里的合成 id 和路径。在 `AGENTS.md` 的“规则入口”表里加一行：“做片头 / 数据对比卡（Remotion 模版）→ 先读 `工具/remotion模版/README.md`”。

## 以后加一个模版的流程（写进库 README）

1. 你发来提示词或视频链接，粘在下载文件夹的一个文本文件里。我只做“下载视频并复刻”，不建 GitHub 仓库、不调接口。
2. 我先看一遍，告诉你这段适不适合做（真人出镜、靠原作者素材、要三维粒子的不做）。
3. **粗做，20–30 分钟**：结构完整、关键帧号对上（进场、退场、揭晓相差 3 帧以内）、字体用库里现有的近似。渲一条成片和左右对照图，放进库并登记，状态标“粗做”。
4. 你看一遍，挑出要常用的。
5. **精修，每个再加 40–60 分钟**：逐字量位置、换更接近的字体、逐帧比轨迹和打字进度，做到 01 这个程度，状态改“已精修”。

## 验证

- `npx tsc --noEmit` 通过；`npx remotion compositions src/index.ts` 能列出 T01。
- 迁移和抽取共用部件之后，各渲一遍默认成片，和迁移前的成片逐帧比差，平均差不超过 0.2（满量程 255；当前基线是 0.1）。“片头”“开场”两个示例同样比一遍。
- `python3 scripts/render.py 01 --示例 片头` 能出片；`new_template.py` 建一个临时模版确认登记正确后删掉。
- `npm run studio` 能启动。
- 磁盘上整个库约 700MB，而不是每个模版各 700MB。
