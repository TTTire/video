# 对标结构样本与证据边界

更新时间：2026-09-15

用途：当任务需要选择“机制解释型 / 实测决策型”、审读对标结构或复核样本依据时读取。普通写稿只使用 `SKILL.md` 的路由，不重复加载本文件。

这些结论是对公开成片的反向结构编码，不是创作者提供的原始口播稿，也不证明某种结构会直接导致高赞、完播或入选精选。

## 证据等级

- **A级：抖音原作品页。** 用于确认作者、标题、发布日期、时长和抖音成片结构。
- **B级：创作者官方 YouTube 或 B站版本。** 只用于辅助观察长口播方法；跨平台标题相同也不能默认逐秒一致。
- **C级：创作者采访或官方栏目页。** 用于确认账号定位、栏目分类或创作意图。
- **D级：搜索摘要、机器摘要和第三方拆解。** 只用于发现线索，不用于互动数字、精确逐字稿或结构定论。

自动字幕和本地语音识别只用于判断段落功能。专有名词、数字和原句必须回到原视频或原始资料核对。

### 反复出现的结构

`可见异常 → 简单模型 → 隐藏变量 → 证据校正 → 适用边界 → 回扣开头`

- 用一个解释物反复演算，例如押金、债券、一杯饮品或一道菜。
- 转场由观众的自然追问驱动，不靠章节报幕。
- 先讲动作、角色和钱怎样变化，再集中命名术语。
- 强钩子后主动补口径、特殊年份、反例和不能推出什么。
- 结尾让开头对象获得一个新解释，不靠口号升华。

不照搬“一口气了解”等辨识度表达、固定口癖、长篇案例树或个人幽默方式。

### 反复出现的结构

`高结果密度 Hook → 尽早给路线图 → 沿真实流程或固定维度推进 → 每段完成小验证 → 压缩总结 → 明确判断`

- 常用完成态、量化投入、问题串或反常识重分类开场。
- 行业稿按商业链，教程按操作顺序，横评按测试维度，决策稿按分类框架推进。
- 每一段形成“问题或场景 → 演示或数据 → 人话判断 → 限制”的微循环。
- 权威感来自实际做过什么、测过什么，而不是履历介绍。
- 结尾先压成两三项，再提高半层判断，不另开新理论。

不照搬多工具清单、连续疑问句、“最强”“天花板”“离谱”“神”等包装词，除非题目和证据确实需要。

## 合并使用原则

- 共同部分是：具体对象、单一任务、可见证据、主动交代边界、结尾给判断。
- 小Lin式结构适合追问因果，用一个解释物暴露隐藏变量。
- 秋芝式结构适合验证能力，用一个真实任务或测试矩阵展示输出和失败。
- 一条稿只选一种推进母结构。混合时只能让另一种充当局部证据，不能同时维护两条主线。
- 学习的是问题设计、证据结构和节奏，不复制逐字表达、案例顺序、口癖、标题包装或人设。
