# 抖音知识精选选题

目标是提升“像素呼吸”认知讲解内容进入抖音精选的内容质量，而非承诺获得精选标签。抖音没有公开精选准入公式；把本 Skill 当作选题与表达的质量门槛。

## 开始前

1. 先读工作区根目录的 `AGENTS.md`。写新稿、改开头、拟标题或写发布文案时，再读 `模板/三重张力五杠杆写稿流程.md`。
2. 若任务涉及《100个经济学原理》，先读 `模板/选题库/100个经济学原理.md` 确认正式序号；再按工作区的固定开场与三件套要求执行。
3. 明确视频只打穿的一个核心认知反转。一个视频不能同时解释多个同等重要的问题。

## 精选样本的可复用规律

2026-09-02 从已登录账号的抖音“精选 → 知识”页抽取了 50 条作品。它们涵盖 AI/科技、商业财经、历史人文、科学科普与认知学习；共同点不是题材，而是把知识写成一个与观众有关的判断题。

- 从具体、可感的异常或损失进入，不从概念定义进入。
- 标题承诺一个明确问题的解释或判断，例如“为什么 X”“你以为 X，其实 Y”“一口气看懂 X”“普通人该怎么判断 X”。
- 中段给出因果链，而非只抛观点：现象 → 机制 → 证据/案例 → 对个人的影响。
- 抽象理论必须落到钱、时间、工作、关系、风险或日常选择。
- 结尾留一个可复述、但不喊口号的判断。它应能让观众转述“原来我以前把 X 理解错了”。
- 样本中短讲、深讲和 20 分钟以上内容并存；按问题所需证据决定时长，不为了时长灌水。
- 标签只帮助分类和检索。不要把 `#抖音精选` 当作入选手段，也不要把“精选”写成可保证的结果。

## 选题模式

对每个候选题输出一张“精选可能性卡”，再排序，不要先写长稿。

```markdown
### 选题名
- 观众此刻的场景：
- 他以为的问题：
- 核心认知反转：
- 要解释的机制：
- 必须准备的证据物：数据、案例、对比、时间线或可视化之一
- 与观众的切身关系：钱 / 时间 / 工作 / 关系 / 风险 / 选择
- 一句带走的判断：
- 3 个标题候选：
- 不做的原因（如过泛、无法核验、只是观点或与现有选题重复）：
```

优先选择同时满足以下条件的题：有真实生活入口、有单一反转、能找到可靠证据、能给普通人一个具体判断。若只能得到“介绍一个概念”，重找入口，而不是堆模型。

## 标题与前 10 秒

标题要同时交代“对象 + 冲突/反常识 + 收益”。以下是可改写的骨架，不要机械套用：

- 为什么 `[常见现象]`，反而会让你 `[具体代价]`？
- 你以为 `[表面解释]`，真正起作用的是 `[机制]`。
- `[一个日常动作/物件]`，藏着 `[可解释的商业或认知规则]`。
- 普通人最容易看错的不是 `[A]`，而是 `[B]`。
- 用 `[时长]` 看懂 `[具体对象]`：它怎样影响你的 `[利益]`？

开头前三句依次完成：具体场景、反直觉判断、继续看的理由。不要用“今天我们来讲”“这个概念很重要”开场；也不要把未核实的刺激性结论写成事实。

## 脚本与审读模式

保持工作区既定的四章和三件套交付，不新增分镜脚本。每章应推进同一条链：

1. 让观众认出自己的场景或误判。
2. 拆掉表层解释，给出机制。
3. 用事实、案例或对比让机制站稳。
4. 回到观众可用于下一次选择的轻判断。

审读时逐项检查：

- 是否只有一个主反转，而不是一篇概念大杂烩？
- 标题、开头和结尾是否兑现同一个承诺？
- 每个关键主张是否有可核验依据，数字是否有生活尺度？
- 是否至少有一个具体物件、价格、人物动作或现实场景承接抽象概念？
- 删除后是否仍有重复解释、空泛总结或成功学压迫感？
- 发布清单中的标签是否以领域、对象和议题为主，而非堆“精选”“爆款”等词？

## 边界

- 不声称内容一定被精选、一定获得流量或可以通过某个标签入选。
- 不把片面案例、传闻或标题中的数字当事实；涉及时效信息先核验来源和日期。
- 不自动发布、评论、购买流量或改动现有脚本；这些操作须由用户单独授权。
- 若用户要求“对标”，学习问题设计、证据结构和叙事节奏，不复刻他人的逐字稿、画面或人设。
