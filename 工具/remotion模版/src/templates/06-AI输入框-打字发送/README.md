# 06-AI输入框-打字发送

状态：粗做。参考视频和出处在 `参考/`。参考是 1920×1080、30fps、180 帧，和成片画幅一样，版面数值都是照它量的屏幕坐标（帧号从 0 数）。

一句话：一个 AI 输入页。空输入框里光标闪着，一句提示词逐字打进去，鼠标指针从右下角滑过来点下发送，打好的字往上淡出，发送钮左边淡入三个小点，然后定住。

默认横屏 1920×1080，180 帧（6 秒），30fps。合成 id 是 `06-AI输入框-打字发送`，只做横屏。

参考是 motionface 片段「AI 输入页(可换 AI)」`0a1a589b-5e12-499f-81a1-5793d8a8bd20`。输入页是用 HTML 排的，不是原作者的截图，所以问句、提示词、模型标签都能换。

**参考里实际的动作顺序（逐帧量的，和一开始隔着总览图读的不一样）**：

| 帧 | 发生了什么 |
|---|---|
| 0–21 | 空输入框，光标闪：亮 14 帧、灭 14 帧，28 帧一个来回，从第 0 帧亮起。打字期间光标照旧闪，不打断 |
| 22–85 | 逐字打进 `Let's design an interface for a new AI workbench`。第 22 帧第一个字已有六成深，第 85 帧最后一个字变深。词和词之间停半拍到三拍，每个字从出现到变深用 1–2 帧 |
| 78–84 | 指针在右下角（尖在 1842, 923）淡入，85–88 停着 |
| 88→103 | 指针沿直线滑到发送钮上（尖 1582, 577），滑 15 帧、走 433 像素，方向正好是 (−0.6, −0.8)。两头慢中间快，最快一帧 73 像素 |
| 105–106 | 点下去：指针以尖为轴缩到九成。107 回到九四成，108 复原并开始淡出，109 很淡，110 没了 |
| 111–119 | 打好的字往上挪 23 像素、淡出（不缩放）。同一段时间模型标签一边淡一边压扁收窄 |
| 111–120 | 发送钮左边三个很淡的点依次淡入，之后定住到第 179 帧 |

输入框全片不变高（一直是 236 像素），发送钮不变色，输入框里也没有出现占位文字。这三处和最初隔着总览图的印象不同，是量出来的。

## 适合 / 不适合

- **适合**：片子里要出现“我给 AI 发了这么一句提示词”的时候；问句、提示词、模型标签都换得掉，外观能换成浅底、深底或自己配色。
- **不适合**：要放 AI 的回答（这里只做到“发出去”为止）；竖屏（没做）；提示词特别长（输入框不会变高，折了三行放不下只会把字缩小一点）。

## 用法

在库根目录（`工具/remotion模版`）跑：

```bash
python3 scripts/render.py 06                        # 默认内容（参考视频的原样）→ out/06-AI输入框-打字发送/默认.mp4
python3 scripts/render.py 06 示意                   # 中文长提示词的示例 → out/06-AI输入框-打字发送/示意.mp4
python3 scripts/render.py 06 自己的参数.json         # 用自己写的参数。只想换外观：{"theme": "light"}
npm run studio                                      # 左边挑 06，右边改参数
```

几个人同时改库的时候出片加 `--单独`（`python3 scripts/render.py 06 示意 --单独 -- --concurrency 2 --log=error`）。出片很快，180 帧十几秒。

## 参数

字段说明写在 `schema.ts` 的 `.describe()` 里，Studio 面板会直接显示。要点：

- **theme**：外观预设。`claude` 是参考这一套（深棕底、白框、橙钮，默认）；`light` 是浅灰底、白框、黑钮；`dark` 是深灰蓝底、淡紫钮、纸飞机图标；`custom` 按 **customTheme** 里填的颜色（可以只填要换的几项）。每套外观含背景、问句、输入框底色和边线、输入文字、光标、强调色、小图标和标签的字色、描线色、投影色、发送钮图标（`up` 向上箭头 / `plane` 纸飞机）。浅底、深底两套是照常见的输入页配色写的，不是照着哪一家量的。
- **question、showMark**：左上方的问句，居中；要不要前面的星标。
- **prompt**：打进去的提示词。太长会在输入框里自动折行，最远排到发送钮左边；折了三行还放不下就把字缩小一点（按每个字的大概宽度估的行数，不是量出来的）。
- **model、icons**：左下角的模型标签（留空 `""` 就不显示）和它左边的图标（从 `plus`、`sliders`、`globe`、`mic`、`none` 里挑，空数组一个都不放）。
- **thinking**：发送后要不要那三个点。
- **typeAt、typeEnd**：第几帧开始打字、第几帧打完。中间每个字什么时候出来是照参考量的节奏等比伸缩的：默认那句和参考一句一句对得上，换了文字以后停顿还是有的，只是不再落在词边界上。
- **clickAt**：指针点下发送钮的帧。指针淡入（比它早 27.5 帧）、滑过去（比它早 17 帧起步，滑 15 帧）都从它起算。光标闪烁的相位不跟着变，从第 0 帧起算（`caretPeriod`）。
- **sendAt**：发送后的变化（字淡出、标签收起、三个点出现）从哪一帧开始。默认比 `clickAt` 晚 6 帧。
- **showPointer**：不要指针的话文字照样在 `sendAt` 淡出，只是没有人来点。
- **fontStretch**：拉丁字母用多宽的字，默认 89%，中文不受影响。
- **motionBlur**：指针滑得快时带不带动态模糊，默认关（见下面“和参考不一样的地方”）。

## 运动是怎么做顺的

- 指针的位置是关键帧表过共用的 `curve.ts`（速度连续的平滑曲线）。表是逐帧量的，所以每一帧的位置和参考差不到 2 像素：起步 2.8、7.2、12.8…… 一直加到最快一帧 73 像素，再对称地慢下来，两头都是静止起步、停成静止。
- 指针淡入淡出、点下去的缩放、字的上移和淡出、标签的压扁、三个点的淡入，都是同一类曲线。
- `node scripts/motion.mjs 06` 的结果：指针每帧最多走 72.9 像素（第 96 帧，和参考一样），速度一次最多变 14.3 像素（第 96 帧附近是它加减速最猛的地方，前后是 12、13.6、14.3 这样一级一级加上去的，没有突变），全程不走弯。字块那个点发送后每帧最多走 3.5 像素。其余三个点是输入框的角和发送钮圆心，全片不动。

## 和参考不一样的地方

- **默认内容是参考视频的原样**，只为逐帧对照，里面的东西没有核实过。`示例-示意.json` 的中文内容全是示意，不是真的提示词或模型。
- **字体**：参考的字是一款偏紧的无衬线粗体，没认出是哪一款；这里拉丁字母用 Archivo（字宽调到 89%），比参考的笔画略粗、小写字母略高。换别的文字时字宽不会再跟着调。
- **打字的逐字节奏**：首尾（第 22、85 帧）和词一级的停顿对得上；细到每个字，默认这句里有 12 帧字行的右缘比参考多出 14–23 像素（早半拍到一个字），光标停在空格后面时比参考靠右 5–9 像素。
- **文字的起点**：参考里空着时的光标在 x=322，第一个字的墨迹却从 317 起，差 5 像素，对不上同一个文字起点。这里取了中间值，所以打出来的字比参考靠右 5 像素，空着时的光标靠左 1 像素。
- **文字退场的起步**：参考第一帧就上移 5 像素；这里抹顺了，第 111–115 帧比参考低 2–3.5 像素（那几帧字正在淡出，看不出来）。
- **指针**：黑边是清楚的 4 像素，外头一圈很淡的暖色光晕。参考里黑边外还有一条 1 像素的亮线，看着像录屏放大时的振铃，没有做。参考里指针飞得再快也是清楚的（量过第 96、97 帧的边和静止时一模一样），所以动态模糊默认关。
- **几样小的**：输入框上方几乎不做投影（参考也只亮 1–2）；图标是照着样子画的，不是原来的图标文件，外圈的软边比参考宽 2 像素；模型标签的药丸右端比参考短 4 像素；三个点只有七八个像素又很淡，大小只能对到大概。
- **没做**：颗粒（参考是纯色底）、竖屏。

对过的（成片 `默认.mp4` 对参考，同一套量法）：指针尖每帧的位置在滑动和点按的全程（第 90–107 帧）差 0–2 像素；打字从第 22/23 帧开始、第 85 帧打完，两边一样；字从第 111 帧起上移淡出，第 111–116 帧的高度差 3 像素以内，第 120 帧两边都没了；三个点第 111 帧出现、第 120 帧定住，两边一样；输入框底下的投影亮度差 3 以内；发送钮的位置差 1 像素以内。全片每帧全画面的平均像素差 1.3/255。对照图在库根目录的 `out/06-AI输入框-打字发送/对照/`。

## 注意

`scripts/render.py --单独` 的小入口以前不经过库的 `src/index.ts`，那里引入的 npm 字体（Archivo、JetBrains Mono、Instrument Serif）没有加载，拉丁字母会回落到别的字体。2026-11-26 已经修了：这些引入挪进了 `src/shared/fonts.ts`，两个入口都会走到。做这个模版时在它自己的 `index.ts` 里临时再引了一遍 Archivo，修好以后已经删掉。

## 文件

```
index.ts            对外的四样东西：默认画幅、组件、参数定义、默认值
Template.tsx        画面：makeView 的结果画出来，按需给指针叠几层动态模糊；makeView 从 motion.ts 转出去
motion.ts           makeView：某一刻画面该是什么样（打字的节奏、指针的位置和明暗、发送后的几条曲线、probes）
layout.ts           版面：每样东西放在哪、多大（量自参考第 110 帧）
Page.tsx            输入页：背景、问句、输入框里的字和光标、图标、模型标签、三个点、发送钮
Pointer.tsx         鼠标指针：内联 SVG 画的白色箭头，黑边加一圈淡光
fitText.ts          提示词太长时估行数、缩字号
themes.ts           三套外观预设、配色的小工具
schema.ts           参数定义和默认值
示例-示意.json      中文长提示词的示例（内容全是示意）
参考/               参考视频（mp4 不进 git）和 来源.txt
```

字体都注册在库的 `src/shared/fonts.ts`：Archivo Variable（拉丁字母）和 Noto Sans SC（汉字，也是拉丁字母的备用）。两款都是 SIL Open Font License。
