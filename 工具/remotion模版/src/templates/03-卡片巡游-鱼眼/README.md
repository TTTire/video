# 03-卡片巡游-鱼眼

状态：粗做。参考视频和出处在 `参考/`。

横屏 1920×1080，180 帧（6 秒），30fps。合成 id 是 `03-卡片巡游-鱼眼`。

深绿的底上飘着几张白色的卡片（横条、发票、流水、环形图），隔着一个弯得很厉害的广角镜头看。镜头一路飞过去，每停一处，一张卡片从远处带着虚影转进来、落在正中间，荧光绿的标题一个词一个词弹出来；换站时眼前这张又冲着镜头飞出去。一共四站，最后一站是所有卡片的总览。

参考是 motionface 片段「财务卡片巡游」`029698a2-50d4-4a4e-be7f-25eb67f76d90`，竖屏 720×1280、60fps、6 秒（出处见 `参考/来源.txt`）。帧号是从它逐帧量出来再除以 2 的；版面没有参考，是照竖屏那一套的感觉按横屏重新排的。

动效顺序（30fps 的帧号）：第 0–18 帧开场总览，镜头极慢地漂 → 各张卡片往四面散开，横条卡从右上飞到中间，第 33 帧落定 → 33–40 帧「Track Income」两个词先后弹出 → 定住到第 56 帧 → 横条卡放大、拖虚，冲着镜头从上方飞出去；发票卡从左下仰着进来，第 71 帧落定 → 「Manage Invoices」弹出，定住到第 90 帧 → 发票卡从右上飞走，流水卡从右边像翻页一样甩进来、过了中线再荡回来，第 107 帧落定 → 「Organize Transactions」弹出，定住到第 123 帧 → 各张卡片归位成总览，第 137 帧「Understand Business」两行先后弹出，第 148 帧以后画面完全静止。

对照：参考是竖屏的，和横屏成片没法并排。成片的总览图是 `out/03-卡片巡游-鱼眼/对照/横屏-总览图-每6帧.jpg`（每格隔 6 帧，从左到右、从上到下），参考的总览图在 `out/03-卡片巡游-鱼眼/参考总览/`，两张对着看节奏。成片是按 2 倍渲完再看过的：换场那几帧的动态模糊是顺的，贴着画面边的卡片完整、边上没有台阶。

## 适合 / 不适合

- **适合**：同一个话题的三个看点依次亮出来、最后收成一张总览——“三个数”“三个侧面”“三步”。每站一张卡：横条（带数值的比较）、单据（发票那样的版式）、清单（带正负号的流水）。
- **不适合**：每站要放一大段文字。卡片是固定版式，不自动换行：横条两到四行，清单最多五行，每一行的名字和数都要短。只是要标题的话用 01 就够。竖屏还没做。

## 用法

在库根目录（`工具/remotion模版`）跑：

```bash
python3 scripts/render.py 03                 # 默认内容（参考视频的原样）→ out/03-卡片巡游-鱼眼/默认.mp4
python3 scripts/render.py 03 示意            # 一份中文的示意内容 → out/03-卡片巡游-鱼眼/示意.mp4
python3 scripts/render.py 03 --still 45      # 只看第 45 帧的一张图，调版面时快得多
npm run studio                               # 左边挑 03，右边改参数
python3 scripts/render.py 03 出片.mp4 自己的参数.json   # 用自己写的参数
```

调内容时先把 `motionBlur` 关掉，出片快两三倍，定稿再打开。

**出片会自动按 2 倍渲、再缩回 1920×1080**（`index.ts` 里的 `renderScale = 2`，`scripts/render.py` 认这一行）。这是镜头的脾气：Chrome 做置换的时候位移是取整像素的，1 倍渲出来卡片边上有 1 像素的台阶，所以 2 倍渲完再缩回去才顺。所以这个模版出片比别的慢：180 帧默认内容渲了 40 分钟，调大并行也快不了（卡在浏览器里合成的那一个线程上）。先调内容时把 `motionBlur` 关掉、并在命令末尾加 `-- --scale 1` 先快速看一遍。手敲 remotion 命令时要自己加 `--scale 2`。Studio 里预览不受这个影响。

## 板子是怎么搭的

- **镜头**：库共用的 `src/shared/Lens.tsx`（原理和它为什么要按 2 倍渲，见库根目录 README）。它把整层内容做置换，中心不动、越靠边越往外弯，`lens` 是弯得多厉害（默认 420：画面最远的那一角往里拉 420 像素）。镜头本身不动，要“镜头飞过去”是动内容。主角落定的位置就在镜头中心下方，所以主角的边只弯一点点，和参考一样。
- **卡片**：每张卡片原大画好（`Cards.tsx`），再用一个 4×4 的矩阵摆到画面里（`space.ts`）：中心、放大、绕三个轴的转角。转角带着透视，近的一边会大一些，于是卡片的直边在大转角下本来就有点不平行，再被镜头一弯就像参考里那样。
- **每一张卡片什么时候在哪**：`layout.ts` 里每张卡片七条关键帧表（横、竖、放大、三个转角、模糊）。用的是 `src/shared/curve.ts` 的平滑曲线：它在一串关键帧里“到了一个数停住”和“折返”的地方速度正好是零，所以停着的段落不会突然起步，流水卡甩过了头再荡回来也是顺的。改 `stations` 里的帧号，这些表跟着走。
- **标题**：空格分开的词每 4 帧弹一个，每个词从 1.9 倍大、带着斜度和模糊缩到位，略微缩过头再弹回来；刚出来时外圈那层辉光特别大，随后收回。
- **动态模糊**：卡片动得快时，在前后半帧里给**这张卡**多取几个样，一个压一个地叠起来（照 02 的做法）。只有动得快的卡才叠，不动的卡、标题、光点只画一遍——换场时其实只有一进一出两张卡在动，整层一起叠的话每一份都要把所有东西重画一遍，按 2 倍渲一帧要几十秒，还会超时。景深是每张卡片按 `blur` 那条曲线自己糊，离镜头越近越糊。

`node scripts/motion.mjs 03` 量过十来个点（每张卡片的中心和一个角）：收尾归位之前有一版是 10 帧里飞两千多像素、到位前两三帧还在急刹，改成了 18 帧左右慢慢滑到位（也和参考一样，和标题弹出叠在一起）；开场散开改成了别的卡片先动、多给几帧。剩下速度变得快的地方只有两次“冲出去 / 甩进来”本来的那下加速。

## 参数

字段说明写在 `schema.ts` 的 `.describe()` 里，Studio 面板会直接显示。要点：

- **stations**：四站，每站一个标题、`at`（主角落定、标题开始弹的帧）、`until`（开始离开的帧，第四站不填）。标题里空格分开的词一个接一个弹出，要换行写 `\n`。前三站的主角落在一起定死：横条卡、发票卡、清单卡；第四站是总览。标题最长的一行按字数估出来的宽度有上限（前三站 1240 像素、第四站 720 像素），超了整个标题就缩小字号，所以长标题不会压到角上的小卡（`layout.ts` 的 `TITLE_POS`）。
- **introTravel**：开场的总览停多久，也就是从第一帧到镜头开始飞向第一张主角卡的帧数。最小 12。
- **cards.bars / cards.transactions**：标题、右上角那行灰字、每一行（名字、右边的数、名字下面的小字）。横条卡每行可以给 `bar`（0 到 1，占满格的多少），不给就没有条。清单卡每行可以给行首小圆圈里的 `icon`、底色 `tint`、数字的颜色 `tone`（`pos` 绿、`neg` 红）。
- **cards.invoice**：一张单据。左上机构名、右上的大字、单号和状态、买卖两方各三行、两个日期、明细四列和那一行、小计、税、合计。两个小标题 (`billLabel`、`fromLabel`) 也能换成中文。
- **cards.donut**：环形图，中间的数和三小块（颜色、占比）。`cards.expense`：那张带蓝色按钮的小卡。
- **lens**：镜头弯得多厉害，0 就是没有镜头。它的 `max` 是 700。
- **accent / titleColor / fontSize / motionBlur**：横条的颜色、标题的颜色和字号、带不带动态模糊。
- **durationInFrames**：成片总帧数。默认 180；第四站从第 148 帧起是完全静止的，要长要短改它就行。

`示例-示意.json` 是一份换成中文的示意内容（用的是“价格歧视”那期的框子，所有数字都写着“假设”，不是真实数据），只写了要换的项。

## 和参考不一样的地方

- **横屏没有参考**。卡片多大、总览时各卡停在哪、每站从哪个方向进来，是照竖屏那一套的感觉重新排的：参考里竖屏新卡基本都从下方来，横屏画面矮，就改成了发票卡从左下、流水卡从右边甩进来。
- **开场**：参考第 44 到 88 帧镜头扫过一张「Income Summary」折线卡，这一段没有做，横条卡直接从开场它待的右上角飞到中间。
- **默认内容是参考视频的原样**（一套记账软件的界面），只为对照，里面的名字和钱数都没有核实过。参考里那张蓝按钮的卡只露出一角，它的标题「EXPENSE TRACKER」和按钮上的字是猜的；环形图卡的图例也是照着很小的字放大的，可能认错。
- **镜头的强弱是估的**：竖屏参考里同一张卡不同时刻量出来差一倍（200 到 450 像素都有），取了 420，按横条卡落定时边上弯的那一点对过。
- **两个词弹出的间隔**：参考是 60fps 的 8 帧（等于 30fps 的 4 帧），落定用了 10 帧（5 帧）；这里是 4 帧和 7 帧，落定略慢一点。
- **景深**：参考里靠边的卡片即使不动也是虚的；这里是每张卡片按自己那条 `blur` 曲线糊，不按它离画面中心多远。
- **没做**：参考里背景的光斑跟着镜头有视差地游动，这里只做了三粒按各自关键帧表走的光点。总览里那只折线卡和蓝色的按钮卡旁边的细字没有。

## 文件

```
index.ts            对外的：画幅、组件、参数定义、默认值，还有 renderScale（出片按几倍渲）
Template.tsx        makeView：某一刻画面该是什么样（每张卡片的矩阵、光点、每个词的进度）；Template：叠采样出动态模糊、套 Lens
layout.ts           每张卡片的七条关键帧表、三粒光点的走向、镜头的漂移、标题的位置
space.ts            给一张卡片一个 pose（中心、放大、三个转角），出它的 4×4 矩阵；把它自己的一个点换算到画面坐标
Cards.tsx           四种卡片：横条、清单、发票、环形图，外加一张蓝按钮小卡
schema.ts           参数定义和默认值
示例-示意.json      换成中文的示意内容
参考/               参考视频（mp4 不进 git）和 来源.txt
```

字体只有 `Archivo Variable`（库里 `@fontsource-variable/archivo`，卡片和标题；标题用 800 字重），中文字符回落到 `Noto Sans SC`。两款都是 SIL Open Font License，登记在库的 `src/shared/fonts.ts`。画面用的是库的 `Lens`（鱼眼镜头）和 `Grain`（颗粒），不开铺底照片。
