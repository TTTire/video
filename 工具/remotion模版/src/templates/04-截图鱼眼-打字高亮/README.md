# 04-截图鱼眼-打字高亮

状态：粗做。参考视频和出处在 `参考/`。

横屏 1920×1080，60 帧（2 秒），30fps。合成 id 是 `04-截图鱼眼-打字高亮`。

一条手机「信息」通知的截图，隔着一个弯得很厉害的鱼眼镜头在拍：画面先漂一下（内容往右上方挪、缩小、带着三维的转角），字边发亮发糊，画面上有拍屏幕的横向扫描纹，四角压得很黑；正文可以逐字打出来，然后荧光黄的高亮块从左往右把关键词刷出来。

参考是 motionface 片段「鱼眼畸变效果（Fisheye + 摩尔纹 + 暗角）」`7f6a33d3-83e5-4c41-89fe-0910881e46c6`，1080×1102、30fps、60 帧（出处见 `参考/来源.txt`）。版面上的数都是照它量的，再按画面高度 ×(1080 / 1102) 换过来的。

**参考里实际是怎样的（逐帧量的，和一开始隔着总览图的印象不一样）**：

- 没有打字。第 0 帧正文四行就全在了，亮字的像素数一直是 9.3 万上下。
- 只有一块高亮：盖住第三行的「浙大」（在“支付宝“浙大通””里），第 30.5 帧起从左往右刷，第 51.5 帧刷完，之后一直在。
- 画面的动是一段漂移：第 4 帧起看得出来，第 14–16 帧最快（正文一帧挪 20 多个参考像素），第 29 帧停住，之后只剩高亮在刷。
- 镜头（拿第 0 帧的四条边界拟合的）：中心在画面 (538.5, 553)，差不多是正中；strength 698，是 reach 的 0.90。

所以模版的默认内容照参考：`typeAt` 给负数、等于不显示打字过程，一块高亮。要打字的话把 `typeAt` 设成 0 以上、每帧打几个字（`示例-示意.json` 就是这么做的）。

## 适合 / 不适合

- **适合**：把一条通知、一段聊天记录、文档里的一两句原隔着镜头亮出来，再高亮其中的关键词。正文四五行、每行十二三个汉字以内最合适；高亮可以有好几块。
- **不适合**：要让人逐字读完整一大段文字的（镜头把边上的字压弯、压小了）；竖屏（没做）。赶时间：它出片按 2 倍渲，比别的模版慢。

## 用法

在库根目录（`工具/remotion模版`）跑：

```bash
python3 scripts/render.py 04                 # 默认内容（参考视频的原样）→ out/04-截图鱼眼-打字高亮/默认.mp4
python3 scripts/render.py 04 示意            # 一份中文示意（带打字、下划线、高亮）→ out/04-截图鱼眼-打字高亮/示意.mp4
python3 scripts/render.py 04 --still 59      # 只看第 59 帧的一张图
npm run studio                               # 左边挑 04，右边改参数
python3 scripts/render.py 04 出片.mp4 自己的参数.json   # 用自己写的参数
```

调内容时先把 `motionBlur` 关掉，出片快两三倍，定稿再打开。

**出片会自动按 2 倍渲、再缩回 1920×1080**（`index.ts` 里的 `renderScale = 2`，`scripts/render.py` 认这一行）。原因和 03 一样，是镜头的脾气，见库根目录 README。这个模版的镜头特别强（strength 1000），置换面积大，60 帧出片要 20 分钟上下。

## 板子是怎么搭的

- **镜头**：库共用的 `src/shared/Lens.tsx`，中心在画面正中，`strength` 是“画面最远的那一角往里拉多少像素”（默认 1000）。镜头自己不动，画面的漂移是内容在动；置换层四边按实际要采多远逐边留白（`lensPadsFor`），比四边都留 1000 省三成多的面积。
- **内容怎么漂**：内容整体过一个透视变换（`camera.ts`，照 02 抄的）。末态是拿参考末帧顶部带下沿、气泡上沿、下沿、右沿的读数反解出来的（单位是参考像素）：绕横轴转 21.3°、绕竖轴转 26.2°（右边远、左边近）、再转 −7.4°，透视距离 2659，缩到 0.907，往右上方平移 (+206, −54)。快慢是在参考的字上钉 20 个小图块逐帧跟位移，再把平移和转角的进度合成一条曲线（`Template.tsx` 的 `Q`）：第 4 帧起步、第 14–16 帧最快、第 29 帧停住，两头都从静止起步、停成静止。
- **高亮**：每块高亮是盖在字身上的小色块，用渐变控制从左往右露出来多少；高亮的词按“去掉换行的正文”里的第一处子串找。
- **顶部那条深灰带不过置换**：它的下沿在内容里是一条水平线，模版逐列反解出这一帧它在画面上的形状，直接画成一条路径填上。这样置换区域不用一直铺到画面外很远的角落。
- **扫描纹**只画一遍、跟着正中间那个样走，不跟动态模糊一起叠样（省一半出片时间）。

`node scripts/motion.mjs 04`：跟五个点（正文上一点、气泡两个角、带下沿一点、气泡左侧一点），最快每帧 22 像素（第 16 帧，就是参考里最快的那两帧），速度一次最多变 4 像素，没有突变。

## 参数

字段说明写在 `schema.ts` 的 `.describe()` 里，Studio 面板会直接显示。要换的都在这儿：

- **正文**：`body`（写 `\n` 就在那儿断行，没写的地方排到气泡右边自动换行）、`link`（做成下划线样式的那一段，写成子串）、`highlights`（每一块：`text` 子串、`at` 开始刷的帧、`wipe` 刷完用几帧、`end` 从哪一帧起刷走，`null` 就一直留着、`color`）。`typeAt`、`charsPerFrame` 管打字。
- **截图上的其他东西**：`sender`（号码那一行）、`titleLine`、`timeLine`、`badge` 和 `badgeColor`（留成空字符串就不画）、`battery`（留成空字符串就连状态栏三个图标一起不画）。
- **镜头**：`strength`（0 到 1100）、`lensX`、`lensY`（镜头中心）、`drift`（0 到 1，漂移的量）、`driftFrom`、`driftEnd`（第几帧起、到第几帧停）。
- **拍屏幕的质感**：`glow`（字边发亮发糊）、`scanlines`（扫描纹深浅）、`vignette`（四角压黑）、`grain`，以及带、气泡、正文、小字、号码、下划线各自的 `…Color`。
- **image**：给了 `public/` 里的图片路径，就贴在气泡的位置上（按气泡的圆角裁），正文不打字。文档页截图这么用。
- **durationInFrames**、`motionBlur**。

`示例-示意.json` 是一份中文示意（“示例图书馆”的取书通知，全是编的，只为看换成中文、带上打字以后排版坏不坏），只写了要换的项。

## 和参考不一样的地方

- **横屏没有参考**：参考接近方形（1080×1102），横屏里把头像、号码、两行小字、气泡都改成对着画面中线居中，气泡宽 1860（居中，两边都露出来；参考里气泡左边被画面切掉了）。正文字号 92，比按高度等比换算（84.6）大一成——1920 宽里等比换算的字只占 4% 的宽，看着小；再大默认那四行里最长的一行就放不下了。
- **默认内容是参考视频的原样**（一条校园访客短信的截图），只为对照，里面的日期、号码、校名都没有核实过。
- **镜头的强弱**：参考在 1080×1102 里量出 strength 698；横屏的 reach 更大（1124），模版默认给了 1000，弯得和参考差不多。没有逐帧对过。
- **参考里镜头自己也在变**（中心、强度都在动）。模版按库的规矩镜头不动、只动内容，所以末帧顶带的下沿、气泡的几条边和参考最好也只对到差 20 来像素，右边的那条差得多一点（20–50 像素）。
- **漂移的末态是拟合出来的**，不是逐个读数对出来的；进度曲线合成了平移和转角两条（各用一条的话两边进度会差两三帧）。
- **质感是看着调的**：扫描纹、辉光、暗角的强度都没有量；参考里摩尔纹是斜的、有粗细变化，模版是均匀的横线。
- **字体**：参考是 iPhone 的系统字体（中文是苹方一类）。模版用 Archivo（数字和拉丁字母）加 Noto Sans SC（汉字），字宽和参考略有差别，所以断行的位置是在模版的字体下试出来的。
- **没做**：参考第 0 帧左上角露出的一小块蓝色（「52」的徽标在模版里是在的）、状态栏图标的细节；高亮刷出的快慢是匀速的，没核过参考是不是先快后慢。

对照图在库根目录的 `out/04-截图鱼眼-打字高亮/对照/对照-左参考右成片-第0-29-59帧.jpg`：参考和成片缩到一样高以后左右并排（左参考、右成片），从上到下是第 0、29、59 帧。参考是接近方形的，成片是 16:9，没法用 `pairs.py`。亲眼对过这三帧：四行断行的位置、下划线、徽标和号码的位置、第 29 帧的漂移方向（向右上方）、第 59 帧高亮盖住的词都一致；字的大小、气泡的宽窄不同（见下）。

## 文件

```
index.ts            对外的：画幅、组件、参数定义、默认值，还有 renderScale（出片按几倍渲）
Template.tsx        makeView：某一刻画面该是什么样（内容变换、打出多少字、每块高亮盖到哪、顶带的形状、probes）；Template：叠采样出动态模糊
Page.tsx            截图：头像、号码、两行小字、徽标、状态栏、气泡（正文、下划线、高亮块、辉光）、扫描纹；版面的数都在这儿
camera.ts           透视镜头，照 02 的 camera.ts 抄来的
schema.ts           参数定义和默认值
示例-示意.json      中文示意内容
参考/               参考视频（mp4 不进 git）和 来源.txt
```

字体只有两样，都是 SIL Open Font License：Archivo Variable（库的 `@fontsource-variable/archivo`）和 Noto Sans SC（`public/fonts/`），登记在库的 `src/shared/fonts.ts`。画面用的是库的 `Lens`（鱼眼镜头）和 `Grain`（颗粒），不开铺底照片。
