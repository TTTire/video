# 01-宋体标题-打字数据表

状态：已精修。参考视频和出处在 `参考/`。

粗宋体标题带倾斜、模糊进场，红色英文副标题逐字打出；可选地接一张滑入的数据表，逐字打出并点亮黄色高亮。默认 8 秒，1920×1080，30fps。合成 id 是 `01-宋体标题-打字数据表`。

这是库里第一个模版，从一段参考视频逐帧量出来复刻的（motionface 片段 `1f6419af-0fba-4b69-b76f-55bdc6196a29`，一段别人成片视频的录屏，出处见 `参考/来源.txt`）。

动效顺序：粗宋体大字带倾斜和模糊进场 → 红色英文副标题逐字打出 → 标题向上加速冲出画面 → 斜体表头的数据表从下方滑入 → 每一格按各自的节奏逐字打出（新字带色散、从下方升到位）→ 黄色高亮块从左往右展开 → 整块缓慢漂一下。全程有颗粒。

逐帧对照图在库根目录的 `out/01-宋体标题-打字数据表/对照/`，左边参考、右边本模版。

## 用法

在库根目录（`工具/remotion模版`）跑：

```bash
python3 scripts/render.py 01 片头              # 只有标题的片头，5 秒
python3 scripts/render.py 01 开场              # 标题加两行数字的表格
python3 scripts/render.py 01                   # 默认内容（参考视频的原样）
npm run studio                                # 左边挑 01，右边改参数
```

换内容有三种改法：

- 在 Studio 右侧的参数面板里直接改，立刻能看。
- 把要换的几项写进一份 json（照着 `示例-*.json` 写），出片时带上：`python3 scripts/render.py 01 出片.mp4 自己的参数.json`。没写的项自动用默认值。
- 想让某个内容成为以后每次打开的默认画面，改 `schema.ts` 里的 `defaultProps`。

## 两种用法

- **只有标题**（片头）：`rows` 留空。标题进场后停住，一直到最后，背景全程缓慢推；副标题留空就连点线一起不出现。要标题中途冲出去，填 `titleExitAt`。例子：`示例-价格歧视-片头.json`。
- **标题 + 表格**：标题冲出去，表格滑进来。例子：`示例-价格歧视开场.json`。

两份示例都取自第 11 期「价格歧视」：标题「价格歧视」，数字是那期讲稿卡数字表里的本人经历，表头按“别说”的要求写「上上周 · 《生化危机》」、不提购票平台，铺底照片是那期的图片素材 S02。

## 参数

字段说明写在 `schema.ts` 的 `.describe()` 里，Studio 面板会直接显示。要点：

- **durationInFrames**：成片总帧数。所有动效在第 130 帧前做完，往后是定住并缓慢漂移。
- **title**：分段数组，每段有自己的字号、横纵拉伸、前间距、上下错位。第一个元素是大字，其余是小字。默认值按参考里“长 / 链路 / 测试”三个大小不一的样子填的，换标题时可以都设成不拉伸。
- **titleCenter**：打开后整块标题水平居中、过宽自动缩小；长标题用它。四五个字的短标题可以不开，位置和参考一样。
- **subtitle**：红色斜体英文，逐字打出，留空就不出现。它贴着大字的底边放，不用单独调位置。
- **titleExitAt**：标题完全出画的帧。有表格时默认等于 `tableAt`；没有表格时默认不出画。
- **rows**：每行有名字、数值、是否粗体，以及表格进场后第几帧开始打；某行想和别的行快慢不同，单独填 `nameSpeed` / `valueSpeed`。
- **highlights**：每块写清表格进场后第几帧点亮、从第几行到第几行。
- **tableAt**：表格开始滑入的帧，标题会在它之前 23 帧开始退场。
- **backgroundImage**：铺底图片放 `public/t01/` 下，填相对 `public/` 的路径。文字、黄块、表格线都是正片叠底压上去的，深色照片上要调高 `wash`，否则黑字看不清。

## 和参考不一样的地方

- **默认内容是参考视频的原样**（“Kimi K3 42.0”等），只为逐帧对照用，这些数字没有核实过。
- **背景**：参考用的是原作者的机械手素材，没有拿来用。默认是素色底，换成自己的照片见 `backgroundImage`。
- **字体是近似替代**，不是原作者的那几款：中文用寒蝉锦书宋 Heavy，表头英文用 Liberation Serif Bold Italic，名字、数值、副标题用 Archivo 可变字体（粗体行字母 112%、数字 125% 宽，细体行字母 78%）。名字里出现中文时回落到思源黑体。表头的中文因此比参考更重一点。
- **没有做**参考里烧死的字幕，以及最后一帧的真人画面。
- 标题进场那一段，参考是从动画中途开始录的，模版从第 0 帧起就是同样的中途状态。

## 文件

```
index.ts            对外的三样东西：组件、参数定义、默认值
TypedTable.tsx      标题、表格，以及版面常量（坐标是参考第 104 帧和第 30 帧的屏幕坐标，文件里有注释）
motion.ts           逐帧量出来的运动曲线（进场、退场、滑入、漂移、高亮展开）
schema.ts           参数定义和默认值
示例-*.json         换内容时的参数示例
参考/               参考视频（mp4 不进 git）和 来源.txt
```

用的部件来自库的 `src/shared/`：`SplitGroup`（色散叠字）、`Typed`（逐字打出）、`Backdrop`（铺底和推镜）、`Grain`（颗粒）。字体都注册在 `src/shared/fonts.ts`：寒蝉锦书宋 Heavy、Liberation Serif Bold Italic、思源黑体 Bold / Regular，加上 npm 包 `@fontsource-variable/archivo`。四款都是 SIL Open Font License。
