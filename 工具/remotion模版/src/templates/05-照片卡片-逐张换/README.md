# 05-照片卡片-逐张换

状态：粗做。参考视频和出处在 `参考/`。

默认横屏 1920×1080，361 帧（12 秒），30fps；也能出竖屏 1080×1920。合成 id 是 `05-照片卡片-逐张换`。

一张浅灰的压纹纸上，产品图从左下升上来，两行字从右边滑进来，一条丝带从左边扫过去压在它后面；接着一拍一张照片卡片配一句短句地换过去——下一张从画面下沿升上来落定、上一张往上飞走，中间夹一次只白卡片那一块的闪白和一次硬切；最后卡片直接换成产品图，逐行出字，镜头换成大特写再出最后几行字。用几张照片加短句，讲一家公司、一个产品、一个人的几个侧面，最后收回一句总结。

参考是 motionface 片段「More than just coffee. @starbucks」`56b2315a-852c-409f-9050-3de363328d94`，一段竖屏的、别人成片的录屏（出处见 `参考/来源.txt`）。竖屏是照它复刻的；横屏没有参考，是照竖屏那一套的疏密重新排的。

## 适合 / 不适合

- **适合**：讲一家公司、一个产品、一个人的几个侧面——产品图加一两句开场，三四张照片各配一句短句，最后收回一句总结。每句短句一行：横屏不超过 20 个汉字，竖屏不超过 12 个。
- **不适合**：长句子（字是按位置摆的，不会自动排版；只有卡片上方那一行能折行）；要放真实数据的（默认内容是参考的原样，没核实过）；要原片的照片或品牌图形的（都不进模版）。

## 用法

在库根目录（`工具/remotion模版`）跑：

```bash
python3 scripts/render.py 05                         # 横屏，默认内容（参考视频的原样）→ out/05-照片卡片-逐张换/默认.mp4
python3 scripts/render.py 05 竖屏                    # 9:16，照参考排 → out/05-照片卡片-逐张换/竖屏.mp4
python3 scripts/render.py 05 示意 --still 150        # 中文示意内容，只出第 150 帧
python3 scripts/render.py 05 --out 自己的.mp4 自己的参数.json
npm run studio                                      # 左边挑 05，右边改参数；orientation 一改，画面大小跟着变
```

库正在被几个人同时改、共用入口打不起来的时候，命令里加 `--单独`（在示例名后面、`--out` 前面都行），它只打进这一个模版。

出片时间：横屏约 2 分半，竖屏约 4–6 分钟（都带着动态模糊）。先调内容时可以把 `motionBlur` 关掉，快很多，定稿再打开。

底、压纹、丝带、字都是用 HTML 和 SVG 排出来的；照片给路径，没给就画占位色块。

## 运动是怎么做顺的

照 02 的做法：

- 该动的数都走共用的 `src/shared/curve.ts`：升入、往上飞走、开场的杯子和四行字、丝带带尖都是照参考逐帧量的关键帧表，用 `curve`（速度连续的单调三次曲线）求值，拐点处不变速；落定的那头速度归零。
- 连着的几步是一口气滑过去的：卡片升上来带着短句一起动，落定前 15 帧的速度从每帧 146 像素一路顺降到 0，中间没有一格一格的顿。
- 动得快的地方带动态模糊（相当于 180° 快门）：按组（开场、每一拍、收尾各一组）看它在前后半帧里挪了多远，就叠几个样（每 4 像素一个、最多 16 个）；样不够密时再补一层模糊把台阶揉平。
- 叠样时，这一组在有的样里还不存在（它刚出现，或者正要消失）：那些空样不算进“叠几层取平均”里。算进去的话，它出现的那一帧会被摊成六成不透明，看着像先闪了一下透明的（2026-11-26 用户看出“不太对”以后查出来的：硬切换进来的卡片、闪白回来的卡片、收尾的纸杯都中过招）。
- 换拍时背景里的两组装饰形状是交叉淡化的：新的一组淡进来、旧的一组淡出去，各 8 帧。新的一组一出来就是满的话，头几帧两组叠在一起像重影，旧的一组淡完画面又突然变清楚。
- 收尾的镜头是两段：推近前那一套轻轻推近（1 → 1.3 倍）并淡出，大特写从再大 10% 的地方收回来淡入；两段都走 smootherstep（`track` 配缓动），两头速度、加速度都是零。参考第 303→304 帧是硬切，这里把接缝藏在淡出淡入里，到位的帧不变（都是第 304 帧）。

`node scripts/motion.mjs 05`（加 `竖屏` 是竖屏，加 `--表` 逐帧） 的两处大数是有意的（下面的数字是 横屏：点 1 每帧最多走 718.5 px（第 174 帧，换主角）、点 2–5 每帧最多 1476–1825 px（第 304 帧，切镜头）；去掉换主角和切镜头的那些帧，点 1 每帧最多走 89 px（画面高的 8.3%），速度一次最多变 90 px（第 176 帧，新卡片升入后猛减速的那一下，是照参考量的进场曲线），点 2–5 每帧最多 88 px、速度一次最多变 34 px。竖屏：点 1 每帧最多走 1220 px（第 174 帧）、点 2–5 每帧最多 1424–1949 px（第 304 帧）；去掉这些帧，点 1 每帧最多走 159 px（画面高的 8.3%），速度一次最多变 160 px（第 176 帧），点 2–5 每帧最多 85 px。两种画幅里，开场主角每帧最多走画面高的 3.4%（横屏 37 px、竖屏 64 px），静止段每帧不超过 2.5 px，收尾两段镜头里主角每帧不超过 31 px、速度一次最多变 11 px。）：第 174 帧（以及第 68、105、273 帧）主角换了人——从飞走的旧卡片的角换到升上来的新卡片的角，点 1 的位置是跳的，参考在第一处是硬切、后面两处是新旧卡片同屏换位；第 304 帧镜头切成大特写，点 1 跟着换到大特写的杯子上、点 2 到 5 这四个画面上的固定点也跟着跳，参考里这是硬切。新卡片升入后猛减速那一下是照参考量的：店面卡片的上沿第 105→106 帧走 213 像素、106→107 帧走 106，再往下 67、47、35……一脚刹车，然后拖着长尾。

## 参数

字段说明写在 `schema.ts` 的 `.describe()` 里，Studio 面板会直接显示。要换的东西都在这儿：

- **orientation**：`横屏`（默认，1920×1080）或 `竖屏`（1080×1920）。
- **motionBlur**：带不带动态模糊，默认带。
- **colors**：纸的中心色 / 一半处 / 四角，丝带，粗斜体字，细体字，圆环下面那行（参考里它是灰的），背景装饰形状。
- **opening**：`image` 是产品图（透明底 PNG 的 staticFile 路径，留空画占位纸杯）；`cupAt` 产品图出现的帧；`titleSmall`、`titleBig`（右对齐的两行）和 `titleAt`；`ribbonAt` 丝带出现的帧；`tagSmall`、`tagBig`（左对齐的两行）和 `tagAt`。
- **beats**：一拍一项，照顺序出现。
  - `photo` 照片的 staticFile 路径（放 `public/t05/` 下，写 `t05/xxx.jpg`），留空画占位色块，颜色取 `color`。
  - `style` 版式：`圆环`（抠图产品图、外面一圈虚线圆、上下各一行）、`小卡`（卡片小一些、偏下，短句离得近）、`大卡`（卡片占满中间，短句在上面）。
  - `transition` 怎么进来：`切入`（上一拍直接换成它，丝带接着扫）、`升入`（它从下沿升上来，上一拍同时往上飞走）、`闪白`（卡片那一块冲到很亮但不到全白，新照片在白底下透出来、两帧回到全实，位置不变）。
  - `at` 出现的帧。升入的话卡片在第 `at` 帧从下沿露头（上沿在参考的 976）、第 `at+20` 帧落定；上一拍从第 `at−16.5` 帧开始往上飞；圆环版式的那一拍飞不出画面，到第 `at` 帧直接拿掉。闪白的话第 `at−2` 帧起白底下透出这一张，第 `at−1` 帧最亮，第 `at+1` 帧回到全实。
  - `caption` 卡片上方的短句；`captionBelow` 只有圆环版式用。
- **ending**：`at` 收尾开始的帧（最后一拍的短句在这之前 9 到 4 帧淡掉，卡片只在之前 4 帧整张发虚，这一帧直接换成压纹纸和产品图；产品图之后 6 帧里长到原大小、长实）；`image` 收尾用的产品图（留空沿用开场的）；`zoomAt` 换成大特写的帧（大特写在 `zoomAt+7` 帧到位）；`near` 是推近前的几行（最多三行：第一行在产品图上方，后两行在下面），`close` 是之后的几行（最多四行）。每行有 `text`、`bold`（粗斜体大字还是细体小字）和 `at`。

`示例-竖屏.json` 只写了 `{"orientation": "竖屏"}`；`示例-示意.json` 是一份横屏的中文示意（“这是一家卖椅子的公司”，照片全是占位），换了配色，用来看换成中文以后排版坏不坏。汉字的字身是方的，叠着放的几行（开场两组、收尾两组）遇到汉字会自动改成接在上一行底下。示例里的内容都是编的，不代表任何事实。

## 和参考不一样的地方

- **默认内容是参考视频的原样**（一条星巴克品牌短片），只为逐帧对照，里面的文字没有核实过。
- **照片全是占位色块**：原片里的照片（星冰乐、门店、人群、咖啡馆、办公）是别人的素材，不进模版。占位的颜色是从参考第 84、140、200、230、260 帧里取的主色；办公那张按第 262 帧卡片的中位色调浅了一截，它和咖啡馆两张要是差不多，硬切过去就像没换照片。产品图也是占位纸杯；圆环那一拍参考里是三只抠图的杯子，模版里没给照片时是一个圆角色块（给了 `photo` 就按抠图原样摆）。
- **品牌图形都换掉了**：纸上的压纹换成“细环 + 里外几道圈 + 一圈小叶子”的中性图案；杯子上的标志换成纯色圆点（颜色取丝带的颜色）；背景里的深色装饰形状换成两头圆的长条，位置照参考量的摆，但不是参考里带尖的花瓣形状。
- **没做**：开场左上角的手写体水印（像工作室的署名，认不清是什么字）；杯子上的极小字；画面很慢的整体漂移（已并进量到的位移曲线里）；晨练那张在参考里其实是一段人在动的视频，模版只支持静态照片。
- **背景里的装饰形状怎么换**：参考是形状带着动态模糊飞出去、新的扫进来；模版没有量这个速度，用的是新旧两组交叉淡化，所以没有那种“唰”的一下。
- **2026-11-26 按用户的反馈改过一轮，又对着参考按时间轴帧号重量了一遍**（原话是“感觉不是很丝滑，而且后面的一个一个切换有点不太对”）：
  - 换卡那几帧卡片会闪成半透明（见“运动是怎么做顺的”）；
  - 硬切那一拍被当成新的一拍，丝带先消失、再从左上角重新长出来，现在接着上一拍往下扫；
  - 圆环那一拍：初版照大卡片的加速曲线飞到第 108 帧，和正在升上来的新卡片叠在一起。现在到新卡片进场的那一帧（第 105 帧）直接拿掉，参考就是这样。中间有一版改成“往上挪一点就淡掉”，是看着帧号错位的对照图定的：淡早了 6 帧、空出 7 帧才来新卡片，已经改回；
  - 背景的装饰形状换拍时交叉淡化；
  - 收尾：中间有一版改成第 270 帧硬换，实际参考是第 273 帧换，卡片之前 4 帧发虚、之后杯子再长 6 帧，已按这个改；
  - 闪白：最亮的帧一直是第 206 帧，没变；改的是最亮那一下和回来的过程——最亮时留两成卡片透出来（原来接近全白），新照片从第 205 帧起在白底下透出来、第 208 帧全回，旧短句不再压在新短句底下；
  - 圆环那一拍下面那行（just coffee）原来比参考低 50 像素，已贴回杯子下面；这一组往上飞的曲线早七成帧起步，第 94、98、100、102 帧两行字的位置和参考差在几个像素以内；飞走的时候下面那行跟着一起动（原来它不动）。
  第一轮为什么会定错：那段参考视频的画面是从第 0.167 秒才开始的（开头空了 5 帧），按“第几个解出来的帧”拼出来的对照图里，参考永远比成片快 5 帧。现在库里的量帧工具都按时间轴帧号取帧，见库 README「保存一个新模版」第 4 步。
  没改的：卡片升入和往上飞走的曲线本来就是照参考量的（竖屏版第一张卡片升入那 20 帧，上沿和参考逐帧差 0–3 像素；飞走那 12 帧下沿差 5 像素以内）。
- **升入时短句的“擦出来”**：店面那一拍参考是每帧 30 来像素、带虚边地从左往右露出来，模版用遮罩按第 109、112、116、124 帧四个点擦，前沿比参考软（右边早早有一层淡淡的影子），没逐帧对；晨练那一拍参考是一整行淡淡地一起升、一起实，模版两种用的是同一条擦出曲线。
- **卡片后面的丝带**：参考里只有卡片两头露出的小段能量到，中间藏在卡片后面。模版用一条 S 形曲线把两头连起来；第一张卡片时从右上往左下扫，之后都从左上往右下（照参考量的）。咖啡馆那一拍以后参考里丝带具体怎么转的没完全看清。
- **收尾的镜头**：参考第 303→304 帧是硬切到另一个机位的特写（能看到杯盖的顶面，杯子也更高），推近前后不是同一个画面单纯放大。模版用两段镜头加淡出淡入模拟；倍数是按杯上圆标的直径量的（约 90 → 248，2.8 倍），圆标落点 (27, 602)。占位纸杯是平面的，特写里杯子比参考矮、盖子没有透视。
- **字体**：参考的细体是一款字面很窄的细无衬线（没认出是哪款），粗斜体是一款 x 高很大的衬线斜体，收尾特写里的细体还是斜的。模版用 Archivo 可变字体（字重 260、宽度 85%）和 Liberation Serif Bold Italic：后者 x 高小、偏窄，“lifestyle / coffee / feeling”这类以小写为主的词看起来比参考矮；特写里的细体没做斜。
- **圆环下面那行**（just coffee）参考里是灰的、笔画比上面的粗斜体细，模版用同一个粗斜体配 `inkGrey` 颜色近似。
- **横屏没有参考**：照片卡片、产品图都在左边（中轴 x≈600），字在右边；丝带贴着画面下半走，免得压着字；倍数和位移按画面高度 1080/1280 换算。

## 文件

```
index.ts            对外的五样东西：默认画幅、按参数定画幅（sizeForProps）、组件、参数定义、默认值
Template.tsx        makeView：某一刻画面该是什么样（哪几拍在场上、升降、丝带、闪白、收尾的两段镜头）；Template：按组叠采样出动态模糊
layout.ts           两套版面（Layout）：竖屏的数全是参考坐标乘 1.5，每一处注明量自第几帧；横屏是重新排的
view.ts             “某一刻画面该是什么样”的类型，toScreen 把世界坐标换到画面上
Page.tsx            画：纸和压纹、装饰形状、丝带、占位纸杯和卡片、字；每一拍的卡片、收尾的字
schema.ts           参数定义和默认值
示例-竖屏.json      切到竖屏的示例
示例-示意.json      横屏的中文示意内容
参考/               参考视频（mp4 不进 git）和 来源.txt
```

字体都注册在库的 `src/shared/fonts.ts`：Archivo 可变字体（npm 包 `@fontsource-variable/archivo`，细体行，用了字重和宽度两个轴），`public/fonts/` 里的 Liberation Serif Bold Italic（粗斜体行）和 Noto Sans SC（中文字符回落到这里；粗斜体行里的汉字由浏览器合成斜体）。三款都是 SIL Open Font License。画面用的是库的 `Grain`（颗粒），不开铺底照片。
