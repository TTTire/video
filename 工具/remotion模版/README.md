# Remotion 模版库

`工具/remotion模版` 整个是一个 Remotion 工程，里面的动效都是从一段参考视频逐帧量出来复刻的。每个模版是 `src/templates/` 下的一个文件夹，合成 id 就是文件夹名。换内容只改参数，不用动代码。

## 用哪个模版

| 文件夹 | 它是什么 | 适合 | 不适合 | 状态 |
|---|---|---|---|---|
| [01-宋体标题-打字数据表](src/templates/01-宋体标题-打字数据表/) | 粗宋体标题带倾斜、模糊进场，红色英文副标题逐字打出。可接一张滑入的数据表：逐字打出，黄色高亮从左往右展开；行留空就只有标题 | 每期的片头（只用标题）。有 2 到 4 行短数字的对比：价格、比例、排名，而且反差本身就是钩子 | 没有数字可列的开头。值是长句。数字要先交代口径才看得懂的 | 已精修 |
| [02-榜单排名攀升](src/templates/02-榜单排名攀升/) | 默认横屏 1920×1080，可切竖屏。一张榜单网页斜着怼到镜头前，高亮的一行从榜单底部往上爬、越过别人，分数往上数、长进度条，闪白后拉远露出整个榜单 | “谁排到了第几”的揭晓：某家、某个模型、某款产品名次上升。榜单八到十一行 | 排名下降。行数和默认差很多。这一期要放真实数据的，数字得自己核 | 粗做 |
| [03-卡片巡游-鱼眼](src/templates/03-卡片巡游-鱼眼/) | 待补 | 待补 | 待补 | 粗做 |
| [04-截图鱼眼-打字高亮](src/templates/04-截图鱼眼-打字高亮/) | 待补 | 待补 | 待补 | 粗做 |
| [05-照片卡片-逐张换](src/templates/05-照片卡片-逐张换/) | 待补 | 待补 | 待补 | 粗做 |
| [06-AI输入框-打字发送](src/templates/06-AI输入框-打字发送/) | 待补 | 待补 | 待补 | 粗做 |
| 待补充 | | | | |

状态的意思：**粗做**是结构完整、关键帧号对上了，版面没有逐字校准；**已精修**是逐帧和参考对过的。粗做的模版用之前先看一眼它 `out/` 里的对照图。

选的时候看开头是靠什么进场的。靠一条新闻、一个反常现象、别人的话进场的，用标题做片头就够了；只有当“这几个数放在一起”本身就是看点时，才把表格也用上。

01 这类能铺照片的模版，是深色字压在浅底上；铺深色照片时要把压白的参数调高，照片才不抢字。

## 怎么用

都在本文件夹里跑（Windows 把 `python3` 换成 `python`）：

```bash
npm install                 # 第一次用。渲染时如果提示缺浏览器：npx remotion browser ensure
npm run studio              # 左边列出所有模版，挑一个，右边改参数、预览
python3 scripts/render.py   # 列出所有模版和各自的示例
python3 scripts/render.py 01                  # 用默认内容出片 → out/01-宋体标题-打字数据表/默认.mp4
python3 scripts/render.py 01 片头             # 用某个示例出片 → out/01-宋体标题-打字数据表/价格歧视-片头.mp4
python3 scripts/render.py 01 片头 --still 149 # 只出第 149 帧的一张图
python3 scripts/render.py 01 --out 目标.mp4 自己的参数.json   # 用自己写的参数出片
python3 scripts/render.py 02 竖屏             # 02 默认横屏，这样出竖屏
npm run render -- 01 片头    # 和上面等价：npm run render 后面跟的参数原样交给 scripts/render.py
```

- 每个模版文件夹里有自己的 `README.md`（参数说明、和参考的差异）和 `示例-*.json`（换内容时照着改）。参数只写要换的项，没写的自动用默认值。
- 想让某个内容成为 Studio 一打开就有的默认画面，改那个模版 `schema.ts` 里的 `defaultProps`。
- 成片都在 `out/<模版文件夹>/` 里，不进 git。

## 文件怎么摆

```
工具/remotion模版/
├── README.md                本文件
├── package.json 等          整个库共用的一份依赖
├── scripts/
│   ├── new_template.py      建新模版骨架并登记
│   ├── fetch_reference.py   从 motionface 的提示词里下载参考视频
│   ├── render.py            按编号出片、出单帧
│   └── measure/             量帧小工具
├── public/
│   ├── fonts/               所有模版共用的开源字体
│   └── t01/ …               编号 01 等模版自己的素材（示例铺底图）
├── 参考候选/                下载下来、还没决定做不做的参考视频（不进 git）
├── src/
│   ├── index.ts、Root.tsx    入口；Root.tsx 按标记块登记所有模版
│   ├── shared/              共用部件
│   └── templates/01-… /     每个模版一个文件夹
│       ├── index.ts         对外的几样东西：画幅、组件、参数定义、默认值
│       ├── Template.tsx、schema.ts、motion.ts
│       ├── README.md、示例-*.json
│       └── 参考/            参考视频（mp4 不进 git）和 来源.txt
└── out/01-… /               成片和 对照/
```

`src/shared/` 里的共用部件：`textParts.tsx`（`SplitGroup` 带蓝红色散的叠字、`Typed` 逐字打出）、`Backdrop.tsx`（铺底和推镜）、`Grain.tsx`（颗粒）、`fonts.ts`（字体注册）、`fontMetrics.ts`（字体度量）、`curve.ts`（`track`：关键帧之间走速度连续的平滑曲线）。

## 每个模版都守的约定

- 合成 id 就是文件夹名，所以名字只能用字母、数字、连字符和汉字，不能有空格、下划线、点；编号从 01 起两位。
- 30fps，时长用 `durationInFrames` 参数控制。画幅默认 1920×1080，竖屏的那种建骨架时用 `--尺寸 1080x1920`，之后在它自己的 `index.ts` 里改 `width`、`height`。一个模版要横竖都能出的话，把画幅也做成参数：`index.ts` 里照 02 导出一个 `sizeForProps`，合成大小就跟着参数变（登记行里已经带了 `size: sizeOf(…)`）。Remotion 版本和 `工具/video-render` 对齐（4.0.530）；浏览器用 Remotion 自带的 chrome-headless-shell，不要换成本机 Chrome（会出花屏帧）。
- 模版文件夹里不要再放 `package.json`。`Root.tsx` 里两处成对的标记注释由脚本维护，别删。
- 文字、时间点、高亮、铺底图片都做成参数；版面数值注明是参考第几帧的屏幕坐标。
- 默认内容是参考视频的原样，只为逐帧对照，里面的数字没有核实过。真实的内容放 `示例-*.json`，用频道自己核实过的东西，并在模版 README 里写明出处。
- 字体只用开源可再分发的，文件放 `public/fonts/`（名字别撞），在 `src/shared/fonts.ts` 注册，模版 README 写明用了哪几款。

## 保存一个新模版

模版会很多，所以先粗做一批、再精修被选中的。每一步的命令都在本文件夹里跑。

1. **拿参考视频**：motionface 的“复刻提示词”粘到一个 txt 里（放下载文件夹），然后 `python3 scripts/fetch_reference.py <那个txt>`。它只下载视频，先放进 `参考候选/<片段编号前 8 位>/`；提示词里建 GitHub 仓库、调接口那些内容和凭证不碰、不打印、不保存。视频链接一小时内有效，过期就回片段页面右键重新复制一份。手上已经有视频的话，新建一个候选文件夹直接放进去也行。
2. **先看值不值得做**：`python3 scripts/measure/frames.py 参考候选/xxxxxxxx/参考视频.mp4 --every 2` 把整段拼成总览图。参考多半是别人成片的录屏：带烧录字幕、可能切到真人、素材是原作者的，这些都不进模版。真人出镜、靠原作者素材、要三维粒子才成立的，不做。不做的在那个候选文件夹的 `来源.txt` 里写一句原因，留着。
3. **建骨架**：`python3 scripts/new_template.py 02-名称 --候选 参考候选/xxxxxxxx --尺寸 宽x高`。会生成一个能直接渲染的最小模版，把参考视频挪进它的 `参考/`，并在 `Root.tsx` 和本文件的表里登记好。
4. **粗做，20–30 分钟**：结构完整，关键帧号对上（进场、退场、揭晓相差 3 帧以内），字体用库里现有的近似。默认内容写成参考原样，渲一条成片，用 `pairs.py` 拼对照图放进 `out/02-名称/对照/`。模版 README 的状态写“粗做”，本文件的表里把“适合、不适合”填上。做的时候：
   - 动手前用 `crops.py` 把几个关键帧按原尺寸裁出来，先读懂结构：谁在动、按什么顺序、每次变化在第几帧。别在缩小的总览图里认字，行和行挨得近时特别容易认串。
   - 能量的不目测。主角的位置、角度、大小用 `band.py`、`boxes.py`、`track.py` 逐帧量成关键帧表，让代码照表求值；渲完再用同一个量法和参考并排量一遍。
   - 页面被镜头放大时，模糊这类滤镜是放大之前算的，要除以放大倍数才是画面上看到的那个数。
   - 动作要顺，三样都做：关键帧之间用 `curve.ts` 的 `track`（速度连续，别拿很多段直线拼）；连着的几步做成一口气滑过去，别一格一格顿；动得快的地方带动态模糊（在前后半帧里多采几个样叠起来）。写法都在 `02-榜单排名攀升/Template.tsx` 里。做完跑一下 `node scripts/motion.mjs <编号>`：让代码报出逐帧位置，算每帧的速度有没有突变。它只能查导出了 `makeView` 的模版（照 02 的写法，把“某一刻画面该是什么样”写成一个导出的函数）。别从成片画面反推，遮挡和模糊会让量出来的抖动大半是噪声。
5. **用户看一遍**，挑出要常用的。
6. **精修，每个再加 40–60 分钟，只做被挑中的**：对照参考逐字量位置，换更接近的字体，逐帧比运动轨迹和每个字出现的帧；再拿频道自己的内容出一版，确认改内容后字体、位置、时长都没问题。状态改“已精修”。

量帧小工具在 `scripts/measure/`，要 python3 的 numpy 和 ffmpeg：

| 工具 | 干什么 | 例子 |
|---|---|---|
| `frames.py` | 把一段视频抽帧拼成总览图，先看整段在讲什么 | `python3 scripts/measure/frames.py src/templates/02-名称/参考/参考视频.mp4 --every 2` |
| `pairs.py` | 把参考和自己的成片按同样的帧左右并排拼成对照图 | `python3 scripts/measure/pairs.py src/templates/02-名称/参考/参考视频.mp4 out/02-名称/默认.mp4 --frames 3,9,40,50` |
| `boxes.py` | 量一帧里几块区域的外框，参考和自己的并排量、给差值 | `python3 scripts/measure/boxes.py src/templates/02-名称/参考/参考视频.mp4 --frame 104 --对比 out/02-名称/默认.mp4 --对比帧 104 --区域 表头:380,255,710,145` |
| `track.py` | 逐帧量位置和像素数，找动作的帧号、比两条片子的轨迹 | `python3 scripts/measure/track.py src/templates/02-名称/参考/参考视频.mp4 --到 30 --色 red --指标 top,left --区域 副标题:250,0,1050,900 --变化才列` |
| `band.py` | 逐帧量一条有颜色的带的倾角和位置；带 `--对比` 用同一个量法量自己的成片，并排给差值 | `python3 scripts/measure/band.py src/templates/02-名称/参考/参考视频.mp4 16 152 34 --对比 out/02-名称/默认.mp4` |
| `crops.py` | 按原尺寸裁几帧的同一块窗口摞起来，参考和自己的上下紧挨着；认字、比字的大小用 | `python3 scripts/measure/crops.py src/templates/02-名称/参考/参考视频.mp4 out/02-名称/默认.mp4 --out /tmp/比.jpg --window 0,500,1080,700 --frames 44,60` |
| `../motion.mjs` | 让模版的代码报出每一帧几个点的位置，汇总每帧走了多远、速度变了多少；查动作连不连续（要 node，模版要导出 `makeView`） | `node scripts/motion.mjs 02 --表 --每 4` |

## 注意

- 整个库共用一份依赖，磁盘上约 600MB；每多一个模版只多源码和字体。`node_modules/.cache` 是打包缓存，会随使用长回来，随时可以删。
- 版面位置是按各自的画幅写死的像素值，文字特别长时不会自动换行。
- `public/fonts/` 和 `public/tNN/` 里的东西会跟着进 git，照片能小就小。
