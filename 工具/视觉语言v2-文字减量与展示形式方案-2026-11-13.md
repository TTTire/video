# 视觉语言 v2：文字减量与展示形式方案（2026-11-13 定稿）

> 定位：这是**第二版计划**，只管画面表达层（写稿叠字 + 渲染形式），与第一版《视频剪辑管线优化方案》无关，两份文档独立。方向来自用户确认：画面文字偏多，减字 + 换展示形式；证据类内容换成「原文档展示」（文件高亮风格）。图片素材量允许增加。

## 0. 现状与目标

- **现状实测（AI05）**：29 个场景平均约 3 个文字元素/场景，峰值 7 个（配给、AOL 两场）；字几乎从不离开画面。
- **目标**：字变少、形式变多——证据换原文档、数字换图表/实物、罗列换卡片墙、复述口播的字删掉。
- **不变的红线**：质量不下降；事实底线不松（引用必须可回溯到事实核对）；出镜层照旧。

## 1. 减字三原则（调研归纳）

1. **文字只当标签**：机构名、数字、一个词可以上屏；**句子让口播说**（回形针式，黑底白线图标 + 标签字）。
2. **信息分两层**：画面只放「可辨认的最小证据」，完整标题 + 链接放发布文案/事实核对（掘金《短视频资料来源怎么标注》方法论）。来源要直接支持那一句话，截图裁切不改原意。
3. **同一视觉元素反复登场**：公司/人物做成徽章全片复用；同一张信息图多次出现、每次状态变化（变灰/盖章/变色）——靠重复建立视觉词汇，不靠每次重新写字（小lin说式）。

## 2. 按文字类型逐类替换（核心表）

| 现在的字 | AI05 例子 | v2 换成 | 素材增量 |
|---|---|---|---|
| 证据/引用 | 客服原话卡、道歉信要点卡、报道要点 | **document 元素**：原文页滑入 + 黄底高亮 + 聚焦放大 + 画面短标签（机构/资料名/年份）；完整链接留发布文案 | 原文页截图 2–4 张/期 |
| 数字 | 「1908 元」「19.95 美元/月」写在句子里 | odometer / fill / units 大数字 | 部分需实物小图 |
| 罗列 | 「限额 · 排队 · 停卖 · 少给」一行字 | **tagwall 四宫格大卡**（≥780 宽、h 档大字） | 图标（跨期复用） |
| 层级/结构 | 用文字描述阶层 | **pyramid 层级图**（逐层弹出 + 图标） | 图标 |
| 因果链 | stack 三张 + notch 卡 + 第四行字 | 只留 stack 三张，其余删 | — |
| 人名/公司 | 每场重复写名字 | **徽章**（圆形 + 图标/字卡）反复登场 | 图标 |
| 对比 | 两张并排 tab 卡（已克制） | 保留，颜色语义化（teal/coral） | — |
| 复述口播/疑问句 | 「割韭菜吧？」「那它拿什么管住你？」 | **直接删**，出镜 + 口播扛 | — |

## 3. 素材预算（用户已确认可加量）

| 素材 | 每期增量 | 说明 |
|---|---|---|
| 原文页截图（document 用） | +2–4 张 | 论文页/报道页/公告页截图。**分工：这是资料活不是出图活**，由写稿侧从事实核对来源截取、裁掉水印/无关区，用户不负责 |
| 底图 S 系列 | 基本不变 | document/tagwall 场景不需要底图（黑底），可能反而省 |
| 卡内小图/实物图 | +0–4 张 | units 变体如需实物（钞票堆等），可即梦出图或矢量 |
| 图标 | 一次投入 | 走 `工具/图标库/`，跨期复用（用户找，规格见 document-highlight 设计 §7）。**具体清单见下** |

### 图标清单（第二批依赖，要这些）

图标的作用：让画面用「图形」代替句子表达语义——tagwall 每张卡配一个图标、pyramid 每层配一个图标、徽章 = 图标 + 名字。全部**单色线条风**（stroke 1.5–2px、圆角统一、透明底、无文字、可商用、SVG 能改色），一组约 25–35 个。

| 组 | 图标 | 用在哪 |
|---|---|---|
| 钱与市场 | 硬币、钞票、钱包、购物车、商店、银行大楼、天平、价格标签 | 徽章、pyramid 财富层、tagwall、graph 节点 |
| 人 | 单人、人群、排队、握手、喇叭 | 社会阶层、排队场景 |
| 生产与算力 | 工厂、齿轮、芯片、服务器机架、灯泡、电池 | AI 徽章、算力层、供给侧 |
| 规则与限制 | 锁、沙漏、禁止、放大镜、红绿灯 | tagwall「限额/排队/停卖/少给」、政策场景 |
| 结构与变化 | 房子、写字楼、网状连线、上/下/循环箭头、金字塔层块 | 因果、涨跌、网络效应、层级 |

**来源（可直接下载单个 SVG）**：Lucide（ISC）、Tabler Icons（MIT）、Phosphor（MIT）、Feather（MIT）——都是免费商用。挑好丢进 `工具/图标库/` 即可，实现阶段配 import 脚本统一入库改色。

估算：每期图片素材约 19 张 → 23–26 张，可接受。

## 4. 配套改动（写稿层 / 渲染层 / 校验层）

**写稿层（broll SKILL + 讲稿卡规范）**
- 叠字规则改为**按类型配字**：证据、数字、结论才上字；讲述性要点不上字
- 「禁止 8 秒无字」改为「**每章留 1–2 处呼吸段**」（无字 + 底图缓推 + 出镜，3–5 秒）
- 分场景表的叠字列允许写形式名：`document` / `tagwall` / `pyramid` / `units` / 徽章
- 画面短标签规范：证据场景挂「机构/资料名/年份」，与事实核对条目号对应

**渲染层**：document、pageflip（硬翻）、pyramid、tagwall、徽章 skin、units 变体——设计见 [references/document-highlight.md](工具/video-broll-maker/references/document-highlight.md)，挂第一版方案阶段 5，实现时与本计划合并执行。

**校验层**
- 同屏文字元素 ≤ 4（warn 级）
- document 引用必须有 fact 号且存在于事实核对（已设计）
- 呼吸段检查：每章至少 1 处（warn 级，替代原「8 秒无字」禁令）
