# 补充音效清单

放进这个文件夹（`工具/音效库/`），**文件名里带上类型词**（英文），再在 `工具/video-render` 下跑 `python scripts/import_sfx.py` 就会自动裁静音、统一响度、进工程。
同一类型多个版本会轮流用，所以**同类多放几个、音色略有差别**最有用。

格式：mp3 / wav 都行，单声道双声道都行。找素材：Pixabay、Freesound、Mixkit、Zapsplat（都免费可商用，Freesound 注意选 CC0）。

## 一、现有类型，数量不够的（优先补）

一期视频里 pop 响 40 多次、impact 15 次左右，只有 2–3 个版本会听出重复。

| 类型词 | 现有 | 补几个 | 要什么样的 | 命名示例 |
|---|---|---|---|---|
| `pop` | 3 | **+3** | 很轻的气泡 / 软弹出音，0.3 秒内，音高一个高一个低一个闷 | `pop-高.mp3` `pop-低.mp3` `pop-闷.mp3` |
| `impact` | 2 | **+3** | 1 个低沉闷击（电影预告那种 thud），1 个短脆的硬击（文字砸下来），1 个带一点金属尾音 | `impact-闷.mp3` `impact-脆.mp3` `impact-金属.mp3` |
| `swipe` | 2 | +2 | 快速滑过的布料 / 纸张 / 空气声，用在划掉、横向切换，0.5 秒 | `swipe-纸.mp3` `swipe-布.mp3` |
| `tick` | 1 | **+2** | 1 个秒针走动 loop（3 秒以上），1 个单声机械咔哒 | `tick-秒针.mp3` `tick-咔哒.mp3` |
| `ding` | 2 | +1 | 很柔的一声叮（提示"对了"），不要太像微信提示音 | `ding-柔.mp3` |
| `cash` | 1 | +1 | 现有的是收银机，补一个硬币落下 / 钱点数 | `cash-硬币.mp3` |
| `error` | 1 | +1 | 低沉的"嗡-"否定音，比现在的更克制，不要游戏感 | `error-低.mp3` |
| `whoosh` | 3 | +1 | 很低频、慢的推进感 whoosh（照片缓推用），1 秒 | `whoosh-低慢.mp3` |

## 二、环境声（每期场景不同，这是最缺的）

现在只有 1 个通用环境声。写实照片风格下，开场和金句段都会铺一层环境声，和画面对不上会很出戏。
每个 20–60 秒即可，不要有明显的人声说话内容。命名 `ambience-场景.mp3`，代码里可以指定场景词。

| 命名 | 内容 | 用在 |
|---|---|---|
| `ambience-奶茶店.mp3` | 店内：冰块落杯、封口机"咔-嗤"、点单提示音、远处街声 | 第 6 期这类门店场景 |
| `ambience-街道夜晚.mp3` | 夜晚街道、远处车流、偶尔脚步 | 外景、排队、结尾氛围 |
| `ambience-森林.mp3` | 风过树叶、鸟叫、远处木头声 | 伐木 / 自然类比 |
| `ambience-办公室.mp3` | 键盘、空调低鸣、偶尔椅子声 | 职场 / AI 类选题 |
| `ambience-商场.mp3` | 商场混响、远处人声嗡嗡（听不清内容）、电梯提示 | 第 7 期奢侈品排队这类 |
| `ambience-厨房.mp3` | 餐厅后厨：炒锅、盘子、出餐铃 | 外卖 / 餐饮选题 |
| `ambience-雨.mp3` | 中雨打在雨棚 / 窗上 | 下雨天外卖这类 |
| `ambience-咖啡馆.mp3` | 安静咖啡馆：杯碟、磨豆机远处、低语 | 讲解段落的安静底 |

以后每期在发布清单的「画面与素材清单」里如果写了需要的环境声，按同样方式补一个即可。

## 三、新增类型（现在没有，加了以后代码会自动用上）

| 类型词 | 要什么样的 | 用在哪 |
|---|---|---|
| `stamp` | 印章 / 橡皮章砸在纸上，"啪"短促带一点纸的闷响，0.4 秒 | 「边际报酬递减」这种盖章式关键词（现在借用 impact） |
| `page` | 翻一页纸 / 纸张抖动 | 章节卡、表格出现（现在借用 flip） |
| `click` | 机械开关 / 相机快门以外的"咔" | 时钟出现、数字定格 |
| `drop` | 一个物件落在桌面上（硬币、杯子、木块） | 数字一个个掉下来的那一排 |
| `bell` | 店门风铃 / 柜台叫号铃 | 门店场景、"队伍散了" |
| `crowd` | 人群嘈杂短片段（3–5 秒，听不清内容） | 排队、忙乱 |
| `machine` | 小型机器运转 3–5 秒 loop（封口机 / 打印机 / 传送带） | "哪台机器一直在响" 这种瓶颈段 |

## 四、不用补的

whoosh、riser、flip、notify、boom、shutter、typing 现有数量够用。

---

补完后在 `工具/video-render` 下运行：

```bash
python scripts/import_sfx.py
```

输出会列出每类有几个；"未识别类型、已跳过"里出现的文件说明文件名没带类型词，改名重跑即可。
