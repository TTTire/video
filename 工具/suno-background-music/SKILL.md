# Suno 背景音乐

为一条已经完成的认知讲解视频提炼一条整体配乐线：让音乐托住旁白、主场景与情绪变化，而不是替每一句话配音效或另讲一个故事。

## 何时使用

- 在完整口播逐字稿已经确定后使用。若任务同时包含写新稿或改稿，先遵守工作区根目录 `AGENTS.md` 的写稿与三件套规则；写稿相关内容还要先读 `模板/三重张力五杠杆写稿流程.md`。
- 默认把结果加入既有 `选题名-发布清单.md`，不新建第四个固定交付文件，也不生成分镜脚本。
- 若用户只要求一段 Prompt 或明确要求不改文件，只交付 Prompt，不改现有发布清单。

## 先提炼什么

阅读完整口播稿和已有发布清单；若可用，也参考其中的时长、画面方向、开场环境声和结尾画面。剪映版只用于核对口播节奏，不作为判断情绪的主要依据。

先用很短的中文归纳以下信息：

- **主场景与物件**：观众在前 30 秒能看见或想象到的一个画面。
- **唯一反转**：这条视频想让观众改掉的表层理解，以及落下来的新判断。
- **情绪弧线**：开头的张力、解释段的推进、证据或顿悟处的抬升、结尾的余味。
- **声音边界**：旁白优先；保留哪些环境声或动作声；哪些情绪会误伤主题。

一条稿只选一个贯穿的音乐母题和一条宏观情绪弧线。不要把每个例子、每个章节或每句话硬拆成不同曲风。

如果只有标题或提纲，没有完整稿，仍可给出临时方向，但要明确写出所依据的假设；完整稿确定后应按真实场景重新生成。

## 写 Prompt 的原则

默认生成 **一段可直接粘贴到 Suno 的英文 Prompt**。它应自然包含：

1. `Instrumental` 和视频的核心情境或心理张力；
2. 有辨识度的音乐材质、节奏或乐器，而不是只堆“emotional”“cinematic”等形容词；
3. 与本期情绪弧线一致的整体编曲走向，而不是逐句或逐章换曲；
4. 适合旁白的空间：克制的中频、不过分抢戏的旋律、可平滑淡出或循环的尾部；
5. 与本期不相容的元素，例如 `no vocals, no vocal chops, no intrusive lead melody, no abrupt EDM drop`。对知识讲解视频通常也避免泛企业宣传片式的励志高潮。

根据内容选择声音，不要把所有主题都写成电子史诗：

- AI、选择、信息过载或不确定性，常适合克制的模拟合成器脉冲、玻璃质感、零碎钢琴与低饱和电子纹理。
- 日常消费、经济判断或温和顿悟，常适合温暖钢琴、木质敲击、轻微低频律动与少量环境质感。
- 风险、误判、稀缺或悬念，常适合低频模拟贝斯、闷拍、过滤合成器与逐渐收紧的节奏。
- 历史、人性或回望型主题，常适合毛毡钢琴、细弦乐、呼吸感纹理与更少的节拍。

这些是选材方向，不是固定配方。只有节拍速度确实会影响气质时才写 BPM；不要为了看起来专业而硬填参数。不要要求模仿在世音乐人、具体歌曲或可辨认的艺人风格，改用流派、音色、节奏和编曲描述。

## 默认交付格式

在发布清单的“画面方向”之后，新增以下小节：

```markdown
### 背景音乐（Suno）

**音乐定位：** [一句中文，点明主场景、核心张力和旁白优先]

**情绪弧线：** [开场] → [中段] → [顿悟/证据处] → [结尾]

**Suno Prompt（直接粘贴）：**

> [一段英文 Instrumental Prompt]
```

默认交付只包含音乐定位、情绪弧线和这一段 Prompt，避免把选择负担或逐句配乐表丢回给用户。只有用户明确需要剪辑衔接时，才额外补充音乐何时进入、何处让位给环境声、怎样淡出的简短建议。需要备选时，备选必须代表清晰不同的叙事取向，而不是换几个同义形容词。

## 交付前检查

- Prompt 是否来自真实主场景、核心反转与结尾，而不只是标题里的关键词？
- 是否是无歌词、旁白友好、不会在解释段抢走注意力的配乐？
- 是否有可感的编曲推进，但没有逐句换风格、突兀落差或广告片式高潮？
- 是否把可直接复制的一整段英文 Prompt 单独标清？
- 若 Suno 界面提供 `Instrumental` 开关，是否提醒用户开启？

只交付 Prompt 与剪辑建议，不声称尚未生成或试听的音乐一定合适。用户生成后若要复盘，应拿音频分别对照开头 30 秒、人声最密集的解释段和结尾余味，再针对掩盖人声、情绪跑偏或循环生硬的问题迭代 Prompt。
