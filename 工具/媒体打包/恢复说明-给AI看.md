# 媒体包恢复说明（给 AI 看）

这个包里是「视频选题」仓库的全部音视频文件，比如样片、剪辑片段、音效库、配音和渲染产物。这些文件太大，被 `.gitignore` 忽略了，不在 git 里，所以单独打包搬运。

## 包里有什么

| 文件 | 作用 |
|---|---|
| `manifest.json` | 每个文件的原始相对路径 `path`，以及大小、sha256 和修改时间。内容重复的文件用 `same_as` 指向另一份，只存了一次 |
| `files/` | 实际文件，目录结构和仓库完全一致 |
| `restore.py` | 恢复脚本 |

`path` 都是相对于**「视频选题」仓库根目录**（有 `AGENTS.md` 的那一层）的路径。打包时这个目录在 `~/Documents/工程队/视频选题`，换了电脑以后可能不一样，先确认实际位置。

## 恢复步骤（AI 照做）

1. 找到用户电脑上「视频选题」仓库的根目录（含 `AGENTS.md`）。没有的话，先 `git clone` 这个仓库，或者问用户放在哪里。
2. 先预演，确认不会出问题：
   ```bash
   python3 restore.py "<仓库根目录>"
   ```
3. 把预演结果告诉用户：要复制几个文件，有几个已经存在且相同，有几个冲突。
4. 用户同意以后，真正执行：
   ```bash
   python3 restore.py "<仓库根目录>" --apply
   ```
   每个文件复制完都会用 sha256 校验。
5. 遇到「冲突」（目标位置已经有同名文件，但内容不同），默认跳过。先问用户要保留哪一份，确认要用包里的覆盖时再加 `--force`。
6. 恢复完成后，在仓库里运行 `git status`，确认没有音视频文件被列为待提交。它们都应该被 `.gitignore` 忽略。

## 在 Windows 上恢复

- 命令里的 `python3` 换成 `python` 或 `py`。如果没装 Python，先安装 3.8 或更高版本；也可以直接用下面「不用脚本的话」的方法。
- 路径要加引号，比如 `py restore.py "D:\工程队\视频选题" --apply`。
- 解压可以用系统自带的功能或 7-Zip。zip 里的中文文件名已经按 UTF-8 编码；如果解压后文件名还是乱码，就换 7-Zip 重新解压。
- 脚本恢复完成后，所有文件都会用 sha256 校验，用户不用再手动核对。

## 不用脚本的话

把 `files/` 里的内容整体合并复制到仓库根目录就行，目录结构是对应的。`same_as` 表示这个文件和另一份内容一样，复制一份到它的 `path` 就行；不复制也不影响剪辑，只影响渲染工程 `工具/video-render/out/` 里的产物。
