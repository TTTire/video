# 像素呼吸本人的口吻（从随记里归纳）

> 来源：随记原文（路径见 SKILL.md 开头的表），2026-09-07 ~ 11-04，新的在最上面。09-07 ~ 10-15 和 10-21 前半是手打的；10-21 后半、10-28、11-04 是语音口述转出来的，最接近他说话的样子，里面的错字是识别错误（多么态 = 多模态，大圆模型 = 大语言模型，羽翼 = 语义），不是口癖。同目录下的“听后记”“公众号版”和 `02-资料源/05-个人随记/` 是 AI 整理过的，不作为口吻依据。
> 用法：写稿前读这份，再读随记最上面最新的一篇；写完逐条对照“五、讲稿卡自检”。
>
> **例句只用来体会语气，不是造句模板。** 下面每一条引文都是真事，但把随记里的现场连句子一起搬进开头，就会变成一整套通用开头（“早上……照常一边……一边……”）。规则是：借它的**姿态和说法**（坦白、翻译、类比、多说一句、其实 / 比如 / 那么……呢），不把它的**现场**搬进开头。每期开头先换入口，见 SKILL.md 的「开头别复读」。

## 一、姿态：我在弄懂这件事

随记的标题叫“记录我在尝试理解世界的过程和想法”。每篇都是同一个走法：

我去听了 / 看了什么 → 对方说了什么（转述，带数字）→ 我的理解是（换成人话，配一个身边的例子）→ 这里我想多说一句 / 我有一些不一样的看法 → 这块我也不确定，留给大家 → 我接下来要去做的事。

他不是懂行的人来纠正你，是一个正在弄懂的人，把弄懂的过程讲给你听。可信度来自坦白和具体，不来自权威腔。讲稿三章照这个走，见 SKILL.md「结构」。

11-04 一篇就是完整的样子：先交代谁讲的、自己听得怎么样（“这次课程对我的感受有限，不过在下半部分明显感到有 aha moment，听我跟你们娓娓道来”）→ 老师的数字 → 用烧水壶、桌边的杯子讲清四个概念 → 借一句“三思而后行”→ 自己的不同看法（照片只是这一帧的过去式）→ 留一个问题。

## 二、说话方式

浓度接近随记口述原样（2026-11 本人定的）。随记口述三篇每千字：其实 10、比如 3、那么 / 呢 6、我觉得 / 我认为 1、大家 / 你们 2、哈 / 啊 / 吧 2；改之前的 AI06 讲稿卡这几样几乎全是 0。卡上写成什么样，他录的时候基本照着念：AI06 实录里“那么……呢”是他自己加的（卡上每千字 0.8，实录 5.0），“其实 / 比如 / 我觉得”卡上没有，他录的时候也几乎没说。所以口吻要写进卡里。

1. **顺着讲的长句**。一句话顺着往下走，用“其实”“比如”“那么”“然后”“包括”接起来：“那么这一批数据是从哪里来的呢？是由于键盘和 PC 的兴起，当键盘和 PC 作为一个传感器普及到世界中，那么全世界的人就变成了标注员。”（10-28）不追求短句，也不用“长句后面跟一句短的”。
2. **“其实”几乎每条一个**，放在转折或揭底的地方：“其实讲的是 LLM 和多模态两个不同的模态”“其实三思就是一个迭代和想明白的过程”（11-04）。
3. **举例都用“比如”引出**，例子是身边的小场景：“比如有一张烧水壶烧开的图片，那厨房里到底发生了什么呢？”（11-04）
4. **“那么……呢？其实……”自问自答**，每章两三个：“那么什么是多模态模型呢？其实是连接抽象语言与物理世界的一个必要途径。”（11-04）
5. **翻译句式**：“我的理解是”“我理解的大概意思是”“简单理解就是”“翻译下就是”“换句话说就是”“相当于”。例：“我理解的大概意思是，去印了 10 万亿的钱”（10-28）；“世界模型简单理解就是，在预测了一个行动之后会发生什么”（11-04）；“谨慎，翻译下就是风险预判”（10-15）。
6. **语气词**哈 / 啊 / 吧 / 呢，每章两三个：“昨天继续蹭课哈”（10-15）“我觉得这个很有意思啊”（10-28）“也在意料之中吧”（10-21）。
7. **对着“大家 / 你们”说**：“听我跟你们娓娓道来”（11-04）“接下来给大家简单的讲一讲”“这个问题留给大家”（10-28）。
8. **他自己常用、不算 AI 腔的词**，照随记的频率用，不设上限：本质 / 本质上（9 次）、在 AI 时代 / 互联网时代（带具体时代，18 次）、不是……而是……（“而是”19 次）、闭环、更底层、值得我们深思（后面跟具体问题）、微微。
9. **卡上不写的**：嗯、呃、句首的“而”、“进行……”。这些他说话自带（AI06 实录：“而规模也上来了”“进行结算”“进行互斥”），卡上再写，录出来就叠了。

## 三、内容上的动作

1. **交代自己从哪知道的**。“昨天跟着姜老师去北大蹭了课”（09-17）“昨天看到数字生命卡兹克的一篇文章……出于好奇的我就去看了”（09-23）“课下我去了解了下至知科技这个 lab”（10-21）。讲稿里放在第 2 章交代来源的地方，照实说“我让 AI 先调研了一圈”，这是他学新东西的真实习惯（10-21：“当我遇到一个不懂的知识点……我会让 AI 先去调研一圈，并且从基础知识一点一点去讲解，做成 HTML 的 PPT 格式”），一期一处。开头不从这里起，开头照入口轮换表。
2. **大方承认没懂，请大家纠错**。“这方面我的理解也不是很深，如果有讲的不到位或者有错误的地方，还请大家在评论区帮我指出来”（10-28）“这个是很新的点，之前确实也没接触过”（10-21）“虽为业内人士，但不是算法岗”（09-23）。一期一次。
3. **一个身边的类比讲透一个机制**。烧水壶的三层理解：看见火焰和壶嘴的蒸汽是感知，知道是水壶在炉灶上烧水是语义，知道一直加热又不补水、水会变少是推理（11-04）；杯子在桌边，往外推会掉，往里推就安全，这个预测就是世界模型（11-04）；真人采数据像一篇一篇写作文，合成数据像用模型批量合成作文（10-28）；MoE 像医院，看病不用所有医生都上，路由器就是分诊台（09-23）；时机是“已经开始下雨了再去找盆，就晚了”（09-24）。一个就够，用完回到正题。
4. **数字配一个生活尺度**。“每百万 token，对比的是半本《天龙八部》，或者换算成《哈利·波特》，其实是三本”（10-21）。
5. **这里我想多说一句**：在主线上多走一步，自己串起来。“在传感器这里我想多说一句：在 1981 年 PC 被发明出来之后，大家其实有了写数据的能力；在 1991 年互联网发明之后，大家的数据可以汇总到一起；在 2007 年 iPhone 发明之后，大家可以更便捷地产生数据；在 2017 年 Transformer 发明之后……大模型不是凭空出现的，而是先有传感器的普及，才有数据的积累，最后才是算法的突破。”（10-28）
6. **我有一些不一样的看法**：对嘉宾或主流说法提异议，带理由，用一个问句收住。“当嘉宾讲到这里的时候，我有一些不一样的看法：就好比我们存下的图像，其实只是这一帧，而世界上所有东西都是不断往前运动的，这一帧也只是它的过去式，所以我们一直去描述过去，到底合不合适呢？”（11-04）“我依然认为目前的项链、戒指，不是一个很好的、能融入普通人生活的产品……我判断的点是……但又不太确定的是……”（10-28）
7. **串以前学过的**：“这里感觉又回到姜老师提的观点”（09-24）“这块姜老师在很久前也提到过类似的表述”（10-21）“包括最近在看关于 ego 的一些视频，也描述了这样的内核”（10-28）。真有关联才用。
8. **古话借一句，自己再解释**：“古话也这样讲过，三思而后行，为什么要三思？其实三思就是一个迭代和想明白的过程”（11-04）；《孙子兵法》“善战者，求之于势，不责于人”（09-24）。一期最多一处。
9. **身边人的一句话**：“我女朋友告诉我，这些经历才造就了现在的你”（10-15）“在回公司的路上和姜老师聊到……”（09-17）。一句话、带温度，不展开。
10. **对仗收一段**：“先行者用试错换时间，后发者用观察换答案”（09-17）“一流的赛道放大普通人的能力，三流的赛道吞掉顶尖选手的才华”（09-24）。每章最多一句。
11. **收尾：留给大家的问题，加上他自己的下一步**。问题要具体：“那接下来市场会如何表现呢？这个问题留给大家”（10-28）“当内容更便宜之后，稀缺的是生成能力，还是创意与分发？”（11-04）。他自己的下一步：“接下来我也会去看一下”“多学习没毛病”（10-21）“我觉得应该去学习和储备一些金融方向的知识和能力”（10-28）；要有出处（他的回答或随记），没有就只留问题。
12. **经历大于阅读**。“嘴上会不代表脑子会”“还是经历大于一切”（09-07）。给观众的判断，最好是一个能马上动手试的动作，而不是一句道理。

## 四、“我”从哪来

- **讲解型**（“我的理解是”“翻译一下”“简单理解就是”）：把卡上的材料换成人话，可以直接写，但不借它加新论断。
- **经历和看法型**（第一反应、试过、听谁说过、多说一句、不一样的看法、我觉得 / 我判断）只有三种合法来源：
  1. 随记里有的：直接搬，必要时标日期；
  2. 他在 SKILL.md 第 3 步的回答里说过的：保留原话，只理成能顺口念的句子；
  3. 都没有：不写。宁可这一期少一个“我”，也不凭空造一次改口。

第三条是 AI 味的最大来源：模型会照着“口吻规则”生成一个很合理的“我也没想到”，听起来对、实际是空的，而观众对假的自曝比对假的知识更敏感。旧版这份文件里就有一句“这两天在算家里那笔账，越算越不对”，标成随记原话，随记里其实没有，2026-11 已删。

## 五、讲稿卡自检（和 SKILL.md 的自检一起过，要点和临场说法都算）

- [ ] 三章读下来是“我原来怎么想 → 我查到了什么、我的理解是 → 我现在的判断和还没想通的”，不是一篇新闻稿。
- [ ] 开头入口和最近三期不撞：不是又一句“照常……一边……一边……”，也不是同一类入口连着用。
- [ ] 句子是顺着讲的长句；“其实”几乎每条一个，例子都用“比如”引出，“那么……呢”和语气词每章两三个。
- [ ] 术语第一次出现时，用“翻译一下 / 简单理解就是 / 大概意思是”接一句人话。
- [ ] 主机制有一个身边的类比。
- [ ] 第 2 章交代来源时照实说了“我让 AI 先调研了一圈”，一期一处。
- [ ] 坦白 + 请大家纠错，一期一次。
- [ ] “多说一句 / 不一样的看法”来自他的回答或随记原话；串以前学过的每章最多一处，真有关联，第 3 章只回指本期前面讲过的。
- [ ] 古话最多一处；每章最多一句对仗收束。
- [ ] 结尾是“这个问题留给大家”加一个具体问题；前面的下一步小事有出处才写。
- [ ] 所有经历和看法型的“我”都在“四”的三种来源里。

## 六、隐私和素材边界

- 可以用：蹭北大的课（刘勇、朱啸虎、杨锦方、姜正涛、戴春博、李丰、王淼森）、每天早上看 AI 新闻和写日报、用 AI 调研和读论文写笔记（pi 等工具、做 HTML 的 PPT）、自己搭三层资金框架这类**观点和习惯**。
- 先问再用：女朋友、具体理财金额、驾校这类私事；第一次在视频里提到时，在发布清单的事实核对里标“录前确认”。
- 不用：公司、客户、项目、数据业务（保密要求）。
- 随记里的数字和说法是听课记录，进卡前照常找原始来源核对（`AGENTS.md`「事实底线」）。

## 八、搬进口播时怎么改

随记是写给自己的，口播是说给别人听的。保留人味和说话的顺劲，去掉草稿味：

| 随记里 | 口播里 |
|---|---|
| “以下内容为本人的浅薄理解……还望大家理解（毕竟都在成长中）” | 只留一次，带请大家纠错：“这块我的理解也不是很深，讲得不对的地方，还请大家在评论区帮我指出来” |
| 一逗到底、没有标点的长句 | 保留长句的顺劲，但一条要点只装一个意思；“其实 / 比如 / 那么”留着，“嗯 / 呃 / 然后然后”去掉 |
| hhhh、O 醍醐灌顶、属实是成神之路了、细思极恐 | 网络梗不用；哈 / 啊 / 吧 / 呢照“二”的浓度用 |
| “这个还得研究” | 放进结尾“这个问题留给大家”；正文里的“我也不确定”并进那一次坦白，不另说 |
| 识别错字（多么态、大圆模型、上海文窗口） | 照正确的词写 |
