# 像素呼吸本人的口吻（从手写随记里归纳）

> 来源：`~/Documents/工程队/Dify知识库/随记-记录我在尝试理解世界的过程和想法.md`（本人手写，2026-09-07 ~ 10-15）。同目录下的“听后记”“公众号版”是 AI 整理过的，不作为口吻依据。
> 用法：写稿时按这里调口吻，写完逐条对照“口播稿自检”。随记本身也是素材库，见文末。

## 一、他写东西的 10 个习惯

1. **先说自己在哪、在干嘛，再说想法。**
   “早上到公司，依旧像往常一样准备咖啡、发公众号、看文章，点开 X 后就看到……”“昨天跟着姜老师去北大蹭了课……还尝试了北大的食堂。”
   → 观点总是从一个具体的日常现场长出来，有日期、有地点、有手上正在做的事。

2. **大方承认自己没懂、不是专家。**
   “说实话看完后理解没有很深”“虽为业内人士，但不是算法岗”“这个我还没看过，课下一定补齐”“我的理解不是很深，不能很好地解释老师的意思”。
   → 他的可信度来自坦白，不是来自权威腔。

3. **先摆原话或术语，再自己翻译。**
   高频句式：“我的理解是……”“翻译下就是……”“白话讲就是……”“概括点说……”。例：“谨慎，O 醍醐灌顶，翻译下就是风险预判，类似风控的能力。”

4. **一个类比讲透一个机制，类比都来自日常。**
   MoE = “整个医院的医疗资源，看病不用所有医生都上；路由器就是分诊台”；时机 = “已经开始下雨了再去找盆，就晚了”；北大的课 = “埋了一根针”；能力和价值观 = “能力是数值，价值观是数值前面的正负号”。
   → 类比只用一个，用完就回到正题，不堆。

5. **顺手借一句古话或历史人物。**
   《孙子兵法》“善战者，求之于势，不责于人”、王阳明龙场悟道、士别三日、秦始皇求长生。一篇里通常只出现一次，用来给观点找一个中国人熟悉的锚。

6. **身边人的一句话。**
   “我女朋友告诉我，这些经历才造就了现在的你”“在回公司的路上和姜老师聊到……”。一句话、带温度，不展开。

7. **用对仗句把一段收住。**
   “先行者用试错换时间，后发者用观察换答案”“一流的赛道放大普通人的能力，三流的赛道吞掉顶尖选手的才华”“创业最怕的不是跑得慢，而是在错误的战场上跑得快”。
   → 一段一句，不连着排比。

8. **最后落到自己下一步要做的小事。**
   “课下一定补齐”“今天必须把它解决掉（我去读期货的文章了～）”“接下来加强与人的交流先”“先拿出 100 块，尝试 1—6 个月看看”。
   → 结论不是喊给别人听的，是他自己先去试。

9. **经历大于阅读。**
   “嘴上会不代表脑子会”“还是经历大于一切”“以身入局，最痛的经历才能让你产生反思”。给观众的判断，最好是一个能马上动手试的动作，而不是一句道理。

10. **爱留开放问题，也爱用具体数字和小框架。**
    “什么变得稀缺了呢……需要大家深度思考？”“这个还得研究”；同时又会写“30% / 40% / 30%”“原理—变量—阈值—决策”“三层分级”。
    → 一期给一个能记住的小公式或小框架，结尾留一个他自己也还在想的问题。

## 二、搬进口播时怎么改

随记是写给自己的，口播是说给别人听的。保留“人味”，去掉“草稿味”：

| 随记里 | 口播里 |
|---|---|
| “以下内容为本人的浅薄理解……还望大家理解（毕竟都在成长中）” | 只留一句：“我一开始也没想明白”“说实话我也是查了才知道” |
| 一逗到底的长句、“这里……其实……感觉……这样” | 拆成一行一句；“其实 / 感觉”每章最多两次 |
| hhhh、O 醍醐灌顶、属实是成神之路了、细思极恐 | 口播里最多一处轻语气（“哈”“说白了”），不用网络梗 |
| “这个还得研究” | 留在结尾问题里，正文里不说“我也不确定” |

## 三、口播稿自检（和 SKILL.md 的自检一起过）

- [ ] 开头有没有一个**本人真实的**日常现场（看新闻、蹭课、用 AI 干活），而不只是新闻本身？
- [ ] 全片至少一处“我也没懂 / 我第一反应也错了”的坦白，只说一次。
- [ ] 术语第一次出现时，用“翻译一下 / 说白了”接一句人话。
- [ ] 主机制有且只有一个日常类比。
- [ ] 古话、历史人物最多一处；身边人的话最多一处。
- [ ] 每章最多一句对仗收束句。
- [ ] 结尾落到本人自己要去做的一件小事，或者一个他也还在想的问题。
- [ ] 所有“我……”的经历都是随记或本人确认过的真事，不替他编经历。

## 四、隐私和素材边界

- 可以用：蹭北大课（刘勇、朱啸虎、杨锦方、姜正涛）、每天早上看 AI 新闻和写日报、用 AI（pi 等工具）读论文写笔记、自己搭三层资金框架这类**观点和习惯**。
- 先问再用：女朋友、具体理财金额、驾校这类私事；第一次在视频里提到时，在发布清单的事实核对里标“录前确认”。
- 不用：公司、客户、项目、数据业务（保密要求）。
