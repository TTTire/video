# 视频脚本生成工具 - 使用指南

## 快速开始

### 1. 初始化工作区（首次使用）

告诉 AI：
```
搭建视频脚本工作区
```

AI 会自动创建：
- 文件夹结构
- 模板文件
- 待写选题文件

### 2. 添加选题

**方式1： 直接生成脚本**
```
帮我写个关于"为什么你越努力越焦虑"的视频脚本
```

**方式2： 先添加到选题池**
```
添加选题：为什么你越努力越焦虑？
```

### 3. 生成脚本

```
生成"为什么你越努力越焦虑"的脚本
```

AI 会：
1. 按标准模板生成完整脚本
2. 包含4章节、100个镜头
3. 标注每个镜头类型（视频/图片）
4. 保存到「进行中」文件夹

### 4. 查看待写选题

```
查看待写选题
```

## 脚本格式

### 基本信息
- 时长： 10分钟
- 章节： 4章
- 镜头： 约100个

### 镜头类型
- 🎬 视频（15秒）： 关键转折、情绪高潮
- 🖼️ 图片（5秒）： 辅助说明、数据展示

### 配比
- 视频镜头： 10-12个
- 图片展示： 80-90个

## 脚本结构模板

### 第一章：痛点共鸣（00:00 - 02:30）
- 引出问题
- 描述现象
- 制造共鸣

### 第二章：原理解密（02:30 - 05:00）
- 脑科学/心理学原理
- 简单语言解释复杂概念
- 视觉化呈现

### 第三章：深度分析（05:00 - 07:30）
- 核心理论/模型
- 案例拆解
- 数据支撑

### 第四章：行动指南（07:30 - 10:00）
- 具体方法
- 可执行步骤
- 总结升华

## 视频生成 Prompt 规范

### 统一后缀
```
Cinematic lighting, hyper-realistic, dark moody color palette, 8k resolution
```

### Prompt 结构
```
[主体描述] + [动作/状态] + [环境/背景] + [风格后缀]
```

### 示例
```
一个分屏画面，左边是白天在工位上疯狂打字的背影，右边是深夜躺在床上睁着眼睛失眠的特写。Cinematic lighting, hyper-realistic, dark moody color palette, 8k resolution
```

## 常见问题

### Q: 脚本太长了怎么办？
A: 可以减少章节数量或减少每个章节的镜头数。建议至少保留4章结构。

### Q: 视频镜头太多，API不够用怎么办？
A: 可以调整配比，减少视频镜头，增加图片展示。例如：6个视频 + 94个图片。

### Q: 如何保证画面风格统一？
A: 所有视频生成 Prompt 使用相同的风格后缀。

### Q: 脚本写完后如何定稿？
A: 脚本保存到「进行中」文件夹，你可以反复修改。定稿后告诉 AI "XXX脚本完成了"，会自动移到「已完成」文件夹。
