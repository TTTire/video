## 制作说明

### 镜头类型说明
- 🎬 **视频镜头**： 关键转折点、情绪高潮、重要概念（15秒）
- 🖼️ **图片展示**: 辅助说明、数据展示、概念图（5秒）

### 配比建议（10分钟）
- 视频镜头： 10-12个（150-180秒）
- 图片展示： 88-90个（440-450秒）
- 总计约600秒

### 视频生成 Prompt 后缀
建议统一添加：
```
Cinematic lighting, hyper-realistic, dark moody color palette, 8k resolution
```

### 章节节奏建议
- **第一章**（00:00-02:30）：快速切入，制造共鸣，3个视频镜头
- **第二章**（02:30-05:00）：放慢节奏，讲清原理，3个视频镜头
- **第三章**（05:00-07:30）：适度加快，深度分析，3个视频镜头
- **第四章**（07:30-10:00）：回归平缓，给出行动，3个视频镜头
