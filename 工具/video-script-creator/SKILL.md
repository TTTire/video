# 像素呼吸写稿指南

工作区（本 Skill 源文件都在 `工具/video-script-creator/`，`~/.agents/skills/video-script-creator` 是指向它的链接）：

| 系统 | 工作区根目录 | Python 命令 | 随记原文（口吻样本） |
|---|---|---|---|
| macOS | `/Users/tttire/Documents/工程队/视频选题` | `python3` | `/Users/tttire/Documents/工程队/Dify知识库/随记-记录我在尝试理解世界的过程和想法.md` |
| Windows | `E:\视频脚本` | `python` | `E:\Dify知识库\zwn-wiki\随记-记录我在尝试理解世界的过程和想法.md` |

交付格式、发布清单板块等硬性要求见工作区根目录 `AGENTS.md`。下面命令一律写相对工作区根目录的路径，在哪个系统都一样跑。

讲的人是一个正在弄懂世界的人（随记的标题就叫“记录我在尝试理解世界的过程和想法”）：他把自己从“原来以为”到“现在的理解”这一路讲给你听，讲到自己也没想通的地方，就留给大家。观众最后带走一句话：我原来把什么看错了，为什么会看错，下次该多问哪一句。

## 流程

1. **定题**：《100个经济学原理》先核对 `模板/选题库/100个经济学原理.md` 的序号和相邻期的分工。用一句话写下“观众原来以为什么 → 本期让他改成什么”，一期只打一个反转。
2. **检索**：**这一步的产出是素材，不是灵感。** 至少 1 个权威或原始解释；至少 2 个可回溯的真实案例或数据；再看看别人通常怎么举这个例子，避开最平淡的讲法。随记在这里的作用是**对口吻**，不是找材料：写之前读 `references/本人口吻-来自随记.md`，再读随记原文最上面最新的一篇（路径见上表；新的在最上面，读到下一个日期标题为止），让句子像他说的。里面正好有能用的原话或现场就搬，没有就不搬，不要为了用随记而拉一个不相干的事进来。
3. **选例 + 问他三个问题**：先给用户看“核心反转 + 3 个候选例子 + 推荐及理由”，每个候选一两句话说清画面、冲突在哪、来源；同一条消息里问他下面三个问题，稿子里经历和看法型的“我”就用他的回答写（见「口播写法」）：
   1. **第一反应**：看到这个题（这条新闻），你第一反应是什么？→ 第 1 章“我原来怎么想”。
   2. **相关经历**：你自己碰到过、试过，或者听谁聊过相关的事吗？随记里有沾边的，先列出来问他用不用。→ 开头或正文里的“我……”。
   3. **你怎么看**：看完上面的材料，有没有想多说一句的、不太同意的，或者还没想通的？→ “这里我想多说一句”“我有一些不一样的看法”、结尾留给大家的问题。

   用户确认后再写。回答保留他的原话，只理成能顺口念的句子；哪题没答，对应的“我”就不写。用户说“直接写”时跳过这一步：稿子里的“我”只用随记里有的（包括“我让 AI 先调研了一圈”）和讲解型的“我的理解是”，不替他写第一反应和看法。
4. **写讲稿卡**：格式按 `AGENTS.md`「讲稿卡」，样例见文末「参考」。要点是意思，不是逐字稿：一条 = 一个意思 + 例子 / 数字，用他的口吻写成能顺口念出来的一两句，讲 10–30 秒；★ 标本章主例子；卡里出现的数字都进「数字表」，边界、没过核的材料、禁用词进「别说」。按下面的结构和写法一次写完。
5. **删要点**：通常删掉 15%—25% 的要点，先删最弱的例子、重复的因果，再对着卡试讲一遍。
6. **收尾**：写发布清单：推荐标题、标签、发布文案、发布时间、事实核对自己写；封面和配乐按各自 Skill 写；**画面与素材清单按 `工具/video-broll-maker/SKILL.md` 的「写稿阶段」一节写**（这是用户出图的依据，也是之后渲染动画轨的场景表，必须写完整；要用户准备的东西全列在里面）。论文、报告、规定、新闻原文这类证据能截到干净原文的，当场截成文档页 `D01`…放进 `图片素材/`，列进出图清单最后的「文档页截图」，不留给用户。然后跑校验：
   ```bash
   ruby 工具/validate_package.rb "进行中/选题文件夹"
   python3 工具/video-render/scripts/scenes_from_checklist.py "<发布清单.md>" "<讲稿卡.md>" epN   # 校验起始要点、列出要出的图   （Windows 把 python3 换成 python）
   ```

## 什么样的例子好

- **有冲突**：看起来违反直觉，观众会想“咦，为什么”，比如“奢侈品越涨越抢”，而不是“苹果贵了少买”。
- **真实可查**：有具体的时间、数字和出处，最好是观众刷到过的新闻或身边常见的事。
- **因果对得上**：确实是这个原理在起作用，不只是表面相似。
- **一条线贯穿**：材料可以有好几样，但每一样都在推同一条因果链；删掉不影响理解的就删。
- **示意要说明**：找不到真实个案、只能用示意时，开头说一句“假设”，并且给出价格、数量、时间这类具体数字。

## 结构

- **独立开头**（约 20—40 秒，讲稿卡的「## 开头（入口类型）」一节，4–7 条要点，不算章）：前 10 秒交代具体现场、观众自然会有的误判，以及为什么值得听下去。系列栏目开场放在钩子之后，见 `模板/像素呼吸-100个经济学原理栏目开场模板.md`。
- **开头必须换套路，写之前先查**：先读最近三期的开头（讲稿卡的「开头」一节；第 8 期、AI02 及以前没有讲稿卡，看口播稿前 15 行），本期开场不能和它们撞同一个入口。撞了就是复读，观众第一句就听出来了。
- **第 1 章（我原来怎么想）**：旧判断为什么自然，它漏看了什么。他答了第 3 步第 1 题，就从他自己的第一反应讲起，再说大多数人为什么也这么想。
- **第 2 章（我查到了什么，我的理解是）**：真正起作用的机制，放进主证据。交代来源时照实说“我让 AI 先调研了一圈”（他学新东西的真实习惯，随记 10-21；一期一处），再讲是谁的实验、原文怎么写；机制讲完接“我的理解是……”；他第 3 题有回答，就在这里多说一句，或者说出不一样的看法。
- **第 3 章（我现在的判断，和还没想通的）**：边界只说一次，给一个今天就能用的判断，回到开头的现场；最后落到他自己下一步要做的一件小事，加一句“这个问题留给大家”和一个具体问题。
- 括号里是这一章怎么走，不是章标题；章标题照旧按内容起。
- **章与章接力**：上一章留下的问题由下一章回答；第 2、3 章不能互换顺序；第 3 章不再引入新的研究或人物。
- **结尾**：留给大家的问题可以就是下一期的钩子。

## 开头别复读（踩过的坑）

2026-10 连踩两次，都是同一个原因：拿上一期当模板，改主题不改句式。

| 坑 | 表现 | 规则 |
|---|---|---|
| 咖啡开头 | 连着两期“我照常一边冲咖啡，一边刷 AI 新闻” | “冲咖啡”“照常”“一边……一边刷新闻”这个入口**停用**，见下表其它入口 |
| 模板改口 | 第 6、7 期、AI01 连着三次“我一开始也是这么想的” | 改口句一期最多 1 次，且连续两期不能是同一句 |
| 栏目口播词 | “这里是像素呼吸，今天聊聊……” | 这句话本身可以留（是栏目标识），但前面的钩子不能同构 |

**开场入口轮换表**，相邻两期尽量不选同一类：

| 入口 | 样子 | 例 |
|---|---|---|
| 别人说的话 | 直接抛一句群聊、评论区、同事的原话 | 群里有人丢了个问题：“那还要数学系干什么” |
| 一个具体现场 | 时间 + 地点 + 正在发生的事，不带“我” | 晚上七点，奶茶店门口排了十几个人 |
| 一条新闻 | 日期 + 一个数字，直给 | 2023 年 2 月，LV 要涨价了，最多涨 20% |
| 一个反常现象 | 先给结果，不给解释 | 东西没变快，也没变大，价格涨到五倍多 |
| 自己的动作 | 我手上正在做的一件具体事（必须真实） | 这两天我在算一件很小的事 |

不用“我的一天/我的习惯”当万能入口——那个位置一期只能出现一次，连着用就成模板了。

## 口播写法

下面这些对讲稿卡上的要点和临场讲出来的话都适用。随记里的原句和出处见 `references/本人口吻-来自随记.md`。

- **姿态**：一个正在弄懂这件事的人，把弄懂的过程讲给朋友听：我去看了 / 听了什么 → 对方说了什么 → 我的理解是 → 这里我想多说一句 / 我有一些不一样的看法 → 这块我也不确定，留给大家。每章至少一处第一人称：判断、自问自答，或者一次改口。
- **“我”分两种**：
  - 讲解型：“我的理解是”“翻译一下就是”“简单理解就是”“大概意思是”，只是把卡上的材料换成人话，可以直接写，但不借它加新论断。
  - 经历和看法型：“我第一反应是”“我试过”“我让 AI 先调研了一圈”“这里我想多说一句”“我有一些不一样的看法”“我觉得 / 我判断”，只能来自随记，或者他在第 3 步的回答。没有就不写，宁可不提，也不编。
- **顺着讲，浓度接近随记口述原样**：句子顺着往下讲，用“其实”“比如”“那么……呢”“然后”接起来，不追求短句，也不用“长句后面跟一句短的”那种节奏。“其实”几乎每条一个；举例都用“比如”引出；“那么……呢？其实……”的自问自答和哈 / 啊 / 吧 / 呢这类语气词，每章两三个。
- **术语一出现就翻译**：“翻译一下就是 / 简单理解就是 / 大概意思是 / 换句话说”；数字后面接一个生活尺度，比如“每一百万 token，差不多是半本《天龙八部》”。
- **主机制配一个身边的类比**：随记里的类比都是手边的东西，烧水壶、桌边的杯子、写作文、医院分诊台。一个就够，用完回到正题。
- **多说一句、不一样的看法**：来自他第 3 题的回答，一期一两处。“这里我想多说一句”后面接他自己串起来的东西；“我有一些不一样的看法”后面接他的理由，可以用一个问句收住。
- **串以前学过的**：真有关联才用，每章最多一处，来源只能是随记或他的回答：“这里又回到姜老师说的……”“包括最近在看的……也是这个意思”。第 3 章不新拉人，只回指前面讲过的。
- **坦白一次，请大家纠错**：“这块我的理解也不是很深，讲得不对的地方，还请大家在评论区帮我指出来。”一期一次，一般放在第 2 章机制讲完之后。
- 古话最多一处，借完自己再解释一句（随记：“三思而后行，为什么要三思？其实三思就是一个迭代和想明白的过程”）。每章最多一句对仗收束。
- **收尾**：落到他自己下一步要做的一件小事，再加一句“这个问题留给大家”和一个具体问题；不喊口号。
- 内部材料不进口播：不报幕写稿方法（“注意，我们看的是……”），不逐句免责，边界只说一次；上面那一次坦白不算逐句免责。
- 同一个因果只完整讲一遍，其他地方最多用一句话回指；不连续堆排比。
- 卡上不写他说话自带的：嗯、呃、句首的“而”、“进行……”（AI06 实录：“而规模也上来了”“进行结算”）。卡上再写，录出来就叠了。
- 禁用 AI 腔（随记里他自己没用过的）：深度赋能、认知升级、底层逻辑、显著提升、抓手、高维度、不难发现、值得注意的是、在这个时代。随记里他自己常用的不算，照随记的频率用，不设上限：本质 / 本质上、闭环、更底层、在 AI 时代（说出具体是哪个时代）、值得我们深思（后面跟具体问题）、不是……而是……、微微。
- 不用成功学压迫感：顶级高手、底层人、你必须、否则就会被淘汰。
- 长度讲清为止，不为凑时长加内容。按卡上字数约 200 字/分钟估算（AI03 实录）。

### 句子的手感（对治 AI 味）

AI 味的根子是“平均”：每个词都是最常出现的那个，每句话都是最顺的那个。删干净禁用词只到“不像特别假的 AI”，要到“像人”靠下面三条。

1. **写身体反应，不写情绪名词**。不写“消费者剩余提升”“他感到后悔”，写“结账时他愣了一下”“回去路上一直算这笔账”。具体动作、感官、时间点，是 AI 最不会主动写的东西。
2. **副词配额**。淡淡、缓缓、轻轻、悄然、默默、隐隐、静静——全片合计最多 1 个。这是 AI 最稳定的指纹之一。（“微微”随记里他自己用过，不算。）
3. **用他的说法，不用最顺的说法**。同一个意思，随记里他怎么说就怎么说（“我的理解是”“大概意思是”“简单理解就是”“那么……呢”），不换成书面上更顺的词。

### 一眼能认出是 AI 的五种句子

过稿时逐条扫，中一条就改写。不是“少用”，是“不用”。右列是同一个意思的人话版。

| 特征 | AI 写法 | 换成 |
|---|---|---|
| 排比三连 | 更便宜、更方便、更普及 | 只留最要命的那一个，或者干脆写四件事 |
| 假深刻框架 | 真正的问题在于 / 说到底 / 值得注意的是 | 删掉框架，直接从事实或数字开口 |
| 意义膨胀 | 标志着 / 前所未有 / 意义深远 / 开启了新阶段 | 具体后果：谁多赚了多少钱，谁少了几个工人 |
| 论文式段首 | 每段第一句先总结，再展开 | 直接从动作、现场或数字开始，结论放段末 |
| 收尾升华 | 未来可期 / 时代给出了答案 / 只说“值得我们每个人思考”，后面没有问题 | 落到自己下一步要做的一件小事，再加“这个问题留给大家”和一个具体问题 |

## 删要点与自检

先删：最弱的例子、重复的因果、换个主题也成立的要点、只为显得有料的材料。

交付前自检：

0. **「谁的」检测，先做这一步**——逐条要点问“这件事是谁做的、对谁发生的”。
   - “价格弹性显著提升” → 谁变了？说不出主语的要点删掉。
   - “我们更理解了价格” → 有主语也不等于有人；“成功地”“很好地”这类替自己鼓掌的词一起删。
   - 过一遍通常能砍掉三到五成，砍完再读，剩下的往往就是能讲的。
1. 冷读者能用一句话复述本期的反转（和卡上的「一句话反转」是同一句）。
2. 前 10 秒交代了现场和误判。
3. 卡里每个数字在「数字表」里有一行，都有来源；推断和示意都已标明。
4. 三章不可互换，第 3 章没有新材料。
5. 对着卡把开头试讲一遍：每条要点都能顺口讲出来，像人会说的话。
6. 标题、开头和结尾兑现的是同一个承诺。
7. 过一遍 `references/本人口吻-来自随记.md` 的「讲稿卡自检」。
8. 卡的格式：开头 4–7 条、每章 4–10 条，每条一个意思 + 例子 / 数字、讲 10–30 秒；每章的主例子标了 ★；边界、没过核的材料、禁用词写进「别说」。副词（“微微”不算）不超过 1 个。
9. 五种 AI 句子一条都没中（见上面那张表）。
10. **每一处经历和看法型的“我”都有出处**：随记里有的，或者他在第 3 步的回答里说过的。两处都没有就不写——宁可不提，也不编经历。讲解型的“我的理解是”只换说法，不夹带新论断。

## 改稿

先从旧稿提炼出那一句反转，删掉它装不下的支线，再重组要点。只改开头、标题或文案时，不动各章要点。

按随记口吻改旧卡时，第 3 步的三个问题照问；一条改一条，要点 id 不动。新加的动作（多说一句、坦白、留给大家的问题）要单独成条，就按 `AGENTS.md` 同步改发布清单的场景表。
