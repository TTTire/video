# 像素呼吸 B-roll 动画轨

工作区 `E:\视频脚本`，渲染工程 `工具/video-render/`（Remotion，命令都在这个目录下运行）。第 6 期是完整样例：
发布清单 `已完成/6-100-边际报酬递减-人多了为什么没快多少/…-发布清单.md`，场景表 `工具/video-render/src/ep6/photo.json`，图表 `src/ep6/custom.tsx`。

成片是什么：1920×1080 / 30fps、和用户口播等长、**只有音效没有配音**的动画轨。用户在剪映里把它和 A-roll 从 0 秒对齐叠放，想露脸的地方把动画轨切掉即可。字幕和 BGM 用户在剪映加，所以画面文字压在上 2/3，底部留字幕位。

## 两个栏目，分开做

| | 《100 个经济学原理》 | 《AI经济学》（AI 时事 × 经济学） |
|---|---|---|
| 期号目录 | `ep7` `ep8`… | `ai01` `ai02`… |
| 角标 | `08 像素呼吸 · 100 个经济学原理` | `像素呼吸 · AI经济学`（**不显示期号**） |
| 栏目卡 `type: series` | 有，开场钩子之后 | **没有**，开场用普通 `title` 场景 |
| 口播稿标题 | `# 8/100｜标题` | `# 标题` |

脚本按期号前缀自动分（`new_episode.py ai01` 就全对）；发布清单里写 `<!-- SERIES xxx -->` 可以覆盖栏目名。两个栏目的照片风格、字体、音效都一样，只有这几处身份标识不同。

## 写稿阶段：画面与素材清单

写在发布清单 `## 画面与素材清单` 下，三部分。完整样例见第 6 期发布清单。

### 1. 全局风格

**先定本期视觉方案，再写提示词。** 栏目固定不变的是：左上角标、章节卡结构、音效语言、底部字幕位、**标题字体得意黑**、"写实照片铺底 + 大字 + 代码图表"这个大框架。其余五项每期从本期内容出发重新选，**和上一期相比至少换 3 项**（上一期的方案在它发布清单的 `STYLE_DNA` 注释里，先去读）：

| 维度 | 可选 | 怎么选 |
|---|---|---|
| 文字母版 `layout` | `topleft` 左上大字 / `right` 右侧右对齐 / `center` 居中 / `bottom` 底部字幕带式（**字幕得放顶部**，先问用户） | 看图的留白习惯：主体多在右 → topleft；主体多在左 → right；氛围图多 → center |
| 强调色 `gold` + 正/负色 `teal` `coral` + 压暗色 `bg` | 从本期照片里取：夜景冷调 → 香槟金 `#D9C49C` + 冷蓝底 `#070B14`；暖光门店 → 陶土橙 `#E07B45` + 暖黑 `#0B0907`；白天/自然 → 墨绿、赭石… | 照片入库后看一眼主色，强调色要和照片里的光源色呼应 |
| 照片处理 `tint` / `letterbox` / `grain` | 统一罩色（冷蓝、暖褐、青灰）、2.35:1 黑边、胶片颗粒，任意组合或都不用 | 电影感 / 纪录感 / 干净杂志感，三选一 |
| 入场 `enter` | `blur` 柔切（默认）/ `cut` 硬切 / `slideL` 横推 / `zoom` 缩放 | 节奏快、短句多 → cut；舒缓 → blur |
| 图表语言 | 柱状 / 阶梯 / 表格 / 折线 / 对比卡 | 跟数据形态走，但别和上一期同一种 |

写进发布清单时，一句话说清这期"看起来像什么"，再附一行机器可读的注释（脚本会把它写进 photo.json 的 `style`）：

```markdown
- 本期视觉方案：冬夜橱窗的冷调，字像奢侈品广告——香槟金、冷蓝罩色、2.35:1 黑边、硬切。和第 6 期（暖黑 + 陶土橙 + 左上大字 + 柔切）换了配色、照片处理、入场 3 项。
<!-- STYLE_DNA layout=topleft gold=#D9C49C coral=#C9545A teal=#9DB9CF bg=#070B14 dim=#B9C0CC tint=#1B2A44 tintOpacity=0.3 enter=cut letterbox=1 grain=0 -->
```

效果对比参考：`references/style-compare-ep7.jpg`（上：第 7 期实际版，下：同一内容换一套方案）。

**字体不随期换，但有分工**（对比图 `references/font-compare-2-2026-10-14.png`、角标 `font-compare-4-badge-wenkai-2026-10-14.png`）：标题得意黑；所有数字自动走数黑体；定义卡的大词加 `"font": "song"` 走锦书宋，一期只用一两次；对白、人说的话加 `"quote": true` 走文楷加金色引号；小字思源黑。写分场景表时，叠字里的对白用「“……”」或「老板：……」写出来，脚本会自动标成 quote。一期画面里最多同时出现这五种，不要再加别的字体。

然后是提示词和规格，固定写法（除非用户要换风格）：

```markdown
### 全局风格
- 风格：写实电影感摄影，夜景 / 室内暖光、浅景深、35mm；**画面里不要有任何文字**（招牌、数字、价签都不要，字由代码加）
- 一致性：先出 1 张主场景定调，之后所有同场景的图用它垫图；人物服装、关键道具（本期：___）在所有图里保持一致
- 规格：16:9，宽 ≥ 2560（即梦 2752×1536 直接可用），JPG/PNG，文件名带编号如 `S01.jpg`
- 提示词前缀（每张都拼在前面）：`写实摄影，电影感，<本期场景一句话>，<灯光>，浅景深，35mm 镜头，<人物设定>，画面无文字，16:9`
- 留白：每张图注明文字放哪一侧，那一侧构图留 35–45% 相对干净的区域（代码会压暗，不必纯色）
```

### 2. 分场景表格

列固定，脚本按列位解析：

```markdown
### 分场景

| # | 场景 id | 起始句 | 这段在讲什么 | 图 | 叠字 | 环境声 |
|---|---|---|---|---|---|---|
| 01 | shop | 0 | 晚七点排队，老板再叫一个人 | S01 | 「门口排了十几个人」「老板：再叫一个人 +1」「这下总该快了吧？」 | 奶茶店 |
| 05 | chapter | 10 | 第 1 章 章节卡 | — | — | — |
| 07 | bars | 13 | 1→5 人出杯 30/60/80/85/87?，柱状图 | S08 S02 | 柱状图（代码）「第四个人：只多了 5 杯」 | — |
```

- **场景 id**：小写英文，之后就是代码里的名字。章节标题行固定 `chapter`。
- **起始句**：口播稿行号，从 0 起，章节标题也占一号。写之前先跑 `python 工具/video-render/scripts/build_timeline.py <口播稿.md> epN --list` 看编号。第一行必须是 0。
- **切分粒度**：一个场景 = 一个画面主体，通常 4–12 行（口播稿一行最多 16 字宽，见 AGENTS.md）、10–30 秒；一段话里数字连续变化（柱状图、表格）可以放一个长场景。5 分钟的片子 20–25 个场景。
- **图**：可以写多张（第一张是底，第二张在场景中途淡入切换），可以复用别的场景的图。纯文字卡写 `—`。
- **叠字**：每条「」一句，按出现顺序挂到场景内的句子上；图表写「柱状图（代码）」这类说明。叠字不是字幕，是**提炼**：短、有数字、有对比。
- **环境声**：按 `工具/音效库/补充音效清单.md` 里的名字写（奶茶店 / 街道夜晚 / 森林 / 办公室 / 商场 / 厨房 / 雨 / 咖啡馆），只在开场、金句、结尾这类需要氛围的场景写。

### 3. 出图清单

每张图只写一次：

```markdown
### 出图清单（共 N 张）

先出 **S01**，确认风格后用它垫图出其余。

| 编号 | 画面 | 文字放哪侧 | 用在 |
|---|---|---|---|
| S01 | 夜晚奶茶店外景，暖黄灯光，门口一条十几人的队伍，透过橱窗能看到吧台里 3 个店员，老板站在门边招手 | TW | 01, 23 |
| S02 | 队伍中段特写，年轻人侧脸看手机，主体靠右 | TL | 02, 09 |
```

画面描述要能直接当提示词主体：机位（外景 / 内景平视 / 俯视 / 特写 / 顾客视角）、谁在干什么、关键道具位置、情绪。镜像构图的一对图（分屏用）标 `S20A / S20B`，并写明主体各靠哪一侧。

**「文字放哪侧」写画面区域名**（3 列 × 3 行：`TL TC TR / ML MC MR / BL BC BR`，整行居中用 `TW MW BW`）。这一列同时是给用户出图时的留白提示和脚本填 `box` / `grad` 的依据——同一套词，出图、填 JSON、看拼图提意见都用它，不用再翻译"上 1/3"是多少像素。详见 `references/photo-json.md`「画面区域」。

写完跑一次校验（起始句、id、列出要出的图），并且**顺手把渲染工程搭起来、先用占位图渲一张拼图**——版式问题在用户出图之前就能发现：

```bash
cd E:/视频脚本/工具/video-render
python scripts/new_episode.py epN        # AI经济学期用 ai01、ai02
python scripts/scenes_from_checklist.py "<发布清单.md>" "<口播稿.md>" epN     # → scenemap / scene-names / photo.json 骨架
python scripts/estimate_timeline.py "<口播稿.md>" epN src/epN/scenemap.json   # 按字数估算的预览时间轴（录完音会被 srt 版覆盖）
python scripts/placeholder_photos.py epN                                     # 没到的图先用占位图
# 把 photo.json 从骨架填成正式版（见渲染阶段第 2 步），然后：
python scripts/render.py epN sheet
```

这一步做完，渲染阶段只剩"换真图 + 换真时间轴 + 微调"。

## 渲染阶段：收到字幕和图之后

### 0. 收料检查

- srt：中文、一行一句、和剪映版一一对应。双语的也行（只取第一行）。
- 图：一个文件夹，文件名里有编号。
- 用户如果临场改了词：脚本能容忍少量改词、漏一两句（会打印出入），出入太多会停下 → 先把口播稿改成实际念的版本。

### 1. 建期 + 入库 + 时间轴

```bash
cd E:/视频脚本/工具/video-render
python scripts/new_episode.py ep7                                            # 写稿阶段没建的话：建 src/ep7/、public/ep7/photos/，注册 Ep7Photo / Ep7PhotoCheck / Ep7Sheet
python scripts/scenes_from_checklist.py "<发布清单.md>" "<口播稿.md>" ep7       # → scenemap.json、scene-names.json、photo.json 骨架（已有 photo.json 不覆盖）
python scripts/import_photos.py "<用户的图片文件夹>" ep7 --need "<发布清单.md>"  # 裁 16:9、统一命名 → public/ep7/photos/，报缺图；会覆盖同名占位图
python scripts/timeline_from_srt.py "<口播稿.md>" "<口播.srt>" ep7 src/ep7/scenemap.json   # → timeline.json（覆盖估算版）
```

缺图时先告诉用户缺哪几张；能用别的图顶就在 photo.json 里改 `photo`，别等。

### 2. 填 photo.json

骨架已经有场景、照片、叠字。逐个场景补：推拉方向、压暗侧、每条字的大小 / 颜色 / 出现句、强调标记、音效。字段说明和套路见 `references/photo-json.md`。原则：

- **场景不写 `box` / `grad` 就走本期 `style.layout` 的母版**；只在照片主体位置和母版冲突时单独给 `box`。别每个场景都手写 `box`，否则换母版就不生效了。
- 字压在照片相对干净的一侧（和出图清单里的留白一致），`grad` 设成同一侧。
- 一个场景内：第一句出小字（dim）铺垫，关键句出大字（白 / 金），数字单独做 `big` 或 `count`。
- 要划掉的旧判断用 `strikeAt`；两个对立项用 `compare` 或 `split`；盖章式关键词用 `stamp`。
- 柱状图、表格、折线这类按句子逐步出现的图表写进 `src/ep7/custom.tsx`，参考 `src/ep6/custom.tsx`；photo.json 里 `{"type":"custom","name":"xxx"}` 引用。
- 音效默认已经配好（字出现 pop、盖章 impact、数字 ding…），只在揭晓点手动加 `impact` / `error` / `cash`，别处不用管。

### 3. 看图 → 小样 → 全片

```bash
python scripts/render.py ep7 sheet        # 关键帧拼图，10 秒出一张 out/ep7-sheet.jpg，每个场景 1–4 格
python scripts/render.py ep7 check 40     # 前 40 秒带字幕的核对版 out/ep7-check.mp4
python scripts/render.py ep7 full         # 正式版（只有音效）out/ep7-photo.mp4，约 1 小时 / 5 分钟片
python scripts/render.py ep7 fullcheck    # 全片带字幕核对版（可选）
```

顺序不要跳：拼图自己先按下面的检查单过一遍，改完再给用户看拼图；用户认可后出 40 秒小样；再全片。改字之后只重渲拼图，不要动不动渲全片。

**拼图检查单**（拼图上叠着区域网格和红色字幕禁区线，按"场景号 → 问题 → 用区域名写的修法"逐条列出来，改完再渲一次；人对一闪而过的遮挡也很敏感，宁可多挑）：

1. 遮脸 / 遮主体：字压在照片里的人脸、产品、手上 → 换 `box` 到另一个区域，或改 `origin` 把主体推开
2. 出界：字超出画面边缘、换行后撑出文字框 → 缩 `size` 或改 `w`
3. 进字幕区：任何字的底边越过 y=820 红线 → 挪上去；`center` 和 `bottom` 布局重点查最后一条
4. 该收没收：上一句的字还留在屏上，和下一句的字叠在同一区域 → 给前一条加 `until`
5. 空档：一个场景连续 8 秒以上没有任何字出现或变化 → 补一条小字，或拆场景
6. 同图同动：连续三个场景用同一张图、同一个推拉方向 → 换 `move` 或 `origin`
7. 对比度：字压在照片亮部看不清 → `grad` 设到字那一侧，或加 `dim`
8. 字体用对没：数字是不是数黑体（乱码或方块说明字体没加载）、定义卡大词是不是 `song`、对白有没有 `quote`

### 4. 交付

把 `out/ep7-photo.mp4` 复制到选题文件夹，命名 `<选题名>-动画轨-对齐口播-仅音效.mp4`；需要分场景片段时：

```bash
python scripts/split_scenes.py out/ep7-photo.mp4 ep7 "<选题文件夹>/剪辑素材-分场景-仅音效" src/ep7/scene-names.json
```

写 `<选题名>-剪辑说明.md`（格式照第 6 期的）：文件用法、推荐剪法、分场景起点表（场景号 / 名 / 口播起点 / 时长 / 第一句）、重新生成命令。

最后提交 `工具/video-render` 的改动。

## 禁用清单

拼图审查和填 photo.json 时按这个否决，比"看着不太好"更稳：

- 禁止字进字幕区（y > 820）
- 禁止一个区域里前一条字没走、后一条就来（必须 `until`）
- 禁止一个场景 8 秒以上无字
- 禁止连续三个场景同图同推拉
- 禁止一期内出现第六种字体，禁止把标题换成得意黑以外的字体（定义卡大词和对白除外）
- 禁止一个场景内出现两处以上 `gold` 大字（强调色只给一处）
- 禁止照片里有文字（招牌、价签、数字）；有就让重出或用 `grad` 压掉
- 禁止手写像素坐标做 `box`（除非区域名真放不下）；像素框会盖掉母版，换 layout 不生效

## 常见问题

- **字和字幕打架**：字幕在底部 70px 处，画面文字别放到 y > 820。`center` 布局的场景检查最后一条字的位置。
- **照片切换太频繁**：一个场景一张底图 + 最多一次 `swap`；连续三个场景用同一张图时换推拉方向（in / out）和 origin，别一模一样。
- **用户出的图有文字**：让重出无文字版，或者在 photo.json 里把 `origin` 推到避开文字的区域、用 `grad` 压掉。
- **图不够**：同一张图可以用 `blur` + `dim` 做虚化底（定义卡、章节卡、结尾都这么干），不用每段都要新图。
- **字体**：五款都打包在 `assets/fonts/`（得意黑 / 数黑体 / 锦书宋 / 文楷 / 思源黑），分工见「全局风格」一节，**不随期换**。`style.titleFont` 这个开关留着，只在用户明确要求时用。渲出来数字是方块 → woff2 没加载，看 `kit.tsx` 的 `useFonts`。
- **两期长得太像**：检查发布清单有没有写 STYLE_DNA、photo.json 的 `style` 有没有生效、场景是不是都手写了 `box` 把母版盖掉了。
- **音效单调 / 缺环境声**：让用户按 `工具/音效库/补充音效清单.md` 补，补完 `python scripts/import_sfx.py`。
- **Windows / Mac**：Windows 命令用 `python` 不是 `python3`；两边都用本机 Chrome 渲染（`remotion.config.ts` 自动找）。Mac 上没有真图时先 `placeholder_photos.py` 出占位图再渲拼图。
