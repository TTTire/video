# 文档带读元素族设计（文件高亮风格）

> 用户 2026-11-13 确认，同日评审后修订（修订项见 `工具/视觉语言v2-文字减量与展示形式方案-2026-11-13.md` 开头）。风格出处：小lin说「文件重点高亮」+ Remotion 复刻实验（[aitntnews 文章](https://m.aitntnews.com/newDetail.html?newId=24076)，9 组特效）。用途：讲到研究材料、文章、报纸、论文原文时，用「文档页滑动 + 高亮 + 聚焦放大 + 翻页」渲染。实现挂在管线优化方案的阶段 5（视觉升级）。

## 1. 风格定义（用户描述 + 检索确认）

- 黑底（或黑底白线条），文档页是画面主体
- 页面上下滑动，跟着口播定位到相关段落
- 半透明高亮压住关键句，是文档段里**唯一的强调色**（小lin说用黄色；本工程取本期 `gold` 的半透明，不另引入一个色，用户 2026-11-13 确认）
- **聚焦放到能读**：以高亮句为中心放大，直到它在 1920×1080 画布上的字高 ≥ 44 px（手机上约 25 px），上限 4 倍；页面其余部分压暗/虚化。原稿写的 1.08–1.15 倍在手机上读不出来（右侧 600 宽的文档页，正文字只有十来个像素），评审后改
- 页与页之间用翻页转场
- 专业感来源：原始材料感（有据可查）+ 高亮锚点（视线钉死）+ 动效克制（只有滑、翻、聚焦三种）

## 2. 新增元素规格

### document（文档带读）

视觉与动效序列（按口播点逐条触发）：

1. 页滑入：文档页从下往上滑入（ease），落位
2. 定位：随口播滑到目标段落
3. 高亮：半透明色块渐显压住目标句（可做「扫过一行」的擦入），颜色是本期 `gold` 的半透明
4. 聚焦：以高亮句中心为 transformOrigin 放大到字高 ≥ 44 px（`zoom` 按截图字高算，上限 4），页面其余区域压暗（dim 0.55–0.7）+ 轻微虚化；截图字太小放不到 44 px 就在字区出一行摘句（`excerpt`，`h` 档）
   - 英文原文必配一行中文短译（`zh`，`t` 档），放在摘句 / 短标签下面
5. 换页：翻页转场（见 pageflip）

布局：

- 横屏 16:9：文档页在画面右侧 x 1020–1620，左侧 L 列留字区（短标签、摘句、译文；和现有「字在左、主体在右」的留白习惯一致）。右侧到 1620 为止：x > 1620 是抖音图标区，右上小圆也在那里（x ≥ 1640），互不碰
- 全屏模式（`pos: full`）：文档页占 x 90–1620，高亮句是画面里唯一强调；出镜小圆放左下（`arollSide: left`）或 `hide`
- 页面滑动时滑进字幕区（y > 820）和图标区（x > 1620）的部分压暗，高亮句和短标签永远在安全区内

规则（与 AGENTS 兼容）：

- document 元素内允许出现原文文字——这是引用原文，不是「图中带字」的违例；但引用的句子必须与发布清单「事实核对」条目一一对应（字段里写 fact 号）
- 页面截图不带第三方水印 / logo / 装饰页码以外的元素；有就裁掉或压暗
- 整页展示时，非引用部分一律压暗+虚化——既聚焦，也避免整页长文的版权问题
- 一期 1–3 处，和照片铺底段落交替；不整期都是文档（会变 PPT 讲解）
- **和 `paper` 卡的分工**：能拿到干净、可读、可回溯的原图（无水印、无登录墙、裁切后原意不变）才用 document；只有转述、付费墙、截图模糊的来源用 `paper` 卡 + 短标签。同一条来源不要既出 document 又出 paper；paper 仍然一期最多 1 次
- 文档段里短标签、摘句、译文只用白 / dim，强调色只有高亮一处

### pageflip（翻页）

- **硬翻（2D）**：页面绕中线左右翻（线性蒙版翻转，剪映「蒙版翻页」同原理），约 0.5s，配 whoosh。Remotion 实现简单，先做这个
- **软翻（3D）**：rotateY 90° 换页 + 光影；文章实测 3D 纵深感是 Remotion 弱项（5–6 分），后补
- 变体：**标题翻落**——标题卡片从画面上方翻下来（文章第 9 组），可给章节卡用

### pyramid（分层信息图）

- 文章第 1 组「种姓制度金字塔」：N 层渐变层级图，逐层从下往上弹出。原文每层有名称/翻译/描述，**本版每层只有一个 ≤ 4 字的标签 + 可选一个数 + 一个图标**，翻译和描述让口播说（不然 4 层就是 12 段字，和「文字只当标签」冲突）；层数 ≤ 4；弹出时只有当前层标签亮，其余层压成 dim
- 用在哪：收入阶层、财富分布这类「分层」的经济学场景
- 图标用代码画的几何形/简笔，不用版权素材

## 4. photo.json 字段草案

```json
{
  "type": "document",
  "src": "doc01.png",
  "pos": "right",
  "quotes": [
    {"text": "原句……", "box": [0.06, 0.42, 0.88, 0.06], "at": 0, "till": 2, "zoom": 3.2, "fact": 3, "excerpt": "补回 1/4 个月", "zh": "……"}
  ],
  "flip": "hard",
  "label": "Kimi 官方 X · 2026-10-26",
  "dim": 0.6,
  "blur": 2
}
```

- `src`：页面截图，编号 `D01`…，放选题文件夹 `图片素材/`，用新脚本 `import_docs.py` 入库到 `public/<ep>/docs/`（原比例不裁、不缩到 2560 以下）。**不能用 `import_photos.py`**：它只认 S 编号，而且会把图从中间裁成 16:9，竖版页面会被裁成中间一条。截图宽 ≥ 2560（网页按 2 倍设备像素比截、PDF 按 ≥ 2560 宽导出），否则放大后字是糊的
- `box`：高亮句在页面截图上的归一化坐标 [x, y, w, h]
- `zoom`：聚焦放大倍数，按「高亮句字高 ≥ 44 px」反推，上限 4；不写则只高亮不放大（只在字本来就够大时允许）
- `excerpt` / `zh`：摘句（截图字太小时必填）/ 中文短译（英文来源必填）
- `label`：短标签，机构 / 资料名 / 年份，和 `fact` 那条事实核对对应
- `fact`：发布清单「事实核对」条目号，**必填**——校验时双向核对（引用句 ↔ 来源链接）
- `pyramid`：`{"type": "pyramid", "layers": [{"name": "…", "num": "…", "icon": "…", "color": "…"}], "at": 1}`——每层只有 `name`（≤ 4 字）、可选 `num`、`icon`；不再有 `en` / `desc`
- `tagwall`：`{"type": "tagwall", "tags": [{"text": "央行", "icon": "bank"}, …], "strike": [2], "at": 0}`——4 张，每张 `text` ≤ 6 字 + 一个 `icon`

## 4b. 尺寸约束（tagwall 专条）

复刻版四宫格卡片偏小，本版规则：

- tagwall 是**画面主体**：四张卡 2×2 占满画面中区，不缩在角落当装饰
- 画面可用宽度只有 1530（x 90–1620，右侧 300 留给抖音图标）：每张卡 **≤ 740 宽、列间距 50**；高度 ≤ 325、行间距 40，开黑边的期再减 20。原稿写的「≥ 780 宽」两张放不下；它引用的「数字卡 780」在引擎里也从没生效过（卡都是 900）
- 标签字走 `h` 88 档（手机上约 49 px，满足「不小于画面宽度 4.5%」= 86 px）；每张卡一个图标 + 一个 ≤ 6 字的标签，不写第二行
- 与大字叠字不同屏：tagwall 出场时该场景不放大字，避免两套字打架
- 逐张入场（依次飞入 + 轻回弹），被否的标签盖 X（用 strikeAt 同款动画），一张一期最多出现一次

## 5. 校验规则（validate_ep 新增）

- document 的每条 quote 必须有 `fact` 号，且该号存在于发布清单「事实核对」，且该条的「用在」含这个场景的要点
- document 的 `src` 必须已入库（占位图不算）
- 高亮句 `box` 必须在页面截图范围内；聚焦后字高 < 44 px 报 warn；`zoom` > 4 报 warn
- 高亮句、短标签不出安全区（y ≤ 820、x ≤ 1620）
- 一期 document 场景数 ≤ 3，超过 warn（防止变 PPT）

## 7. 素材需求与来源（用户可找矢量图/素材）

入库方式照音效库的模式：素材放进 `工具/图标库/`，实现阶段加 `import_icons.py` 统一裁切/命名/进工程。

| 素材 | 用途 | 规格（找素材时按这个） | 优先级 | 来源建议 |
|---|---|---|---|---|
| 线条图标集（人、钱币、房子、工厂、芯片、箭头、天平、队列……约 25–35 个，清单见 v2 方案 §3） | pyramid 层级图图标、photorow 徽章、tagwall 角标 | **单色** SVG 或透明底 PNG ≥ 512；线宽统一；无文字；**可商用**；整组风格统一（线条风，呼应 document 的黑底白线审美；引擎能改色） | 高 | **只从一家取**：首选 Tabler Icons（MIT），缺的从 Lucide（ISC）补并改成同样线宽；Phosphor / Feather 不混用；iconfont 注意个别图标授权限制 |
| 纸纹 / 纸面纹理 | document 页面底色、paper 卡质感增强 | 无缝平铺 JPG/PNG ≥ 1024，灰度，可商用 | 低（代码噪点可替代，有素材更高级） | Pixabay 纹理类（免费可商用） |
| 实物小图（钞票堆、硬币堆） | units 变体 | 透明底 PNG ≥ 1024，无文字、无品牌标识 | 中（也可用即梦出图代替，风格更贴照片铺底） | 用户出图或 Pixabay |

找齐后放到 `工具/图标库/`（参照 `工具/音效库/` 的模式），实现阶段写 `import_icons.py` 入库。
