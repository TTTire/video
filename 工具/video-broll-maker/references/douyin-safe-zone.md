# 抖音横屏（16:9）视频：界面遮挡区与出镜小圆的落点

2026-10-30 定。起因：第 8 期出镜版小圆放在右下角（圆心 1720,800），用户在手机上看抖音时被按钮盖住。本文给结论、给依据，也给换算；改落点改 `src/photo/aroll.tsx` 的 `BUBBLE_AT`。

## 结论

16:9 成片（1920×1080）在抖音信息流里的四个角，按"能不能放出镜小圆"分：

| 角 | 能不能放 | 原因 |
|---|---|---|
| 左下 | 能（圆心 220,650） | 信息流里 16:9 画面的左下角没有任何界面元素；字幕线 820 之上 |
| 右上 | 能（圆心 1770,290） | 右侧图标列是从画面**中部往下**排的，画面右上角是空的；整个圆（含金边，x 1626–1914）都在 B-roll 不放字的 `SAFE_RIGHT` 区里，永远不碰字 |
| 右下 | **不能** | 头像 / 点赞 / 评论 / 收藏 / 转发这一列的下半段，加上横屏视频特有的「全屏观看」按钮，都压在这里（用户实测，2026-10-30） |
| 左上 | 不用 | 没遮挡，但 `topleft` / `right` 两种母版的大字都从 y=120 起，左上角经常有字 |

默认：`layout=right`（字在右）→ 左下；其他母版 → 右上；场景里 `arollSide` 换边，`arollPos` 直接给圆心。**没有理由再写右下角的 `arollPos`。**

## 依据

### 抖音信息流怎么显示 16:9 视频

手机竖着拿，16:9 视频居中显示，上下黑边；界面元素全部压在**手机屏幕**的固定位置，不随视频比例变。要知道哪块盖住画面，就把手机屏幕的遮挡区换算到视频坐标。

抖音的界面分区（知乎 [抖音画面量化布局探究](https://zhuanlan.zhihu.com/p/539950589)，2022，按 540×960 屏截图标注；配图里 C 区从屏幕 y≈380 起一直到底，宽约右侧 85px）：

- **B 区**（底部）：ID、文案、话题、音乐，从底部往上约 1/4 屏
- **C 区**（右侧）：头像、点赞、评论、收藏、转发，屏幕右侧 ≈ 15% 宽，**从屏幕中部开始往下**排到底
- **D 区**（顶部）：关注 / 推荐 / 搜索栏

竖屏 9:16 的通用安全区（[adaptlypost 2026 safe-zone guide](https://adaptlypost.com/blog/social-media-safe-zones-2026-complete-guide)，TikTok 同源）：1080×1920 画布上右侧 120px 是图标列、底部 320px 是文案区、顶部 108px 是导航。抖音的图标列比 TikTok 更宽（约 15% 对 11%），本文按抖音的 15% 算。

### 换算到 16:9 画面

手机屏按 9:16（1080×1920）算，16:9 视频居中显示时宽 1080、高 607.5，竖直占屏幕 y 656–1264（刚好压在屏幕中段）。

| 屏幕上的遮挡 | 落到视频画面上（1920×1080 坐标） |
|---|---|
| 右侧图标列（右 15% 宽，从屏幕中部 y≈760 起到底） | x ≥ 1632，y ≥ ≈ 185；也就是**右侧 288px 宽、从上 1/6 往下全是** |
| 底部文案区（底 320px，屏幕 y ≥ 1600） | 在视频画面下方的黑边里，**不压画面**（画面底在 y 1264） |
| 顶部导航（108px） | 在画面上方的黑边里，不压画面 |
| 「全屏观看」按钮（横屏视频独有，紧贴画面右下） | 右下角，约 x ≥ 1500、y ≥ 950 |

所以画面里真正被盖的只有**右侧一竖条**，而且是从中上部到底；右上角那一小块（y < 185）理论上是空的——但图标列的起点随机型、随文案行数上下浮动，不能当安全区用。

**工程里的处理**：B-roll 排版早就把右侧 300px（`SAFE_RIGHT = 300`，`SAFE_RIGHT_X = 1620`，见 `src/photo/kit.tsx`）划为"不放字、不放图表关键部分"的区域——这一条本来就是给图标列让的。出镜小圆放右侧时放进这 300px 里（圆心 x=1770，半径 130 + 金边 14 → x 1626–1914），不占任何排版空间；放在上面（圆心 y=290，圆顶 146，在 2.35:1 黑边 130 之下）而不是下面，是因为图标列和全屏按钮都在下半段，右上是整条右侧里被盖概率最低的位置。**小圆在右上角仍可能被图标列的头像盖住一角**——这是抖音界面决定的，没有不被盖的右侧位置；要彻底避开就用 `arollSide: left`。

### 字幕

剪映字幕放画面底部黑边里（y ≈ 1010）；在抖音信息流里这一行落在屏幕 y ≈ 1224，离底部文案区（1600 起）还有 370px，不会被盖；右侧图标列会盖住字幕最右约 15%，字幕居中、单行不超过 16 字宽时碰不到。

## 怎么核对

1. 渲一张 `render.py <epN> arollsheet`，看 `GridOverlay` 的红虚线：`抖音图标区 x>1620` 和 `字幕区 y>820`——小圆、字、图表关键部分都不该越线
2. 发布前在手机抖音里用「预览」看一遍小圆所在的段落，重点看右侧图标列的起点压没压到圆
3. 剪映手机版：预览窗右上角三横线 → 安全区 → 开启「抖音预览」，可以直接看到图标遮挡的位置（[剪映安全框怎么设置](https://www.douyin.com/video/7583204047948696870)）

## 没采用的材料

- 抖音开放平台「信息流体验设计标准」：讲的是小程序卡片，不是视频播放页
- 各家"安全区检查工具"（adconvert 等）：只有 9:16 模板，没有 16:9 居中显示的换算
