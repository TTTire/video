# B-roll 动效升级审阅稿（2026-10-29）

> 给用户审阅用，先不渲染。目标：回答三个问题——要不要用卡片、卡片能不能带图、数值/表格的变化怎么动。

## 二、先说结论：我们现在缺的不是元件，是"实物感"和"关系感"

对着小Lin说的 8 帧看我们 ep8 的拼图，差距不在字体、不在配色，在三件事：

1. **卡片是"字的容器"，不是"物"。** 我们四种卡（solid / paper / notch / tab）都是扁的半透明色块；小Lin说的卡有厚度、有角花、有细金边、有悬浮漂动，看起来是一张能拿起来的牌。观众对"物"的注意力远高于对"色块"。
2. **卡片里没有图。** 我们的卡只装字。小Lin说的卡装国旗、人物图标、钞票堆、小人；Vox 装剪下来的照片。**图进卡是本次升级的核心**。
3. **数据变化全靠 CountUp 一招。** 数字从 0 滚到目标值，柱子从 0 长到目标长度。小Lin说和 21st 的做法多得多：翻牌、里程表、排名换位、堆叠物增减、表格行点亮。更重要的是——**值变化时旧值和新值要同时在屏上一瞬**，观众才看得出"变了多少"，这是 Heer & Robertson 的核心结论。

## 三、卡片：建议的升级方向

### 3.1 保留四种语义，加一个"图卡"，全部换成实物质感

| 现有 | 用在 | 升级后的长相 |
|---|---|---|
| `solid` 金底黑字 | 结论、揭晓 | 不变语义；加 2px 内描边 + 底部厚边（已有 18px 硬投影，够） |
| `paper` 米白微斜 | 原文、新闻、账单 | **加纸纹 + 顶部一条胶带或回形针**（Vox 那套），这张卡本来就该像实物 |
| `notch` 深底左竖条 | 定义、前提 | 加角花（四角细线装饰，小Lin说那种）+ 中英双标（小字英文放大词下面） |
| `tab` 深底带签 | 一条数据 | 不变，这个已经像标签了 |
| **新增 `photo`** | **一个实体：一家公司、一个国家、一个人、一件商品** | 深底卡，上半是裁好的照片/图标（圆角、带内阴影），下半是中文大词 + 英文小字；细金边；悬浮漂动 ±6px；入场从侧面飞入 + 轻微回弹 |

`photo` 卡的图从哪来：
- **用户出图时多出一类"卡内小图"**：方形或 4:3，主体居中，纯色或虚化背景，编号 `C01`、`C02`…，和场景底图 `S01` 分开。例如 ep8 的"海底捞 / 奈飞 / 香烟 / 奢侈品包"各一张。
- 国旗、品牌 logo 这类不能自己出的，用 SVG/emoji 级别的图标，或者干脆用文字卡——**不用真 logo，避免版权**。

### 3.2 卡片之间的关系：连线 + 分组

小Lin说"避险 / 投机 / 美联储主席 / 地缘政治"四张卡拉发光连线，是在讲**概念之间的关系**。我们的口播稿里这种结构很多（第 8 期的"替代品 / 预算 / 时间"三件事、第 6 期的"人 / 机器 / 瓶颈"）。

建议加 `type: 'graph'`：传入节点（卡）和边，节点按句出现，边在两个节点都出现后画一条带光的线，线从 A 向 B 生长（`stroke-dashoffset` 动画）。节点可以是 `photo` 卡也可以是纯字卡。

### 3.3 不建议做的

- **3D 翻页章节转场**：那篇测评自己说 Remotion 做出来只有 5–6 分，"3D 纵深和光影不够"。我们章节卡现在是 `flip`，够了，别往这条路上堆。
- **粒子 / 光效 / 星空底**：和我们"写实照片铺底"的定位冲突。小Lin说没有照片底图所以需要它们填空，我们有。

## 四、数值和表格的动效

### 4.1 Heer & Robertson 的四条原则（直接拿来做验收标准）

1. **一致性**：动画过程中每一帧都应该是"合法"的数据状态——柱子不能先缩再长、数字不能跳过中间值
2. **分阶段**：复杂变化拆成顺序进行的几步（先换轴 → 再换值 → 再换标签），不要同时动
3. **可预测**：用慢进慢出，用户能预判终点；避免弹跳过头（我们现在 spring 回弹对文字 OK，对数据柱不行，柱子不该过头）
4. **保持对象恒常**：同一个数据项在变化前后用同一个位置/颜色，不要重绘

### 4.2 建议的数值动效词汇（替代"只有 CountUp"）

| 名字 | 长相 | 用在 | 来源 |
|---|---|---|---|
| `odometer` | 每一位数字像里程表独立上滚，右边位先动左边位后动 | **价格变化**（¥16 → ¥23）、年份切换（2011 → 2024） | 21st "Odometer Rows"、react-strp-counter |
| `flap` | 机场翻牌，旧值翻下去新值翻上来 | **一个值被另一个值替换**（涨幅 10% → 6%、"涨得离谱" → "只有 6%"）；和 `strikeAt` 划线是同一语义的两种长相 | 21st "Split Flap Rates" |
| `slam` | 大数从远处砸下来，到位时轻微震屏 + 低频音效 | **本期的核心数字**，一期一到两次（现在 `big` + `stagger` 承担这个，改成这样更有力） | 21st "Stat Slam"，我们的 `Stamp` 已有类似 |
| `rank` | 几行并列项按新值重新排序，行与行交换位置 | 排名、对比表的"谁先走"（第 8 期：年轻人 vs 老烟民） | 21st "Leaderboard Rank Climb" |
| `stackUnits` | 用实物堆叠表量：钞票 / 人形 / 杯子，一个一个落下 | **人数、钱数这种可数量**（5000 万人、80 万用户、41 00 万净增） | 小Lin说钞票堆；第 6 期已有 `IconTea` 可以复用 |
| `fill` | 容器里液面上升到百分比 | 占比、份额（预算占比） | 21st "Liquid Fill" / "Progress Fill" |

实现成本从低到高：`flap` < `odometer` < `slam` < `fill` < `stackUnits` < `rank`。前三个是纯 CSS transform，半天能出；后三个要 SVG 和布局计算。

### 4.3 表格的动效

现在 ep8 的 `threeTable` 已经是"一场加一行、旧行变暗"，方向对。补三件事：

1. **行高亮扫过**：新行出现时，一道 20% 透明的金色横光从左扫到右（200ms），然后落到正常亮度。观众眼睛会被带到那一行。
2. **单元格值变化用 `flap` 或 `odometer`**，不要整格重绘。
3. **列头先出、再出行**：Heer 的"分阶段"——先让观众知道"这张表有几列、每列是什么"，再往里填数。现在是行连着列头一起出。

## 五、给 ep8 的具体改法（如果同意上面的方向）

| 场景 | 现在 | 改成 |
|---|---|---|
| `menu` 开场菜单 | 四行字依次出现，"一片土豆 ¥1.5" stagger | 前三行改 `paper` 卡（加胶带）像一张真菜单；¥16 → ¥23 用 `odometer`；¥1.5 用 `slam` |
| `define` 弹性横条 | 两组横条从 0 长出 | 不变（横条本身是对的），但 −20% / −2% 的数字用 `odometer` |
| `three/budget/time` 三件事表 | 一场一行 | 加行高亮扫光；"月薪 5000 vs 50000" 用两张小 `photo` 卡并排（钱包图标） |
| `tobacco` 香烟 | tab 卡 + 数字 | "4%–5%" 用 `fill` 做个 5% 的容器，直观看出"只掉一点" |
| `two` 老烟民 vs 年轻人 | 分屏 + 字 | 加 `rank`：两行"老烟民 / 年轻人"，涨价后年轻人那行掉下去 |
| `netflix2011 / 2025` | 两张 tab 卡 | 改两张 `photo` 卡（录像带 / 流媒体图标），用户数 80 万 → 4100 万用 `odometer`；股价 −70% 用 `flap` |
| `revenue` 算术卡 | CountUp 两行 | 不变，这里 CountUp 是对的（算式结果滚出来） |
| `substitute` 橡皮筋 → 铁丝 | 字 + 箭头 | 两张 `photo` 卡（橡皮筋 / 铁丝实拍小图）+ 中间箭头生长 |

## 六、需要你拍板的

1. **卡片要不要走"实物感"路线**（厚度、角花、金边、漂动）？还是保持现在的扁平半透明？两者不能混，一期一种。
2. **`photo` 卡的图由谁出**：你按 `C01`… 编号出小图（多一道工序），还是我用图标库顶（质感差一档）？
3. **数值动效先做哪几个**：我建议先做 `odometer` + `flap` + `slam` 三个，半天出，ep8 就能用上；`rank` / `stackUnits` / `fill` 放到下一期。
4. **要不要加 `graph`（卡片连线）**：第 8 期用得上的只有"三件事"一处，不急；但《100 个经济学原理》后面几期（供给定律、均衡、价格歧视）全是关系图，迟早要。

## 七、不做的事，和原因

- 不引入 21st.dev 的现成组件源码：它们是 Tailwind + 独立合成，和我们 photo.json 的 step 驱动模型不兼容，抄思路比抄代码快。
- 不做 Vox 的纸张剪贴整体风格：那是没有照片底图时的解法，我们已经有照片铺底；只借它的 `paper` 卡质感和"一期一个视觉锚点"的做法。
- 不加粒子、光效、星空：和写实照片冲突，而且 WebGL 光效是 ep6 以前就试过放弃的。
