# 第 7 期剪辑说明：口播 A-roll + 动画轨

动画轨的时间轴按你的口播字幕（`10月11日.srt`）生成，每个画面切换都卡在你说那句话的时间点上。全长 6 分 23 秒，和口播一样长。

## 文件

| 文件 | 用法 |
|---|---|
| `7-100-…-动画轨-对齐口播-仅音效.mp4` | **整条动画轨**，1920×1080，只有音效，没有配音和字幕 |
| `剪辑素材-分场景-仅音效/` | 28 个分场景片段，编号和下表一致（旧的第 7 期合成配音版片段已删） |
| `7-100-…-动画轨-核对版-前40秒.mp4` | 前 40 秒烧了字幕，只用来核对画面和口播是否同步 |

## 推荐剪法

1. 主轨放口播 A-roll，**从 0 秒开始**。
2. 动画轨放在画中画轨（上一层），**起点也对齐 0 秒**。
3. 想露脸的段落把动画轨切开、删掉，下面的 A-roll 就露出来了；音效跟着动画一起没了，正好。
4. 字幕、BGM 在剪映里加。画面文字都压在上 2/3，底部留了字幕位。
5. 口播里如果剪掉了 NG 或停顿导致后面错位，就在动画轨同一位置剪掉同样的长度；或者改用分场景片段按下表时间点逐段摆。

## 重新生成

字幕或口播改了以后，在 `工具/video-render` 下运行：

```bash
python scripts/timeline_from_srt.py <口播逐字稿.md> <新的.srt> ep7 src/ep7/scenemap.json
python scripts/render.py ep7 sheet      # 先看关键帧拼图
python scripts/render.py ep7 full       # 全片 → out/ep7-photo.mp4
python scripts/split_scenes.py out/ep7-photo.mp4 ep7 <输出文件夹> src/ep7/scene-names.json
```

改文字 / 位置：`src/ep7/photo.json`；价格阶梯图表：`src/ep7/custom.tsx`。
