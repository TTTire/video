## 剪法

- 成片直接放主轨，从 0 秒开始，不用再对 A-roll：出镜层已经合在画面里，人声已经混进音轨。
- 人声就是 `粗剪.mp4` 自带的音轨（录音笔音轨，aroll-prep 同步 + 用户剪定），原样抽出来混的，和画面同一条时间线。
- 成片比粗剪长 1.1 秒（最后一句说完后留了 2 秒尾巴），末尾是静音 + 画面缓推，剪映里按需要裁。
- 字幕：导入 `同一张票凭什么卖两个价-中文字幕.srt` / `-英文字幕.srt`，或直接用双语版。字幕时间轴就是成片时间轴。
- BGM 按发布清单「背景音乐（Suno）」那段出，铺在人声下面。

## 录制时跳过、改说的要点

讲稿卡是录完按录音重写的，要点和成片一致，没有跳过和改说。几处口径见讲稿卡「别说」：
- 3.2 安卓 / 苹果打车：录音说"定价不一样"，画面只写「大数据杀熟 · 按你的消费记录报价」，不写"苹果更贵"（依据只有复旦 2021 年那份调研，结论是更容易被派到贵车型、优惠更少）。
- 2.6《生化危机》30 多 / 70：本人经历，卡签「上上周 · 《生化危机》」。
- 1.7 舱位：只放一张实物卡，不写"舱位差价全是歧视"。

## 重新生成

字幕对齐（定版 `粗剪.mp4` 是在 `A-roll粗剪` 上手剪的，没有 aroll-prep 的映射，所以用音频互相关定位剪点，再把 srt / words.json 的时间整体平移）：

- 两版粗剪抽成 8 kHz 单声道，滑窗互相关：01:17.97 之前偏移 0（相关 1.000），之后偏移 −1.467 秒（相关 0.978），只有这一处剪点。
- `A-roll粗剪/*.srt` 第 27 条「商家认识你。」整条落在剪掉的区间里，删掉；其余 95 条和 words.json 里每个词按 ≤ 77.967 s 不动、≥ 79.434 s 减 1.467 s 平移 → `粗剪.srt`、`粗剪.words.json`。
- 要点起点表 `src/ep11/starts.json` 按平移后的字幕条填：每条要点取第一句的开始，`N.0` 取上一章最后一句的结束。

动画轨 + 出镜层（`工具/video-render` 下）：

```bash
python scripts/scenes_from_checklist.py "<发布清单.md>" "<讲稿卡.md>" ep11          # photo.json 已手调，不要加 --force
python scripts/import_photos.py "<选题文件夹>/图片素材" ep11 --need "<发布清单.md>"
python scripts/import_cards.py "<选题文件夹>/图片素材" ep11 --need "<发布清单.md>"

ffmpeg -i "<选题文件夹>/粗剪.mp4" -vf scale=1920:1080 -r 30 -an -c:v libx264 -crf 18 -preset fast public/ep11/aroll.mp4
python scripts/aroll_face.py ep11
```

关键帧核对（比逐帧 `npx remotion still` 快）：`node scripts/stills.mjs Ep11FullCheck out/ep11-keys define=303 card=462 …`，每帧一张 jpg 渲进 `out/ep11-keys/`。

成片混音（人声直接从定版粗剪抽，48 kHz）：

```bash
ffmpeg -i "<选题文件夹>/粗剪.mp4" -vn -ar 48000 -ac 2 -c:a pcm_s16le out/ep11-voice.wav
ffmpeg -i out/ep11-full.mp4 -i out/ep11-voice.wav -filter_complex "[0:a]aresample=48000[s];[1:a]aresample=48000[v];[v][s]amix=inputs=2:normalize=0:duration=longest,alimiter=limit=0.7499:attack=5:release=50:level=false:latency=true[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -ar 48000 -movflags +faststart "<选题文件夹>/同一张票凭什么卖两个价-成片.mp4"   # duration=longest：人声比动画轨短 1.1 秒，音轨要跟满画面
```
