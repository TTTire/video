# 第 6 期剪辑说明：口播 A-roll + 动画穿插

动画的时间轴按你口播的字幕（`边际报酬递减.srt`）生成，每个画面切换都卡在你说那句话的时间点上。

## 文件

| 文件 | 用法 |
|---|---|
| `6-100-…-动画轨-对齐口播-仅音效.mp4` | **整条动画轨**，5 分 31 秒，和口播一样长，只有音效 |
| `剪辑素材-分场景-仅音效/` | 23 个分场景片段，编号和下表一致 |
| `6-100-…-样片-横屏.mp4` | 旧版样片（合成配音），只作参考，**不要用来剪** |

## 推荐剪法（整条动画轨）

1. 主轨放口播 A-roll，**从 0 秒开始**。
2. 动画轨放在画中画轨（上一层），**起点也对齐 0 秒**。
3. 在想露脸的段落把动画轨切开、删掉，下面的 A-roll 就露出来了。
4. 音效跟着动画走：露脸的段落删掉动画，音效也一起没了，正好。
5. 口播里如果剪掉了 NG 或停顿，导致后面整体错位，就在动画轨同一位置剪掉同样的长度；或者改用下表的分场景片段，按时间点逐段摆。

## 重新生成

字幕或口播改了以后，在 `工具/video-render` 下运行：

```bash
python3 scripts/timeline_from_srt.py <口播逐字稿.md> <新的.srt> ep6 src/ep6/scenemap.json
npx remotion render src/index.ts Ep6FxSfx out/ep6-fx-sfx.mp4 --codec=h264 --crf=18
python3 scripts/split_scenes.py out/ep6-fx-sfx.mp4 ep6 <输出文件夹> src/ep6/scene-names.json
```
