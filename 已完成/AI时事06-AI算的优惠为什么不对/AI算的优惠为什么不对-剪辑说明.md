## 剪法

- 成片直接放主轨，从 0 秒开始，不用再对 A-roll：出镜层已经合在画面里，人声已经混进音轨。
- 人声是 `同步/A-roll-同步-全部.mp4`（录音笔音轨）按 `A-roll粗剪/剪辑映射.json` 的 71 段 keeps 切出来的，和粗剪同一条时间线：142 个窗口逐段对过粗剪音轨，141 个偏差 0–0.9 ms，剩下 1 个落在 00:02.4 的句间静音里（相关峰不可信，同一段 keep 里其他窗口都是 0 ms）。成片画面逐帧对过粗剪（抽 5 处，都是同帧最像），口型同步和粗剪一致。
- 字幕：导入 `AI算的优惠为什么不对-中文字幕.srt` / `-英文字幕.srt`，字幕时间轴就是成片时间轴。
- BGM 按发布清单「背景音乐（Suno）」那段出，铺在人声下面。

## 重新生成

粗剪按 `同步/同步报告.md`（录音笔五段拼接、对齐，「自我」那段 MVI_9122 没拼进整条）和 `同步/剪切清单.md` 做，渲染不用重跑这一步。要重剪（`工具/aroll-prep` 下）：

```bash
python scripts/cut.py "<选题文件夹>/同步/A-roll-同步-全部.mp4" "<选题文件夹>/同步/剪切清单.md" --words "<选题文件夹>/同步/A-roll-同步-全部.words.json" --out "<选题文件夹>/A-roll粗剪/AI算的优惠为什么不对-A-roll粗剪.mp4" --snap 0 --margin 0
```

动画轨 + 出镜层（`工具/video-render` 下）：

```bash
python scripts/scenes_from_checklist.py "<发布清单.md>" "<讲稿卡.md>" ai06          # photo.json 已手调，不要加 --force
python scripts/import_photos.py "<选题文件夹>/图片素材" ai06 --need "<发布清单.md>"
python scripts/import_cards.py "<选题文件夹>/图片素材" ai06 --need "<发布清单.md>"
python scripts/make_timeline.py "<讲稿卡.md>" ai06 --starts src/ai06/starts.json --srt "<选题文件夹>/AI算的优惠为什么不对-中文字幕.srt"
ffmpeg -i "<选题文件夹>/A-roll粗剪/AI算的优惠为什么不对-A-roll粗剪.mp4" -vf scale=1920:1080 -r 30 -an -c:v libx264 -crf 18 -preset fast public/ai06/aroll.mp4
python scripts/aroll_face.py ai06
python scripts/render_seq.py ai06 --comp Ai06Full --frames 0-9941 --out out/ai06-full.mp4 --fresh --no-check
python scripts/glitch_check.py out/ai06-full.mp4
```

成片混音（人声按上面「剪法」第 2 条切：录音笔整条转 48 kHz wav，keeps 的 `src_start`–`src_end` 按采样点取整逐段接，得 330.297 秒的 voice.wav）：

```bash
ffmpeg -i "<选题文件夹>/同步/A-roll-同步-全部.mp4" -vn -c:a pcm_s16le -ar 48000 out/ai06-audio/sync-full.wav
python -c "import json,wave,numpy as n;M=json.load(open('<选题文件夹>/A-roll粗剪/剪辑映射.json',encoding='utf-8'));w=wave.open('out/ai06-audio/sync-full.wav');x=n.frombuffer(w.readframes(w.getnframes()),n.int16).reshape(-1,2);v=n.concatenate([x[round(k['src_start']*48000):round(k['src_end']*48000)] for k in M['keeps']]);o=wave.open('out/ai06-audio/voice.wav','wb');o.setnchannels(2);o.setsampwidth(2);o.setframerate(48000);o.writeframes(v.tobytes())"
ffmpeg -i out/ai06-full.mp4 -i out/ai06-audio/voice.wav -filter_complex "[0:a]aresample=48000[s];[1:a]aresample=48000[v];[v][s]amix=inputs=2:normalize=0:duration=longest,alimiter=limit=0.7499:attack=5:release=50:level=false:latency=true[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -ar 48000 -movflags +faststart "<选题文件夹>/AI算的优惠为什么不对-成片.mp4"
```

`duration=longest`：人声比画面短 1.1 秒，音轨跟着音效轨走到片尾，最后一场的商场环境声按自己的 0.8 秒淡出收掉，不在人声结束处截断。
