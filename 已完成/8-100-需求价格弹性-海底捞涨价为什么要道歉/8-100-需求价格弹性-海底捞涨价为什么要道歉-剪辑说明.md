## 剪法

1. 整条成片从 0 秒放一条轨，总长正好 6 分 51.6 秒。
2. 原 A-roll（`不带字幕1/不带字幕1-1.mp4`）只留音频（或静音画面垫在底下），字幕和 BGM 照常加。
3. 这期开了黑边，字幕放在底部黑边里（y ≈ 1010）正好，不会压到画面文字。
4. 口播里如果剪掉了 NG 或停顿，导致后面整体错位，就在同一位置剪掉同样的长度。

## 重新生成

在 `工具/video-render` 下运行（Windows 把 `python3` 换成 `python`）。

**换一台电脑后的完整流程**（`public/` 和 `*.mp4` 不进仓库，pull 下来 `public/ep8/` 是空的）：

```bash
cd 工具/video-render
npm install && npx remotion browser ensure                      # 新机器一次
python3 scripts/import_photos.py "../../进行中/8-100-需求价格弹性-海底捞涨价为什么要道歉/图片素材" ep8   # 20 张 S 图 → public/ep8/photos/
python3 scripts/import_sfx.py                                                                             # 工具/音效库 → public/sfx/
# A-roll：无字幕版 不带字幕1/不带字幕1-1.mp4（4K 30fps，410.63 秒，和 10月26日.srt 同一时间线、从 0 秒对齐；srt 最后一条 6:49.6，差 1 秒内算对齐）
ffmpeg -i "../../进行中/8-100-需求价格弹性-海底捞涨价为什么要道歉/不带字幕1/不带字幕1-1.mp4" -vf scale=1920:1080 -r 30 -an -c:v libx264 -crf 18 -preset fast public/ep8/aroll.mp4
python3 scripts/render.py ep8 arollsheet                        # 拼图：右上小圆不该越过红虚线碰到字
# 整片渲一次（约 14 分钟，3×3 并行）；要顺便切 4 段才加 --keep（留图片序列和 wav）
python3 scripts/render_seq.py ep8 --comp Ep8Full --frames 0-12347 --out out/ep8-full.mp4 --workers 3 --concurrency 3 --fresh --no-check
python3 scripts/glitch_check.py out/ep8-full.mp4                 # 应为 坏帧 0
P="../../进行中/8-100-需求价格弹性-海底捞涨价为什么要道歉/8-100-需求价格弹性-海底捞涨价为什么要道歉-动画轨+出镜-仅音效"
cp out/ep8-full.mp4 "$P-全片.mp4"
# 可选：python3 scripts/split_chapters.py ep8 out/ep8-full.mp4 "$P" --verify   # 需要 --keep；从同一套帧 + wav 切 4 段并和整片比接缝；切完 rm -rf out/ep8-seq
```

`src/ep8/photo.json` 的 `aroll` 已经是无字幕版的设置（没有 `halfView`，`bubbleView` 0.72 / `bubbleFaceAt` 0.34）。

只改某一章：改完 cue / 场景后 `python3 scripts/render_seq.py ep8 --comp Ep8Full --frames <该章帧区间> --out "$P-<段名>.mp4" --fresh --no-check` 单渲那一段原位替换；但这样渲出来的段是独立编码的音轨，替换完要听接缝。想彻底稳就按上面整片重渲一次。

字幕或口播改了：`python3 scripts/timeline_from_srt.py "<口播逐字稿.md>" "<新的.srt>" ep8 src/ep8/scenemap.json`，再整片重渲。出镜表：`python3 scripts/aroll_cues.py ep8`。
