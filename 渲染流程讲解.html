01

一期视频的完整流水线

Five Stages

写稿

我写 · 你确认

讲稿卡 + 发布清单（含画面与素材清单）。清单同时是出图清单和渲染场景表，占位图先拼一版查版式。

出图

你做

按出图清单用即梦 / MJ 出图：S01、S02… 铺底图，C01… 卡内小图。所有图无文字、16:9、宽 ≥ 2560。

录制

你做

拿讲稿卡自由讲，相机 + 录音笔。工具 aroll-prep 出粗剪 mp4 + srt + words.json，同一条时间线。

渲染

我做

收到粗剪和图之后：收料 → 时间轴 → 入库 → 写画面 → 拼图 → 小样 → 全片。本页的主体就是这段。

交付

我交 · 你剪

成片 + 剪辑说明 + 双语字幕；跳过 / 改说的要点回写进讲稿卡。你在剪映加人声、字幕、BGM。

01

要点起点表 starts.json

对齐口播src/ep10/starts.json

在写什么

  • 对照粗剪 srt 和 words.json，记下讲稿卡每条要点开口的时间：{"0.1":"00:00.2", …, "end":"05:47.2"}
  • 章节卡 N.0 = 上一章最后一句说完；end = 最后一句说完
  • 画面上的字按「第几条要点」挂，所以这一步定了每行字和每张图的出场时刻

录的时候没讲的要点

  • 填成和下一条完全相同的时间——它要是场景起点，整个场景时长归零自动跳过
  • 别填只差零点几秒：那个场景会闪几帧还带一声 pop
  • 没讲 / 改说的要点自己记下来，交付时回写进讲稿卡（标 ⊘跳过）
过关讲稿卡每个 id 都有（含 3 张章节卡），时间不往回走；make_timeline 报的「时长为 0 已跳过」全是有意跳过。
02

生成时间轴 timeline.json

机器可读source = starts

这一步在做什么

  • 把 starts.json 换算成每个场景的帧区间（from / dur）
  • 把粗剪 srt 切成每条字幕的帧区间，带字幕的小样和字幕合成靠它
  • 算出全片 total 总帧数——ep10 是 10476 帧 ≈ 5:49
  • 录前那份按字数估时的预览时间轴被正式覆盖，之后一切渲染以这份为准

命令与产出

python scripts/make_timeline.py "10-100-消费者剩余-半价买的手机真赚到了吗-讲稿卡.md" ep10 --starts src/ep10/starts.json --srt "A-roll粗剪/*.srt"
  • 产出 src/ep10/timeline.json：场景区间 + 字幕 + 总帧数
  • 渲染最后拿「输出帧数 = total」当完整性的硬判据
过关命令不报错；打印的每个场景起点、时长和口播对得上；total 在合理范围。

04

填 photo.json —— 写画面

核心步骤src/ep10/photo.json

每个场景写什么

  • 哪张照片、推拉方向（in / out）、压暗在哪一侧（字和出图清单的留白同侧）
  • 叠字：h 大字 88 / t 小字 44 / big 数字 180；小字铺陈、大字定结论、数字单独放大
  • 卡片是「信息性质」的标签：solid 结论（一期 ≤2）· paper 原文（≤1）· notch 前提定义 · tab 一条数据
  • 数值动效一场一种：odometer 里程表 / flap 翻牌 / slam 砸入 / rank 排名 / units 堆叠 / fill 液面 / graph 连线

克制项和出镜层

  • 字效只有三个半：outline 空心对比 · gradient 渐变（一期只给一处，核心概念词）· reveal 擦出揭晓 · stagger 逐字（一期 ≤2 次，只给开场钩子和结尾金句）
  • 音效走 sparse 精简：字和卡出现不响，只有「变化」响；揭晓点手动加 impact / error / cash
  • 出镜层 aroll.cues：要点 id → full / half / bubble，见下一节
  • 复杂图表写进 src/ep10/custom.tsx，photo.json 里用 {"type":"custom","name":"xxx"} 引用
过关禁用清单零违例：不压字幕线、不过时出字、一场一种数值动效、不出现第六种字体……（页末速查）。

你的 A-roll 有两条合入路线

Two Ways
第 8 期及以前

路 A · 你自己叠

交付只有动画轨，出镜全在剪映里完成
  • 我交 动画轨（只有音效），你在剪映里把 A-roll 放另一条轨，从 0 秒对齐
  • 想露脸的地方，把动画轨那一截切掉，露出底下的 A-roll
  • 好处是全手动、想怎么切怎么切；代价是每个露脸点都要自己抠
2026-10-29 起 · 默认

路 B · 引擎合

photo.json 里写 aroll.cues，引擎把出镜层直接合进成片
  • cues 按要点 id 写三档：full 全屏（我的判断、感受、打算；开场第一条）· half 半屏（画面左边卡位，只配 right 母版）· bubble 小圆（数据、历史、图表段默认；章节卡自动 hide）
  • 小圆 ⇄ 全屏之间是圆形 iris 切换；跟脸引擎让小圆里的脸始终居中
  • A-roll 在成片里是静音的，人声和字幕你在剪映加——口型时间轴已经对齐

硬规矩速查（违例就否决）

Hard Rules
字幕线画面文字 y ≤ 820，底部 70px 留给剪映字幕；出镜小圆不放右下角（抖音按钮区）。
字号不缩h88 大字一行最多 12 字，超了拆句，不缩字号。
卡片是语义标签solid 结论 ≤2 次 · paper 原文 ≤1 次 · teal / coral 只表示正负，不当装饰。
数值动效一场一种；slam 一期 ≤2；动画每一帧都是合法数据状态。
音效 sparse字和卡出现不响，只「变化」响；揭晓点才手动加 impact。
重渲 --fresh改过 photo.json / custom.tsx / 图 / 时间轴后必须加，否则新旧帧混在一起。
渲染引擎只用 Remotion 自带 chrome-headless-shell；交付前 glitch_check 坏帧 0。
五款字体得意黑标题 · 数黑体数字 · 锦书宋定义大词 · 文楷对白 · 思源黑小字，不加第六种。
无字空档一个场景连续 8 秒以上无字要补一条小字或拆场景；同图同推拉最多连两场。
图里无文字招牌、价签、数字都要重出或用压暗盖掉；宽 ≥ 2560。
gradient / stagger渐变一期 1 处、逐字一期 ≤2 次（开场 + 结尾）；强调色一场最多一处 gold 大字。
接缝校验分章切段 --verify：SSIM ≥ 0.98、音频偏差 < 10%，不过就整片重渲。
